# PoE PD 以太网传感节点需求输入

版本：v0.1；日期：2026-11-02；产品基线：`industrial_telecom`。
状态：供 ASG 任务 1.1 读取的需求草案；文末澄清未答复，尚不是详细设计冻结输入。
范围：**选择 IEEE 802.3af-2003 PD（Type 1 功率范围），不要求 802.3at Type 2**，
10/100 以太网 PHY 与 RJ45 磁件、一路温湿度测量、一路模拟传感输入、MCU、本地标称 3.3 V 轨。
不提供辅助适配器输入或下游 PoE 供电。变换拓扑由 ASG 比较、论证并选择，本文件不指定料号或电路实现。

## 依据与适用边界

- **U**：本次用户任务（2026-11-02），规定功能数量、10/100 速率和本地 3.3 V 标称电压。
- **B**：本次校准选择 IEEE 802.3af、单铜口、室内单建筑布线、仅 PoE 供电、两路传感同时工作。
  温湿度测量作为一个测量功能，同时提供温度与相对湿度；模拟输入不假定为某种工业电压/电流制式。
- **S1**：IEEE 802.3af-2003，§33 PD：检测、分级、供电、维持供电及 §33.4.1 隔离。
  未取得该版标准全文。功率/供电窗先采用
  [Microchip AN3471 Rev.B，2021，表 1-2](https://ww1.microchip.com/downloads/en/Appnotes/AN3471_Designing_a_PoE_PD_using_PD702x1_and_PD701x1_00003471B.pdf)
  的厂家转引（Type 1：PD 可得 12.95 W、工作供电窗 37～57 V），
  并与 [IEEE 802.3at-2009 标准正文副本（TI 社区托管）](https://e2echina.ti.com/cfs-file/__key/communityserver-discussions-components-files/24/4336.802.3at_2D00_2009.pdf)
  §33.3.7、表 33-18 的 Type 1 项交叉核对。**该副本是 at 修订正文，不是 af 全文，也不把本板升级为 Type 2**。
  af 的确切电气限值、瞬态与版本差异在 C01 关闭前仍须核对。
- **S2**：[IEEE 802.3 工作组 David Law，2005-05，Isolation requirements](https://www.ieee802.org/3/poep_study/public/may05/law_1_0505.pdf)，
  PDF 第 9 页摘录 af-2003 §33.4.1；第 5–6 页摘录/讨论 802.3-2002 §14.3.1.1 和 10/100 铜口隔离。
  支持 1500 Vrms、50～60 Hz、60 s 的电气强度条件。它是工作组摘录，不是现行 802.3 或安全标准全文。
- **S3**：IEEE 802.3 以太网：10BASE-T、100BASE-TX、自动协商分别涉及 §14、§25、§28；
  采用的汇编版次和完整 PHY/MDI 条款待 C05 核对，不把 PHY 手册等同于完整标准符合性。
- **S4**：[IEC 61000-4-2:2025](https://webstore.iec.ch/en/publication/68954)，ESD；
  **S5**：[IEC 61000-4-4:2012](https://webstore.iec.ch/en/publication/22271)，EFT；
  **S6**：[IEC 61000-4-5:2014+AMD1:2017](https://webstore.iec.ch/en/publication/61166)，浪涌。
  仅核到官方出版信息/方法范围，未取得正文；试验等级、适用端口、耦合及条款号分别待 C12–C14。

`shall` 为必须满足；`should` 为建议目标，偏离时说明理由。未给出处的数值不自行填入，
“待澄清”不是已获用户授权的有条件假设。PoE 电压/功率在 **PD 的 PI** 测量，不把 PSE 端输出功率当作本板可用功率；
本地电源在负载端、模拟信号在输入端、测量误差在最终数字读数处验收。

## 供电拓扑的设计自由度

隔离反激与非隔离 Buck 是后续比较的候选方向，不是本文件要求实现的电路。
选择理由必须覆盖实际隔离边界、传感器是否外接/接地、调试器接地、受电功率、损耗与全温可行性。
若非隔离 Buck 不能在全部允许连接组合下满足隔离约束，应在方案比较中排除；
若能证明所有跨越路径满足约束，可选择它并给出证据。不能只以低成本或 RJ45 已有磁件为理由免除供电隔离核对。
拓扑设计和器件选型是 ASG 的工作，不列为需要产品方投票的澄清。
