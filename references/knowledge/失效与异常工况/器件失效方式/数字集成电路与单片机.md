# 数字集成电路与单片机的失效方式

类别：器件失效方式。
适用范围：逻辑器件、接口芯片（收发器、电平转换）、存储器、单片机、处理器和可编程逻辑。复杂芯片按功能分析，不逐个晶体管分析。
对应准则：G05-002（复杂芯片按功能分析）、G05-004、G05-007、G05-013（软件参与的故障）、G04-007、G04-009（未上电接口与反灌）、G04-010（上电和复位期间输出确定）。

## 来源

- S1：Standard/ECSS-Q-ST-30-02C 故障模式影响及危害性分析 - 2009.pdf
- S2：Standard/MIL-HDBK-338B 电子可靠性设计手册 - 1998.pdf
- S3：Book/Reliability Engineering Theory and Practice - 2017 - Birolini.pdf
- S4：Applicationnote/Toshiba - 半导体可靠性手册 - No-DocID.pdf

各来源的数据性质：S2 比例引自 FMD-91（1991 年），原件写成小数，照抄（.36 即 36 %）；S3 为第 3 版（1999 年）的示意性分布，对数字 MOS 电路的注释：开路一半在输入一半在输出，短路一半对电源一半对地。

## 失效方式与比例

| 细类 | 失效方式 | 比例 | 来源 |
|---|---|---|---|
| 微处理器、微控制器、存储器、可编程逻辑、逻辑族 | 任一输出对正负电源短路；任一输出卡在 0 或 1；任一输出高阻；任一输入对正负电源短路；任一输入卡在 0 或 1；任一路电源开路（含地脚）；正负电源之间短路；任一功能失效 | 只列模式 | S1 p63 |
| 数字双极型电路 | 输出卡高 / 输出卡低 / 输入开路 / 输出开路 | .28 / .28 / .22 / .22 | S2 p442 |
| 数字 MOS 电路 | 输入开路 / 输出开路 / 电源开路 / 输出卡低 / 输出卡高 | .36 / .36 / .12 / .09 / .08 | S2 p442 |
| 接口电路 | 输出卡低 / 输出开路 / 输入开路 / 电源开路 | .58 / .16 / .16 / .10 | S2 p442 |
| MOS 存储器 | 数据位丢失 / 短路 / 开路 / 数据传送变慢 | .34 / .26 / .23 / .17 | S2 p442 |
| 数字双极型电路 | 短路 / 开路 / 功能（%） | 50 / 30 / 20 | S3 p117 |
| 数字 MOS 电路 | 短路 / 开路 / 功能（%） | 20 / 60 / 20 | S3 p117 |

两个来源都以数字 MOS 电路的开路为最多。接口电路以输出卡低为最多（S2）。

## 失效的形成

| 失效方式 | 形成过程 | 来源 |
|---|---|---|
| 栅氧击穿（静电） | 栅氧化层击穿场强一般为 8 到 10 MV/cm；栅氧 50 nm 厚的器件在 40 到 50 V 击穿 | S4 p60 |
| 结烧毁（静电） | 放电电流使结区局部过热；反向放电比正向更易损坏 | S4 p60 |
| 电过应力 | 超过绝对最大额定的电压或电流；能量大时封装熔化 | S4 p60、p61 |
| 闩锁 | 输入、输出或电源脚上出现超过电源电压的电压或大噪声，寄生晶闸管导通，电源与地之间形成大电流，芯片失去正常功能 | S4 p63 |

## 各失效方式在电路里的后果

后果栏是该失效方式在这个位置的电路推论；原件直接写了后果的另注。

| 失效方式 | 所在位置 | 电路里的后果 | 来源 |
|---|---|---|---|
| 输出对电源或地短路 | 驱动共享总线（I2C、片选、复位线）的输出 | 整条总线被拉住，总线上其他器件一起不能工作 | S1 p63 |
| 输出卡在 0 或 1 | 控制功率开关、继电器、使能脚的输出 | 负载常开或常关；若卡在使能态，保护要靠硬件另行切断 | S1 p63 |
| 输出高阻 | 控制使能、片选的输出 | 被控输入悬空，状态取决于上下拉；没有上下拉时不确定 | S1 p63 |
| 输入对电源短路 | 接对外接口的输入 | 接口另一端的驱动器被短路；电源经该输入灌入接口 | S1 p63 |
| 电源与地短路、闩锁 | 任何芯片 | 所在电源轨短路，同一轨上的其他电路失电；闩锁电流可能把芯片烧毁 | S4 p63 |
| 地脚或电源脚开路 | 多电源脚芯片 | 芯片经输入输出脚的保护二极管取电，状态不确定，并可能向信号线反灌 | S1 p63 |
| 数据位丢失 | 存储器 | 配置、标定数据出错；按功能分析其后果 | S2 p442 |
| 单片机功能失效（程序跑飞、停止） | 承担检测或保护的单片机 | 依赖软件的保护失效；只有软件动作而没有硬件动作的保护不成立 | S1 p63 |

## 促成失效的使用条件

| 条件 | 促成的失效 | 降额（G10 编号） | 来源 |
|---|---|---|---|
| 引脚电压超过电源或低于地（对外接口上的过冲、带电插拔、多电源上电顺序） | 闩锁 | IC-OTH-VIN、IC-MOS-VCC | S4 p63 |
| 静电放电 | 栅氧击穿、结烧毁 | — | S4 p60 |
| 电压或电流超过绝对最大额定 | 电过应力 | IC-MOS-VCC、IC-MOS-IOUT | S4 p60 |
| 结温高 | 失效加速 | IC-MOS-TJ | S4 p60 |

## 设计上的应对

| 适用条件 | 做法 | 对应准则 | 来源 |
|---|---|---|---|
| 输入接到对外接口 | 用串联电阻和钳位把注入电流限制在手册允许内；判输入短路时对端的后果 | G04-007、G04-009 | S4 p63 |
| 一个输出卡死会使负载处于危险状态 | 关键输出有独立的硬件保护或看门狗把它拉回安全态；不只靠软件 | G05-013 | S1 p63 |
| 共享总线 | 判单个器件卡住总线时其他功能的后果，必要时可隔离或复位总线 | G05-007 | S1 p63 |
| 复杂芯片（单片机、处理器、可编程逻辑） | 按功能分析：输出卡 0、卡 1、高阻、功能失效，结合软件响应 | G05-002、G05-013 | S1 p63 |
| 多电源芯片 | 判单路电源开路时的状态和反灌 | G03-027、G04-009 | S1 p63 |

## 缺口

- 单片机、处理器这类复杂芯片没有按功能划分的失效比例来源。
