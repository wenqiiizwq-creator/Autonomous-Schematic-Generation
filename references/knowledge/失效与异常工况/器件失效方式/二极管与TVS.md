# 二极管与 TVS 的失效方式

类别：器件失效方式。
适用范围：整流、开关、小信号、肖特基二极管，稳压管与基准二极管，瞬态抑制二极管（TVS）和 ESD 保护阵列。LED 与光耦输入侧见 [光耦与数字隔离器](光耦与数字隔离器.md)。
对应准则：G05-004、G05-007、G05-030～G05-035（TVS 选型与失效短路）、G05-055～G05-057（反接阻断二极管）、G05-086（串联二极管防反接）、G07-031、G07-037（分级保护与重复冲击）。
相关取值步骤：[TVS取值](../../计算方法/TVS取值.md)、[浪涌分级防护协调](../../计算方法/浪涌分级防护协调.md)、[防反接](../../计算方法/防反接.md)。

## 来源

- S1：Standard/ECSS-Q-ST-30-02C 故障模式影响及危害性分析 - 2009.pdf
- S2：Standard/MIL-HDBK-338B 电子可靠性设计手册 - 1998.pdf
- S3：Book/Reliability Engineering Theory and Practice - 2017 - Birolini.pdf
- S4：Standard/IEC 60812 Ed.3.0 故障模式与影响分析 - 2018.pdf
- S5：Book/功率半导体器件 原理特性和可靠性 - 2013 - Lutz.pdf
- S6：Applicationnote/TI - 浪涌TVS二极管选型 - SLVAE37.pdf
- S7：Applicationnote/Toshiba - 半导体可靠性手册 - No-DocID.pdf

各来源的数据性质：S2 比例引自 FMD-91（1991 年），原件写成小数，照抄（.49 即 49 %）；S3 为第 3 版（1999 年）的示意性分布；S4 为示例数据；S5 是功率器件专著的中译本（2013 年），讲的是功率二极管和晶闸管的损坏机理。

## 失效方式与比例

| 细类 | 失效方式 | 比例 | 来源 |
|---|---|---|---|
| 开关、整流、稳压、基准、瞬态抑制等二极管 | 任一引脚开路；短路；任一端对结构短路 | 只列模式 | S1 p62 |
| 通用二极管 | 短路 / 开路 / 参数变化 | .49 / .36 / .15 | S2 p440 |
| 整流二极管 | 短路 / 开路 / 参数变化 | .51 / .29 / .20 | S2 p440 |
| 小信号二极管 | 参数变化 / 开路 / 短路 | .58 / .24 / .18 | S2 p441 |
| 稳压管（基准用） | 参数变化 / 开路 / 短路 | .69 / .18 / .13 | S2 p441 |
| 稳压管（稳压用） | 开路 / 参数变化 / 短路 | .45 / .35 / .20 | S2 p441 |
| 通用二极管 | 短路 / 开路 / 漂移（%） | 50 / 30 / 20 | S3 p117 |
| 稳压管 | 短路 / 开路 / 漂移（%） | 20 / 40 / 40 | S3 p117 |
| 瞬态抑制二极管（示例数据） | 短路 / 开路（%） | 95 / 5 | S4 p74 |
| 小信号二极管（示例数据） | 短路 / 开路 / 参数变化（%） | 50 / 35 / 15 | S4 p74 |

各来源一致：整流和通用二极管以短路为最多；小信号二极管和稳压管以参数变化或开路为多。TVS 只有示例数据，短路占绝大多数；G05-035 也把短路作为钳位器件的常见失效方式。

## 失效的形成

| 失效方式 | 形成过程 | 来源 |
|---|---|---|
| 短路（浪涌电流） | 正向浪涌超过手册浪涌电流，芯片局部熔融 | S5 p358、p359 |
| 短路（过电压） | 反向电压超过击穿电压，损坏点多从芯片边缘的结终端开始 | S5 p366 |
| 热击穿 | 阻断状态下漏电流随温度上升，高温区漏电更大，形成正反馈，散热跟不上时器件损坏 | S5 p358 |
| 结烧毁（静电） | 静电放电电流使结区局部过热；反向放电比正向更易损坏 | S7 p60 |

## 各失效方式在电路里的后果

后果栏是该失效方式在这个位置的电路推论；原件直接写了后果的另注。

| 失效方式 | 所在位置 | 电路里的后果 | 来源 |
|---|---|---|---|
| 短路 | TVS 或稳压管跨在电源入口 | 输入对地短路，靠上游熔断器或限流切断；原件示例写作“熔断器熔断” | S4 p74 |
| 短路 | TVS 或 ESD 器件跨在信号线上 | 信号线对地短路，该路功能失去；对外接口上表现为对端驱动器长期短路 | S1 p62 |
| 开路 | TVS 或 ESD 器件 | 平时无表现，保护悄悄失去，下一次浪涌或静电直接打到被保护器件；属于潜伏故障 | S4 p74 |
| 短路 | 串联防反接二极管 | 反接保护失去，反接时反压直接加到下游 | S2 p440 |
| 短路 | 桥式整流中的一只 | 交流半周对输入短路，熔断器动作 | S4 p74 |
| 开路 | 桥式整流中的一只 | 变成半波整流，纹波增大、输出电压下降；原件示例写作“交流供电时整流不正确” | S4 p74 |
| 短路 | 续流二极管（继电器线圈、电感负载） | 线圈两端被短路，驱动管导通即过流；对继电器表现为不吸合 | S2 p440 |
| 开路 | 续流二极管 | 关断时线圈反电动势不再被钳住，驱动管承受高压而击穿 | S2 p440 |
| 参数变化 | 稳压管或基准二极管用作基准、门限 | 基准电压漂移，门限或输出偏离 | S2 p441 |

## 促成失效的使用条件

| 条件 | 促成的失效 | 降额（G10 编号） | 来源 |
|---|---|---|---|
| 正向浪涌电流超过手册值 | 芯片熔融、短路 | DIO-GEN-SURGE、DIO-REC-SURGE、DIO-REC-I2T | S5 p359 |
| 反向电压超过额定（含瞬态尖峰） | 边缘击穿损坏 | DIO-GEN-VR-S、DIO-GEN-VR-T、DIO-REC-VR-S、DIO-REC-VR-T | S5 p366 |
| 结温高、阻断漏电大（肖特基尤甚） | 热击穿 | DIO-GEN-TJ、DIO-REC-TJ、DIO-SIC-TJ | S5 p358 |
| 浪涌电流超过 TVS 的峰值脉冲电流；高温下峰值脉冲能力明显下降；手册额定的波形与实际浪涌不同 | TVS 过热失效；原件说明 TVS 是因电流过大而不是电压过高失效 | TVS-SURGE、TVS-TJ | S6 p4 |
| 静电放电 | 结烧毁 | — | S7 p60 |

## 设计上的应对

| 适用条件 | 做法 | 对应准则 | 来源 |
|---|---|---|---|
| TVS 跨在源能力大的电源入口 | 上游有过流保护，TVS 短路时能切断，切断前不起火、不损坏相邻电路 | G05-035 | S4 p74 |
| TVS、ESD 器件开路不会被发现 | 登记为潜伏故障；需要时在测试或生产检验中覆盖 | G05-010 | S4 p74 |
| 防反接靠单只串联二极管，且反接后果严重 | 判二极管短路后的反接后果，后果不可接受时加第二级防护 | G05-054、G05-086 | S2 p440 |
| 续流二极管失效会使驱动管击穿 | 按续流二极管开路判驱动管的电压应力；必要时驱动管选能承受雪崩的型号或另加钳位 | G05-004 | S2 p440 |
| 稳压管、基准用于门限 | 按寿命期漂移核门限 | G02-008 | S2 p441 |

## 缺口

- TVS 和 ESD 阵列的失效比例只有 IEC 60812 的示例数据，没有统计来源。
