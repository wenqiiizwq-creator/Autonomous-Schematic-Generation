# 继电器与开关的失效方式

类别：器件失效方式。
适用范围：电磁继电器（含磁保持）、机械开关（拨动、按键、旋转）。固态继电器、光继电器没有找到来源，未写。
对应准则：G05-004、G05-007、G08-043（按次数耗损的器件）、G05-063（保护恢复后负载进入确定状态）。

## 来源

- S1：Standard/ECSS-Q-ST-30-02C 故障模式影响及危害性分析 - 2009.pdf
- S2：Standard/MIL-HDBK-338B 电子可靠性设计手册 - 1998.pdf
- S3：Book/Reliability Engineering Theory and Practice - 2017 - Birolini.pdf
- S4：Applicationnote/Omron - 通用继电器技术说明 - CSM_GeneralRelay_TG_E_10_6.pdf

各来源的数据性质：S2 比例引自 FMD-91（1991 年），原件写成小数，照抄（.55 即 55 %）；S3 为第 3 版（1999 年）的示意性分布；S4 是继电器厂家的技术说明。

## 失效方式与比例

| 细类 | 失效方式 | 比例 | 来源 |
|---|---|---|---|
| 非磁保持、磁保持继电器 | 卡在一个位置；线圈开路；两组触点都断开（卡在中间）；两组触点处于相反位置；固定触点之间短路；线圈与触点短路（极少）；触点与结构短路（极少） | 只列模式 | S1 p64 |
| 开关（拨动、断路器、微动、舌簧） | 开路；端间短路 | 只列模式 | S1 p66 |
| 继电器 | 该动不动 / 误动作 / 短路 | .55 / .26 / .19 | S2 p443 |
| 按键开关 | 开路 / 卡住 / 短路 | .60 / .33 / .07 | S2 p444 |
| 拨动开关 | 开路 / 卡住 / 短路 | .65 / .19 / .16 | S2 p444 |
| 旋转开关 | 输出不对 / 触点失效 | .53 / .47 | S2 p444 |
| 继电器 | 短路 / 功能（该动不动与误动作约六比四）（%） | 20 / 80 | S3 p117 |

两个来源一致：继电器以功能性失效（该动不动、误动作）为主，短路约占两成。

## 失效的形成

| 失效方式 | 形成过程 | 来源 |
|---|---|---|
| 触点粘连（不释放） | 大电流流过触点：灯负载等的浪涌电流、负载短路电流；触点抖动（外部振动冲击、交流继电器嗡鸣、电压跌落造成的吸合不良）；开关过于频繁 | S4 p25 |
| 触点接触不良 | 微小负载下触点表面有异物或不导电膜（灰尘、油、有机气体、焊剂、指纹）；普通银触点易硫化，硫化膜影响大 | S4 p23 |
| 触点腐蚀 | 开关负载产生的电弧使空气中氮、氧生成硝酸，腐蚀金属 | S4 p23 |
| 不吸合 | 线圈电压不足、线圈规格不对、电压纹波、输入电压上升过慢；线圈断线 | S4 p25 |
| 不释放 | 线圈电压没有完全断开（保护电路漏电、残压）；触点粘连；长线感应电压 | S4 p25 |
| 线圈烧毁、触点烧损 | 触点电流超过额定、浪涌电流超限、短路电流；外部连接不良发热 | S4 p25 |
| 线圈绝缘老化 | 寿命随线圈温度缩短；原件给出常用聚氨酯漆包线以 120°C 下 40000 小时为参考 | S4 p26 |

## 各失效方式在电路里的后果

后果栏是该失效方式在这个位置的电路推论；原件直接写了后果的另注。

| 失效方式 | 所在位置 | 电路里的后果 | 来源 |
|---|---|---|---|
| 触点粘连 | 切断负载或电源的继电器 | 负载不能断开；依赖它切断的保护或安全状态失去 | S4 p25 |
| 触点接触不良 | 切换小信号、采样回路的继电器 | 间歇断开或接触电阻增大，测量出错 | S4 p23 |
| 不吸合 | 接通负载的继电器 | 负载不能接通 | S4 p25 |
| 两组触点相反或卡在中间 | 转换型继电器 | 两路同时接通或同时断开；切换两个电源时可能把两电源并在一起 | S1 p64 |
| 线圈开路 | 任何继电器 | 回到释放态；对磁保持继电器则停在原态 | S1 p64 |
| 开关卡住、短路 | 操作开关、使能开关 | 操作失效或常通 | S2 p444 |

## 促成失效的使用条件

| 条件 | 促成的失效 | 降额（G10 编号） | 来源 |
|---|---|---|---|
| 灯、电容、电机等浪涌负载 | 触点粘连 | RLY-LAMP、RLY-M、RLY-C | S4 p25 |
| 感性负载断开的电弧 | 触点烧损、腐蚀 | RLY-L、RLY-L-R | S4 p23 |
| 触点电流低于最小可靠电流的微小负载 | 接触不良 | RLY-CONTACT-IMIN | S4 p23 |
| 含硫、有机气体、灰尘环境 | 接触不良 | — | S4 p23 |
| 线圈电压低于吸合值、纹波大 | 吸合不良、触点抖动 | RLY-COIL-MIN、RLY-PICKUP | S4 p25 |
| 线圈温度高 | 线圈绝缘老化 | RLY-T、RLY-COIL-MAX | S4 p26 |
| 振动、冲击 | 触点抖动、误动作 | RLY-VIB | S4 p25 |
| 动作次数多 | 触点耗损到寿命 | RLY-LIFE | S4 p26 |

## 设计上的应对

| 适用条件 | 做法 | 对应准则 | 来源 |
|---|---|---|---|
| 继电器断开是安全动作 | 判触点粘连后的后果；后果严重时串第二个独立的断开元件 | G05-004、G05-006 | S4 p25 |
| 切换浪涌负载 | 按浪涌电流选触点额定，或加限流 | G05-004 | S4 p25 |
| 感性负载 | 加灭弧或吸收电路，减少电弧 | — | S4 p23 |
| 线圈驱动 | 线圈电压在吸合与上限之间；保护元件的漏电不使继电器不释放 | — | S4 p25 |
| 按动作次数耗损 | 寿命内动作次数不超过额定 | G08-043 | S4 p26 |
| 转换型继电器切换两路电源 | 判触点卡在中间或相反位置时两路是否会并接 | G05-007 | S1 p64 |

## 缺口

- 固态继电器、光继电器的失效方式没有来源。
- 机械开关只有 FMD-91 的比例，没有失效机理的厂家资料。
