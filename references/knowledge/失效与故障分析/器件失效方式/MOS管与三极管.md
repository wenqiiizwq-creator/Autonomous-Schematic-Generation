# MOS 管与三极管的失效方式

类别：器件失效方式。
适用范围：分立功率 MOSFET、小信号 MOSFET、双极型三极管；IGBT 只在机理部分涉及。集成在芯片里的开关见 [集成稳压器与电源芯片](集成稳压器与电源芯片.md)。
对应准则：G05-004、G05-007、G05-028、G05-029（通路开关耗散性失效）、G05-040～G05-043（短路与热短路的 SOA）、G05-087～G05-089（MOSFET 防反接）、G03-016（启动时的 SOA）。

## 来源

- S1：Standard/ECSS-Q-ST-30-02C 故障模式影响及危害性分析 - 2009.pdf
- S2：Standard/MIL-HDBK-338B 电子可靠性设计手册 - 1998.pdf
- S3：Book/Reliability Engineering Theory and Practice - 2017 - Birolini.pdf
- S4：Standard/ECSS-E-HB-20-20A 电源电气设计与接口要求指南 - 2016.pdf
- S5：Book/功率半导体器件 原理特性和可靠性 - 2013 - Lutz.pdf
- S6：Applicationnote/Toshiba - 半导体可靠性手册 - No-DocID.pdf

各来源的数据性质：S2 比例引自 FMD-91（1991 年），原件写成小数，照抄（.51 即 51 %）；S3 为第 3 版（1999 年）的示意性分布；S4 是空间电源设计手册，耗散性失效一节针对限流开关（LCL）里的 MOSFET。

## 失效方式与比例

| 细类 | 失效方式 | 比例 | 来源 |
|---|---|---|---|
| 三极管、N 沟道和 P 沟道场效应管 | 任一端开路；任两端短路 | 只列模式 | S1 p65 |
| 双极型三极管 | 短路 / 开路 | .73 / .27 | S2 p445 |
| 场效应管 | 短路 / 输出低 / 参数变化 / 开路 / 输出高 | .51 / .22 / .17 / .05 / .05 | S2 p445 |
| 双极型三极管 | 短路 / 开路（%） | 75 / 25 | S3 p117 |
| 场效应管 | 短路 / 开路 / 漂移 / 功能（%） | 60 / 10 / 10 / 20 | S3 p117 |

各来源一致：以短路为主。S1 另要求：场效应管凡是会造成耗散超过额定的失效都要分析其热传播（S1 p65）。

## 失效的形成

| 失效方式 | 形成过程 | 来源 |
|---|---|---|
| 漏源短路（雪崩） | 雪崩击穿中温度升到本征温度附近即损坏；原件给出常用 60V MOSFET 约在 320°C 损坏 | S5 p358 |
| 热击穿 | 漏电流随温度升高而增大，局部更热，正反馈，散热跟不上即损坏 | S5 p358 |
| 过电压损坏 | 损坏点多从芯片边缘的结终端开始 | S5 p366 |
| 阻断状态下的突发失效（宇宙射线） | 高压器件长期承受高直流电压时，宇宙射线中子引起的突发失效，事前漏电流没有征兆 | S5 p393 |
| 栅氧击穿 | 栅氧化层击穿场强一般为 8 到 10 MV/cm，薄栅氧在数十伏即击穿；静电、栅压尖峰是常见起因 | S6 p60 |
| 电过应力 | 电压或电流超过绝对最大额定，芯片熔融，能量大时封装变色或熔化 | S6 p60、p61 |

## 各失效方式在电路里的后果

后果栏是该失效方式在这个位置的电路推论；原件直接写了后果的另注。

| 失效方式 | 所在位置 | 电路里的后果 | 来源 |
|---|---|---|---|
| 漏源短路 | 通路开关（负载开关、热插拔、eFuse 外置管） | 开关不能关断，限流和过流保护失效；下游失去保护，浪涌和过压直接到负载 | S1 p65 |
| 漏栅短路（耗散性失效） | 通路开关 | 管子工作在线性区，压降约为阈值电压加上电流与跨导之比，耗散功率随负载电流增大，几安电流下即可形成局部热点 | S4 p57、p58 |
| 栅极开路 | 通路开关 | 原件指出这是比漏栅短路更严重的耗散情形，管压降可能升到阈值电压的两倍以上，建议向厂家确认 | S4 p58 |
| 漏源短路 | 开关变换器的上管或下管 | 上下管直通或输入对地短路；同步整流管短路时输出被拉低 | S1 p65 |
| 漏源短路 | 防反接 MOSFET | 反接保护失去 | S1 p65 |
| 开路 | 通路开关 | 下游断电 | S1 p65 |
| 栅源短路 | 任何开关管 | 管子不能导通；栅驱动输出被短路，驱动芯片可能过流 | S1 p65 |
| 集电极发射极短路 | 继电器、指示灯等的驱动三极管 | 负载常通，不能关断 | S2 p445 |
| 参数变化（阈值、漏电） | 小信号开关、模拟开关用法 | 门限漂移、关断漏电增大 | S2 p445 |

## 促成失效的使用条件

| 条件 | 促成的失效 | 降额（G10 编号） | 来源 |
|---|---|---|---|
| 漏源电压超过额定（含关断尖峰），雪崩能量超过额定 | 雪崩损坏、边缘击穿 | MOS-VDS-S、MOS-VDS-T | S5 p358、p366 |
| 栅源电压超过额定（尖峰、静电） | 栅氧击穿 | MOS-VGS-S、MOS-VGS-T | S6 p60 |
| 线性区工作（启动、限流、短路）超出 SOA | 热击穿、短路 | MOS-P、MOS-TJ | S5 p358 |
| 高压器件长期承受接近额定的直流电压 | 宇宙射线引起的突发失效；降低工作电压可降低这类失效 | MOS-VDS-S | S5 p396 |
| 电流超过脉冲额定 | 电过应力 | MOS-ID、MOS-IDM | S6 p60 |

## 设计上的应对

| 适用条件 | 做法 | 对应准则 | 来源 |
|---|---|---|---|
| 通路开关可能漏源短路 | 判限流失效后上下游的后果；后果严重时串第二级保护（例如熔断器） | G05-028 | S1 p65 |
| 通路开关可能耗散性失效 | 按漏栅短路估算耗散，核周围器件仍在额定内；没有其他手段切断的登记为风险 | G05-029 | S4 p57、p58 |
| 管子在启动、限流、短路时进入线性区 | 按降额后的 SOA 核每种情形 | G03-016、G05-040、G05-041 | S5 p358 |
| 栅极可能受静电或尖峰 | 栅源间有钳位，栅驱动的过冲在额定内 | G05-004 | S6 p60 |
| 高压开关管长期偏置在高直流电压 | 留出电压余量 | G05-004 | S5 p396 |

## 缺口

- 分立功率 MOSFET 的失效比例只有 FMD-91（1991 年）和 Birolini 第 3 版，没有近年的统计。
- 三极管的二次击穿等机理没有找到中文或厂家来源，未写。
