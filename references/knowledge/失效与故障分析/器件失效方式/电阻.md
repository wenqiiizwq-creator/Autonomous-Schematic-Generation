# 电阻的失效方式

类别：器件失效方式。
适用范围：固定电阻（片式厚膜、薄膜、金属膜、碳膜、线绕、电阻网络）、可变电阻、热敏电阻。压敏电阻见 [压敏电阻与气体放电管](压敏电阻与气体放电管.md)。
对应准则：G05-004（列出故障模式）、G05-007（故障传播）、G06-018（跨安全边界的电阻）、G04-074（端接电阻承受总线短路）、G08-010（凝露与高阻节点）。

## 来源

- S1：Standard/ECSS-Q-ST-30-02C 故障模式影响及危害性分析 - 2009.pdf
- S2：Standard/MIL-HDBK-338B 电子可靠性设计手册 - 1998.pdf
- S3：Book/Reliability Engineering Theory and Practice - 2017 - Birolini.pdf
- S4：Standard/IEC 60812 Ed.3.0 故障模式与影响分析 - 2018.pdf
- S5：Book/硬件十万个为什么 无源器件篇 - 2024 - 朱晓明.pdf

各来源的数据性质：

- S1 附录 G 表 G-1 是资料性的器件故障模式清单（空间环境），只列模式，不给比例。
- S2 表 7.8-1 的比例引自可靠性分析中心《Failure Mode/Mechanism Distributions》（FMD-91，1991 年）（S2 p439 脚注）。原件把比例写成小数，下表照抄原件写法（.59 即 59 %）。
- S3 文件名标 2017，原件实为第 3 版（1999 年）；表 3.5 是“示意性分布”，作者说明要用自己的试验和现场数据补充（S3 p118）。
- S4 表 F.12 是 FMEDA 示例，原件注明失效率与分布数据库是“某公司的示例”。
- S5 的比例是统计值，作者注明只作参考，随使用场景、环境和采购来源变化（S5 p48）。

## 失效方式与比例

| 细类 | 失效方式 | 比例 | 来源 |
|---|---|---|---|
| 金属氧化膜、合成、分流器、金属膜、电阻网络、片式 | 开路 | 只列模式 | S1 p64 |
| 片式电阻 1206 及更大 | 原件认为不会短路 | 只列模式 | S1 p64 |
| 电阻网络（膜式） | 公共端开路要单独考虑 | 只列模式 | S1 p64 |
| 线绕（精密、底盘安装） | 开路；端间短路（极少） | 只列模式 | S1 p64 |
| 可变电阻（微调） | 开路；端间短路 | 只列模式 | S1 p64 |
| 热敏电阻 | 开路；端间短路；测量值错误 | 只列模式 | S1 p64 |
| 合成电阻 | 参数变化 / 开路 / 短路 | .66 / .31 / .03 | S2 p444 |
| 膜式电阻 | 开路 / 参数变化 / 短路 | .59 / .36 / .05 | S2 p444 |
| 线绕电阻 | 开路 / 参数变化 / 短路 | .65 / .26 / .09 | S2 p444 |
| 电阻网络 | 开路 / 短路 | .92 / .08 | S2 p444 |
| 可变电阻 | 开路 / 输出不稳 / 短路 | .53 / .40 / .07 | S2 p444 |
| 固定电阻 | 短路 / 开路 / 漂移（%） | ≈0 / 60 / 40 | S3 p117 |
| 可变电阻 | 短路 / 开路 / 漂移 / 局部磨损（%） | ≈0 / 30 / 30 / 40 | S3 p117 |
| 片式电阻（示例数据） | 短路 / 开路 / 参数变化（%） | 5 / 65 / 30 | S4 p74 |
| 线绕电阻 | 开路 / 阻值漂移超规范 / 引线断裂 / 其他（%） | 90 / 2 / 7 / 1 | S5 p48 |
| 非线绕电阻 | 开路 / 阻值漂移超规范 / 引线断裂 / 其他（%） | 49 / 22 / 17 / 12 | S5 p49 |

各来源一致的是：开路和阻值漂移占绝大多数，短路很少。短路比例各来源不一：S3 记作约为零，S2 为 3 %～9 %，S4 示例为 5 %。

## 各失效方式在电路里的后果

后果栏是该失效方式在这个位置的电路推论；原件直接写了后果的另注。

| 失效方式 | 所在位置 | 电路里的后果 | 来源 |
|---|---|---|---|
| 开路 | 串在电源支路里的限流或采样电阻 | 支路断电；电流检测读为零，依赖它的过流保护失去作用 | S1 p64 |
| 开路 | 分压器上臂 | 中点被下臂拉到地：反馈分压上臂开路时，稳压器以为输出偏低而把输出推高 | S1 p64 |
| 开路 | 分压器下臂 | 中点升到上端电压：被监测的电压读高，可能误触发过压保护，或把超过输入额定的电压送到下游输入脚 | S1 p64 |
| 开路 | 上拉或下拉电阻 | 输入悬空，状态不定；复位、使能、启动配置脚悬空时上电状态不确定 | S1 p64 |
| 开路 | 电阻网络的公共端 | 网络里所有电阻同时失去作用，一次影响多路信号 | S1 p64 |
| 短路 | 与信号串联的限流电阻 | 对端直接连通，限流失效；隔离或保护靠这只电阻的，故障会传到对端 | S2 p444 |
| 短路 | 分压器上臂 | 中点等于上端电压，同上臂开路相反的方向出错 | S2 p444 |
| 阻值漂移 | 分压、基准、检流、增益设定 | 门限、输出电压或增益偏离；漂移是渐进的，常在寿命后期或特定环境下才出现 | S5 p48、p49 |
| 阻值增大直至开路（硫化） | 含银电极的厚膜片式电阻，用在含硫环境 | 阻值慢慢变大最后开路；原件有输入欠压检测电阻硫化后误触发欠压保护、电源反复重启的案例 | S5 p50、p53 |

## 促成失效的使用条件

| 条件 | 促成的失效 | 降额（G10 编号） | 来源 |
|---|---|---|---|
| 电负荷高、温升高 | 老化加速、阻值漂移；温度每升 10 ℃ 寿命约减半 | RES-*-P、RES-*-T | S5 p49 |
| 直流负荷加潮湿 | 电解作用使高阻薄膜电阻阻值增大甚至开路 | — | S5 p49 |
| 空气中含硫（化工厂、汽车尾气、温泉附近） | 厚膜片式电阻面电极硫化，阻值增大至开路 | — | S5 p50、p51 |
| 电压超过最大工作电压 | 内部绝缘击穿；即使功率未超额定也会损坏 | RES-*-V | S5 p61 |
| 浪涌、静电 | 电阻体损伤，最坏时损坏电阻后端的芯片 | RES-FILM-PULSE、RES-WW-PULSE | S5 p61 |
| 机械应力、焊接缺陷 | 基体断裂、引线帽脱落、引线断裂 | — | S5 p48、p50 |

## 设计上的应对

| 适用条件 | 做法 | 对应准则 | 来源 |
|---|---|---|---|
| 电阻开路会使分压中点走向危险的一端（例如反馈上臂开路使输出升高） | 按开路后中点的去向判后果；后果不可接受时，加独立的过压保护，或换成开路后走向安全一端的接法 | G05-004、G05-007 | S1 p64 |
| 串联电阻承担隔离、限流或安全阻抗作用，短路后后果严重 | 用多只电阻串联，单只短路后其余仍满足要求；跨安全边界的按保护阻抗核 | G06-018 | S2 p444 |
| 含硫环境 | 选抗硫化电阻（电极不用银或有防护） | G08-010 | S5 p51 |
| 电阻承受浪涌或静电 | 选抗浪涌型或加大尺寸，使电极间距变大、电位梯度变缓 | G07-032 | S5 p61 |
| 上拉、下拉决定上电状态 | 判这只电阻开路后的输入状态，必要时让芯片内部默认状态与外部电阻同向 | G04-010 | S1 p64 |

## 缺口

- 抗硫化电阻的判据（多高的硫浓度要选抗硫化型）没有原件给出数值。
