# 无线与射频端口

类别：需求要素（模式）。

适用范围：板上有 Wi-Fi、蓝牙低功耗或两者合一的 2.4 GHz 无线功能，无论用认证模块还是用带射频的芯片自己做；包括它的天线口（板载天线、外接天线座）。不含蜂窝、Sub-1 GHz、5 GHz、毫米波、GNSS、NFC，这些没有资料，没写。无线部分的供电和功耗属板内负载，通用的问法见 [板内负载](../全板/板内负载.md)，这里只补无线特有的。实现电路见 [wireless-module](../../典型电路/总线与接口/wireless-module.md)；射频线宽、匹配与净空的取值见 [射频匹配网络与天线净空](../../计算方法/总线与接口/射频匹配网络与天线净空.md)。

## 缺了会怎样

- **目的市场与认证没给**：不知道能不能用现成的认证模块，等到整机送测时才发现要改天线或改发射功率，板子要重做。
- **天线形式与外壳没给**：净空区、板边位置、外接座都定不下来；塑料外壳还会让天线失谐，匹配要重调。
- **发射功率与占空比没给**：峰值电流和去耦定不下来，电池供电时发射瞬间可能使模块复位。
- **同时工作的无线没给**：天线间距和隔离做不出来，Wi-Fi 与另一路 2.4 GHz 互相压制接收灵敏度。
- **天线口能否被触及没给**：静电防护器件要不要加说不清；加了又因电容过大把匹配带偏。
- **下载与产线射频测试方式没给**：可能漏留 UART 下载口，产线上无法做射频测试和频偏校准。
