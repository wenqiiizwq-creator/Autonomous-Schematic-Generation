# 知识包

由硬件设计知识框架发布的固定包，版本和逐文件哈希见技能根目录的 `knowledge-release.json`。不要在这里改条目：改在知识框架里，重新发布后安装。

| 目录 | 回答什么 | 设计层次 |
|---|---|---|
| `需求要素/` | 需求里必须给定哪些条件，缺了哪一条什么定不下来 | 把设计问题定准 |
| `板级架构模式/` | 电源树、电压域、隔离、接地、保护分层、复位时钟、冗余、测试接入有哪几种做法，各适用于什么条件 | 整板结构 |
| `接口约定/` | 块与块之间要交代哪些参数；总线和电平的电气约定；环境与电磁等级 | 整板结构、全板配合 |
| `典型电路/` | 一个功能有几种实现方案、各自的适用条件、必需外围、必算项、已知坑 | 功能电路选择 |
| `计算方法/` | 一类电路的元件值按什么顺序定、每一步的式子、输入取哪一端、算完要满足哪条准则 | 电路实现 |
| `器件参数/` | 器件手册的保证值和页码 | 电路实现 |
| `失效与异常工况/` | 器件怎样失效；故障模式分析、故障树、共因失效怎么做 | 异常工况 |

`条目总表.md` 列出全部条目；`准则支撑表.md` 列出每条准则由哪些条目支撑，可以从准则编号反查条目；`原件勘误.md` 列出原件里的错误和文字层单位有问题的原件。

条目里的来源路径相对知识库的 `HardwareWiki/raw/`，条目里指向 `设计准则/` 的链接在包内无效：准则正文和取值在技能的 `references/shared/`。
