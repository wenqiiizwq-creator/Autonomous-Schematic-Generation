# 电源轨测量断点

功能：在转换器或稳压器与负载之间串一个可拆的元件（0 Ω 电阻、跳线、磁珠、串联电感），调试时断开它，分段上电、测电流、找短路；断开时转换器不因失去反馈而升压，使能脚不悬空。

适用范围：板上有两级以上电源或多个负载域、G09-007 要求设断点的轨；串联件承载该轨的全部负载电流。分段上电的步骤和断点放在哪几条轨，见 [测试接入与可测试性](../../板级架构模式/测试接入与可测试性.md) 做法 C。

电路类型：POWER_CONVERTER

## 断点开路时的两类故障

### 反馈丢失，输出升高

- 反馈断开时，占空比向最大值增加，输出电压接近输入电压，可能烧坏负载（S1 p15）。
- 降压变换器的输出最多升到输入电压；最小关断时间使最高输出略低于输入（S3 p13）。所以反馈丢失时下游看到的是“接近输入电压”，下游器件和电容的耐压要按这个值核，否则判不成立（G09-008）。
- 有的器件自带保护，行为各不相同：例 1，反馈脚悬空时器件关断（S1 p15）；例 2，反馈脚开路时器件在输出检测脚上把输出钳在约 7.4 V（S2 p13），这个值高于多数低压负载的耐压，仍要核；例 3，没有内建保护的器件，手册给出用齐纳二极管加限流电阻把输出钳住的接法（S3 p13）。
- 过压保护比较器若接在反馈脚上（S1 p15 的做法），反馈断开时过压保护也一起失效。所以“器件有输出过压保护”不能代替对反馈位置的检查，要看保护取样接在哪里。

### 使能脚悬空

- 0 Ω 电阻或跳线串在使能线上，断开后使能脚悬空。例：使能脚必须由外部设成高或低；片内约 400 kΩ 下拉只在使能先被拉低、之后悬空时保持低电平，使能为高时这个下拉断开（S2 p8）。所以先高后断开时，状态手册没有保证。
- 原件不一致：同一手册的引脚表注释写“脚悬空时片内下拉保持低电平”（S2 p3），与特性说明（S2 p8）的“只在先为低时”不一致。按更严的 p8 理解：不依赖片内下拉。

## 选方案时比较的量

| 方案 | 断开时反馈 | 断开时下游 | 闭合时多出的东西 | 来源 |
|---|---|---|---|---|
| A 断点在反馈取样点之后 | 不受影响，转换器空载工作 | 失电 | 串联件压降，例：0 Ω 电阻不大于 20 mΩ | S4 p2 |
| B 取样在负载端，加本地保底反馈 | 保底支路接管，输出偏高一点 | 失电 | 负载端精度略受保底支路影响 | S1 p15 |
| C 取样在负载端，靠器件的反馈开路保护 | 器件关断或钳位 | 失电，或按钳位值承压 | 无 | S1 p15；S2 p13 |
| D 断点在电感或磁珠位 | 电感断开时转换器无输出；磁珠在取样点之后同 A | 失电 | 磁珠直流电阻压降，例：上限 0.15 Ω | S5 p1 |

## 实现方案

### A 断点放在反馈取样点之后（首选）

- **适用范围**：负载端电压精度允许“取样点到负载”之间多一个串联件的压降；转换器手册允许空载或轻载运行（例：S1 p15 说明该器件空载也能正常工作，进入突发模式）。多数数字负载、负载点电源用这种。
- **核心器件类**：22 电阻（0 Ω 跳线电阻）、27 连接器（跳线排针）、21 铁氧体磁珠
- **必需外围**：
  - 反馈分压的上端接在转换器输出电容处、断点的上游
  - 断点下游留一个接入点，断开时可接电流表（S6 p8）
- **必算项**：
  - 串联件电流额定：按该轨最大电流和过流保护动作点上限核（G05-022），降额按 G10。例：0 Ω 电阻按尺寸有最大电流，0402 为 1.5 A、0603 为 2.0 A、0805 为 2.5 A（S4 p2）；磁珠的额定电流按温升定义（S5 p1）
  - 串联件压降：最大电流乘最大电阻，计入负载端的电压预算（G03-001 的峰值电流）
  - 空载：转换器在断点断开、只剩反馈分压和输出电容作负载时的行为，按手册的最小负载要求核
- **落实规则**：G09-007、G09-008、G05-022
- **已知坑**：
  - 运行中断开断点会让下游掉电再上电（S6 p29）；测电流时电流表要在上电前接好
  - 断点下游若还从别的路径（另一电源、信号线、调试口）得电，断开后测的不是这一段的电流，还可能倒灌（S6 p18）；按 G04-009、G03-031 核
- **来源**：S1 p15；S4 p2；S5 p1；S6 p8、p18、p29

### B 取样在负载端，加本地保底反馈

- **适用范围**：负载端电压精度要求高、要把串联件和走线压降包在环内（远端取样），又要设断点。
- **核心器件类**：22 电阻
- **必需外围**：
  - 反馈分压上端经一只小电阻接负载端（主取样），另经一只阻值大得多的电阻接转换器输出电容处（保底取样）。断点闭合时主取样决定输出；断点断开时保底电阻接管，输出只比设定值高一些，而不是升到接近输入（S1 p15 给出断开反馈的后果）
- **必算项**：
  - 断点断开时由保底支路决定的输出电压，按分压式和保底电阻算；该值不超过断点上游电容和转换器输出脚的额定
  - 断点闭合时保底支路对负载端精度的影响
- **落实规则**：G09-008
- **已知坑**：
  - 这种接法没有找到厂家资料，是由“反馈断开后输出升到接近输入”（S1 p15；S3 p13）推出的工程做法；阻值比例要逐个算，不能套用
- **来源**：S1 p15；S3 p13（后果）；接法本身为工程推论

### C 取样在负载端，靠器件的反馈开路保护

- **适用范围**：所用转换器手册明确写了反馈开路时的行为，且这个行为对下游安全：关断（S1 p15），或钳位值低于下游耐压（S2 p13）。
- **核心器件类**：08 带反馈开路保护的转换器
- **必需外围**：无额外元件
- **必算项**：
  - 手册给的钳位值对下游器件和电容耐压（例：钳在约 7.4 V，S2 p13）
  - 器件“关断”后是锁定还是自动重试；断点重新闭合后能否自己恢复
- **落实规则**：G09-008
- **已知坑**：
  - 过压保护若取自反馈脚，反馈断开后不起作用（S1 p15）；要看手册写的是“反馈开路保护”还是“输出过压保护”
- **来源**：S1 p15；S2 p13

### D 断点放在电感或磁珠位

- **适用范围**：不想多加元件，用已有的串联电感或磁珠作断点（`g09_break_scope` 允许）。拆下降压变换器的电感，开关节点与输出断开，输出没有能量来源，下游失电；磁珠在反馈取样点之后时同方案 A。
- **核心器件类**：21 功率电感、21 铁氧体磁珠
- **必需外围**：磁珠下游留接入点
- **必算项**：
  - 磁珠额定电流与直流电阻：例：额定电流 1500 mA（温升 20 K）、2000 mA（温升 40 K），直流电阻上限 0.15 Ω（S5 p1）；直流电阻上的压降计入预算
  - 磁珠在取样点之前时，断开磁珠等于断开反馈，按方案 B 或 C 处理
- **落实规则**：G09-007
- **已知坑**：
  - 手册写明不要超过额定电流使用，否则过热损坏元件（S5 p1）
- **来源**：S5 p1

### 使能线上的断点

- **适用范围**：为了单独关断某一路而在使能线上串 0 Ω 电阻或跳线时。
- **必需外围**：在转换器一侧（断点下游、靠近使能脚）放一只确定电平的上拉或下拉，断点断开时使能落到预定状态（通常是关断）；不依赖片内下拉（S2 p8）
- **必算项**：断点闭合时，上下拉与驱动源的分压仍满足使能门限（G04-003）
- **落实规则**：G09-008、G04-102
- **来源**：S2 p3、p8

## 断点放在取样点之前还是之后

| 情形 | 放法 | 判据 | 来源 |
|---|---|---|---|
| 负载端精度允许串联件压降，转换器可空载 | 取样点之后（方案 A） | 串联件压降：例 0 Ω 电阻不大于 20 mΩ | S4 p2 |
| 必须远端取样 | 取样点之前，必须有保底反馈（方案 B）或器件反馈开路保护（方案 C） | 反馈断开后输出接近输入，下游按此承压或另设保底 | S1 p15 |
| 器件手册写了反馈开路钳位 | 可以放在取样点之前 | 钳位值（例约 7.4 V）不超过下游额定 | S2 p13 |
| 手册没写反馈开路行为 | 不放在取样点之前 | 资料不足，按“输出接近输入”估计 | S3 p13 |

## 原件问题

- S2 引脚表注释（p3）说使能脚悬空时片内下拉保持低电平；特性说明（p8）说这个下拉只在使能先为低时起作用，使能为高时断开。两处不一致，按 p8 写。
