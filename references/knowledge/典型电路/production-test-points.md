# 生产测试点与编程焊盘

功能：让固件烧录、校准和测试在生产线可接触。

适用范围：带可配置控制器/MCU 的板子。测试接入的做法见 [测试接入与可测试性](../板级架构模式/测试接入与可测试性.md)，调试口见 [swd-debug](swd-debug.md)。

电路类型：无

## 来源清单

- S1：Designexample/USB-PD/NCP1343PD100WGEVB

页码是 PDF 文件页序。

## 实现方案

### 裸焊盘测试点

- **适用范围**：需要编程/校准接口
- **核心器件类**：27 连接器（测试_探测）或裸焊盘
- **必需外围**：无；位置和探针交 PCB
- **必算项**：
  - 无电气计算；列出每个测试点的信号与用途
  - 依赖校准/选配的功能、位号、对应测试点、校准方法与残差验收限值，列作交生产测试的下游约束
- **落实规则**：G02-018
- **已知坑**：
  - 测试点要在设计网表和分页方案里有归属，不能作为"其他"
- **来源**：
  - S1（编程接口）
