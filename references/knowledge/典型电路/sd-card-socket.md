# SD 与 microSD 卡座

功能：把 SD 或 microSD 存储卡接到主控：选 SD 总线方式（4 位或 1 位）或 SPI 方式，给命令线和数据线加上拉，接卡检测与写保护开关，给卡座单独供电并能断电重上电，限制插卡时的冲击电流和电压跌落，在卡座端加静电防护。

适用范围：3.3 V 信号的默认速度、高速模式，以及 1.8 V 信号的高速模式（需要信号电压切换或电平转换）；主控是带 SD 主机控制器的单片机、处理器，或只有 SPI 的单片机。SD 协会物理层规范里的时序与电气限值本条没有引用（见“没有引用的资料”）。片上 NOR Flash 与 EEPROM 见 [spi-flash-eeprom](spi-flash-eeprom.md)；电平转换的一般做法见 [level-translation](level-translation.md)；负载开关见 [discrete-load-switch](discrete-load-switch.md)。SD 总线的电气约定见 [SD卡](../接口约定/总线与电平/SD卡.md)。

电路类型：STORAGE、SPI

## 选方案时比较的量

下表的数是所引代表器件或参考设计的值，用来说明量级，不是这一类器件的通用上下限。

| 方案 | 代表值 | 来源 |
|---|---|---|
| SD 总线方式，带电平转换器 | 两侧电压 1.1～3.6 V；时钟到 60 MHz，每条数据线到 60 Mbps | S3 p19 |
| SD 总线方式，带电平转换器 | 命令线和数据线两侧各有 40 kΩ 内部上拉；卡检测脚内部 100 kΩ（±30%）上拉 | S3 p3 |
| 卡座端静电防护阵列 | 接触放电 ±8 kV、空气放电 ±15 kV（IEC 61000-4-2 第 4 级）；每路电容典型 1.5 pF | S4 p1 |
| 卡座供电开关 | 输入 1.6～5.5 V，连续 1.5 A；导通电阻 90 mΩ；慢速开启以限冲击电流 | S5 p1 |
| SD 总线走线（参考设计的布局要求） | 命令与数据线长度与时钟线相差在 ±50 mil 内；单端阻抗 50 Ω ±10%；总长最好在 2000 mil 以内 | S2 p31 |

经验上的分界（条件，不是定值）：

- 主控有 SD 主机控制器：用 SD 总线方式，4 位数据线；只用 1 位时空出 DAT1、DAT2 可作他用（S1 p23）。
- 主控只有 SPI：SPI 方式，只占时钟、命令（数据进）、DAT0（数据出）和 DAT3（片选）四根线（S1 p23 说明卡可以用 SPI 方式访问；具体的线对应关系以 SD 规范为准）。
- 主控 I/O 电压与卡的信号电压不同（例如主控只有 1.8 V I/O，卡侧 2.9～3.3 V）：加 SD 专用电平转换器（S3 p19）。
- 主控 I/O 电源可在 3.3 V 和 1.8 V 之间切换：由电源芯片切换 SD 那一组 I/O 的电源（代表设计由电源管理芯片的电压切换输出供给，S6 p44）。

## 实现方案

### SD 总线方式直连主控（3.3 V 信号）

- **适用范围**：主控带 SD 主机控制器、I/O 电压与卡一致。4 位数据总线加时钟和命令线（S1 p23）。
- **核心器件类**：27 连接器（SD/microSD 卡座，带卡检测开关）、22 电阻（上拉）、28 TVS_ESD保护器件、08 负载开关与高低侧驱动、20 MLCC多层陶瓷电容
- **必需外围**：
  - 命令线和数据线上拉：保证 I/O 状态未定时线上电平安全，并且部分 SD 信号兼作方式选择（SPI 方式、1 位方式），上电时电平不能不定（S1 p23）；主控作主机时在用到的引脚上加上拉（S2 p20）
  - 时钟线保持有效电平；参考设计留了时钟下拉的位置（S1 p23）
  - 卡检测：卡座的检测开关接主控输入并上拉（S3 p21 的参考接法）
  - 卡座电源去耦，靠近卡座（S3 p21 的参考接法为 0.1 µF）
  - 卡座端的静电防护阵列（见后面的静电防护方案）
- **必算项**：
  - 上拉不能与卡内或外部的下拉形成电平不够的分压（见下一方案的电平核算）（S3 p20）
  - 与主控的启动配置脚冲突：主控的 SD 引脚中有启动配置脚时，上拉会改变启动方式，要按主控手册核（S2 p20）
  - 布局约束交下游：长度匹配、50 Ω 阻抗、走线尽量短、时钟线包地、不换层（S2 p31）
- **落实规则**：G04-003、G04-010、G04-014、G04-102
- **已知坑**：
  - 只靠主控内部上下拉时，主控复位或引脚未配置期间线上状态不定；要么外加上拉，要么确认主控复位态的内部上拉已使能（S1 p23）
  - 时钟线的寄生电容要小，参考设计要求时钟线两侧包地（S2 p31）
- **来源**：S1 p23；S2 p20、p31；S3 p20–21

### SPI 方式（只有 SPI 的主控）

- **适用范围**：主控没有 SD 主机控制器，用 SPI 读写卡（S1 p23）。速度低于 SD 总线方式，但只占四根线。
- **核心器件类**：同上；主控 SPI 外设
- **必需外围**：
  - 片选、命令（主出）、数据输出（主入）、时钟四根线；不用的 DAT1、DAT2 加上拉，保持确定电平（S1 p23）
  - 卡检测、静电防护、供电开关同上
- **必算项**：
  - 卡上电时进入哪种方式由 SD 规范规定的信号状态决定；SPI 方式下片选与数据线的上拉必须在卡上电前就有效（S1 p23 指出部分信号兼作方式选择）
  - 主控 SPI 引脚的输出电平按卡的输入门限核（G04-003）
- **落实规则**：G04-003、G04-010
- **已知坑**：
  - 1 位或 SPI 方式下把 DAT1、DAT2 挪作他用时，若该线接了 SD 用的上拉，复用的功能要能接受这个上拉（S1 p23）
- **来源**：S1 p23

### 带电平转换器（主控 I/O 电压与卡侧不同）

- **适用范围**：主控 I/O 为 1.8 V 或更低，卡侧信号为 2.9～3.3 V；SD 专用自动方向电平转换器，时钟到 60 MHz（S3 p19）。
- **核心器件类**：18 电平转换器_电压翻译器（SD 卡专用）、27 连接器（卡座）、20 MLCC多层陶瓷电容
- **必需外围**：
  - 两侧电源各 0.1 µF 去耦（S3 p21）
  - 转换器的使能脚：低电平时所有输出高阻；要保证上电和掉电期间输出高阻，按手册连接（S3 p22）
  - 时钟反馈脚按手册连接（S3 p21）
- **必算项**：
  - 外部或卡内的下拉不能小于 10 kΩ：转换器的上拉与下拉分压后的高电平，1.8 V 信号要高于 0.65 × VCC（S3 p20）
- **落实规则**：G04-003、G04-008、G04-010、G04-012、G04-013
- **已知坑**：
  - 原件前后不一致：引脚说明写命令线和数据线两侧内部上拉为 40 kΩ（S3 p3），下拉核算一节按“4 kΩ 上拉”算分压（S3 p20）。按 4 kΩ 算更保守（下拉 10 kΩ 时高电平只有 0.714 × VCC，S3 p20），设计按这一节的下拉限值执行，再向厂家确认实际上拉值
  - 自动方向转换器只适合手册允许的驱动类型和负载，线上额外的强上拉或容性负载会影响方向判断（G04-012、G04-013）
- **来源**：S3 p3、p19–22

### 卡座供电开关与插卡时的电压跌落

- **适用范围**：卡要能单独断电重上电（卡出错恢复、1.8 V 信号模式下的复位）；插卡时卡内电容接到电源上产生冲击电流，与主控共用一路电源时会拉低主控电源。负载开关的慢速开启可降低或消除冲击电流引起的电源跌落（S5 p12）。
- **核心器件类**：08 负载开关与高低侧驱动（带受控上升时间与输出放电）、20 MLCC多层陶瓷电容
- **必需外围**：
  - 负载开关串在卡座电源上，使能由主控控制；使能脚有内部下拉，系统时序完成前保持关断（S5 p1）
  - 输出放电：放电脚接输出，断电时把卡座电源放到零（S5 p3、p14）
  - 开关输入、输出电容
- **必算项**：
  - 冲击电流 = 输出电容 × 输出电压上升斜率；要把冲击电流限在 IRUSH 以内，斜率不超过 IRUSH / CL（S5 p16）
  - 断电后放电时间 tFALL = 2.2 ×（RDIS ‖ RL）× CL（S5 p16）；重新上电前电压要放到足够低，卡才完全复位
  - 主控电源在插卡瞬间的跌落（卡侧电容与插卡时的接触电流）：按电源输出电容和响应核，跌落不超过主控复位门限（G03-025）；卡的输入电容取 SD 规范值
- **落实规则**：G03-017、G03-025、G03-027、G05-093
- **已知坑**：
  - 系统复位时卡也要重新上电：代表处理器说明 SD 3.0 等外设在系统复位时需要重新上电（S6 p7）；卡电源与主控电源不可分开控制时，处理器复位后卡可能停在 1.8 V 信号模式
  - 卡断电而主控信号线仍上拉到主控电源时，卡经内部保护二极管被反向供电，卡不能完全断电（G04-007、G04-009）；上拉接到卡座侧（开关之后）的电源，或断电前把信号线置低或高阻。这一条由反灌原理推出，所引资料没有直接写出
- **来源**：S5 p1、p3、p12、p14、p16；S6 p7

### 卡座端的静电防护

- **适用范围**：卡座是用户可插拔的接口，插卡时人体静电直接到达信号脚；在卡座与主控之间加多路静电防护阵列（S4 p1 适用接口列出 SDIO）。
- **核心器件类**：28 TVS_ESD保护器件（低电容多路阵列）
- **必需外围**：
  - 阵列放在尽量靠近卡座处（S4 p8–9）
  - 阵列的电源脚接 0.1 µF 陶瓷电容（S4 p3、p8）
- **必算项**：
  - 每路电容（典型 1.5 pF，S4 p1）计入时钟和数据线的负载，高速模式下核信号边沿
  - 阵列 I/O 电压不超过其电源脚电压加 0.3 V（S4 p4）
- **落实规则**：G05-034、G07-038、G07-039
- **已知坑**：
  - 阵列的电源脚接到受开关控制的卡座电源时，卡座断电而主控线上仍有高电平，I/O 电压就超过“电源脚 + 0.3 V”的绝对最大值（S4 p4）；电源脚接常通的 I/O 电源。这一条由绝对最大值推出，原件没有直接写出
  - 未受保护的走线要远离阵列与卡座之间的受保护走线，否则静电事件时的耦合绕过保护（S4 p9）
- **来源**：S4 p1、p3–4、p8–9
