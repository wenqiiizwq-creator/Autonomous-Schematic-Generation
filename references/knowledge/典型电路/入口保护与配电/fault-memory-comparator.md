# 比较器 + 触发器的故障记忆与清锁

功能：用比较器从锁定型热插拔控制器的定时脚识别真正的过流故障（电平与斜率同时成立），经冷启动门控置位 D 触发器；锁存跨普通 MCU 复位保持，只在清锁许可成立时由 MCU 清锁请求的上升沿清除，或由真实冷启动清除；锁定输出经缓冲门与开漏 MOS 把控制器 UVLO 拉低，保持主路关断。

适用范围：带定时电容脚的锁定型热插拔控制器（插入延时与故障定时都给同一电容充电）；要求普通 MCU 复位、看门狗复位不清锁，主过流锁定不关常供域；比较器与逻辑由主保护之前的常供电源供电。各路 eFuse 的短路记忆用同一套触发器、清锁资格与冷启动门控，事件由 eFuse 指示组合产生（见 [efuse-bfet-short-latch](efuse-bfet-short-latch.md)）。按“控制器自身的锁定能不能满足清锁条件”“故障事件能不能从现有信号可靠识别”两项选方案。比较器门限分压的取值见 [分压与门限](../../计算方法/通用方法/分压与门限.md)；冷启动复位与上电时序见 [上电时序与复位](../../计算方法/数字核心与时钟复位/上电时序与复位.md)；热插拔控制器本体见 [hotswap-latch-powerlimit](hotswap-latch-powerlimit.md)。

电路类型：POWER_PROTECTION、STARTUP

## 选方案时比较的量

| 方案 | 锁定在哪里保持 | 怎样清除 | UV/OV 恢复会不会清锁 | 来源 |
|---|---|---|---|---|
| 只用锁定版热插拔控制器自身的锁定 | 控制器内部，故障定时到期后 GATE 保持低 | 输入电压断电再上电，或把 UVLO 脚瞬时拉到门限以下 | 会：欠压跌落本身就是一次清锁 | S1 p15 |
| 比较器识别故障 + 外部 D 触发器记忆 + 开漏管保持 UVLO | 外部触发器，由常供电源供电 | 清锁许可成立时的清锁请求上升沿，或冷启动复位 | 不会：触发器持续拉低 UVLO | S2 p10 |

经验上的分界（条件，不是定值）：

- 只要“故障后关断、断电重来即可”：用控制器自身的锁定（方案 2），不加外部记忆（S1 p15）。
- 要求“UV/OV 恢复、MCU 复位都不清锁，只由命令或冷启动清除”：必须外部记忆，并持续拉低 UVLO（方案 1，S1 p15）。
- 外部记忆的预置判据必须对正常动作（插入延时、命令关断、过流重试、热插入允许负载）逐一不成立（G05-098）。

## 实现方案

### 1. 比较器判定时脚电平与斜率 + D 触发器记忆（D 端清锁资格）+ 开漏 MOS 保持 UVLO

- **适用范围**：只判定时脚电平会在插入延时误动作，要加斜率判据区分插入充电与故障充电；比 SR 锁存器多出 D 端清锁资格，许可恢复时不会消费一直为高的旧清锁请求；保持用开漏 MOS 而不用二极管，不锁时不改变 UVLO/OVLO 分压
- **核心器件类**：05 比较器（开集电极输出，多通道）、18 触发器_锁存器_寄存器（带 PRE/CLR 的 D 触发器）、18 标准逻辑门（NOR、NAND，施密特输入）、09 MOSFET（小信号 N 沟道，低关断漏电）、23 肖特基势垒二极管 (SBD)（差分器负向钳位）、22 电阻、陶瓷电容（差分器用 C0G）
- **必需外围**：
  - 识别：比较器由常供电源经 RC 去耦供电；电平比较器：定时脚对基准分压上点；斜率比较器：定时脚经电容-电阻差分器（肖特基负向钳位）对基准分压中点；许可比较器：定时脚低于再使能门限之下的分压点时输出释放；比较器输出各自上拉；未用比较器输入固定
  - 记忆：事件 = NOR(电平_N, 斜率_N)；PRE_N = NAND(事件, 冷启动复位_N)；CLR_N = 冷启动复位_N；D = NOR(Q̄, 许可)；CLK = MCU 清锁请求（下拉电阻）
  - 保持与读回：Q 经缓冲门驱动开漏 MOS 把控制器 UVLO 拉到地；锁定状态送 MCU 读回并留测试点；MCU 命令线上拉到关断态、清锁请求线下拉
- **必算项**：
  - 电平门限：基准电源容差、分压电阻容差与比较器全温失调合成；下端高于正常启动结束时定时脚电压上限，上端低于控制器定时上门限下限（控制器关断前已置位）；见 [比较器故障记忆与锁存](../../计算方法/入口保护与配电/比较器故障记忆与锁存.md)
  - 斜率门限：插入定时电流上限对应斜率的差分输出低于斜率门限下端；故障定时电流下限对应斜率、在到达电平门限时的差分输出高于斜率门限上端；见 [比较器故障记忆与锁存](../../计算方法/入口保护与配电/比较器故障记忆与锁存.md)
  - 许可门限上端低于控制器再使能门限（手册只给典型值的标典型）
  - 比较器开集电极输出在实际灌电流下的低电平上界低于施密特门 VT− 下限（手册只给两点电流时外推，标估算）；见 [比较器故障记忆与锁存](../../计算方法/入口保护与配电/比较器故障记忆与锁存.md)，上拉电阻取值见 [上拉与开漏](../../计算方法/总线与接口/上拉与开漏.md)
  - 低电平保证带测试条件（电源电压、上拉电压是否等于电源、灌电流、温度）。实际接口不在条件内时，先评估让接口落在条件内的接法并写明取舍：比较器电源与上拉按表格条件、灌电流不超过表格电流；换用在实际电源和全温下给出低电平上限的比较器；或加输入门限有保证、输入电流可忽略的缓冲门。都不可行时写淘汰理由，结论保持条件成立。外推只是估算，不构成保证；样机实测记录验证结果，不补厂家保证缺口；这属于工程模型风险，挂待办，不作为改电路的硬约束
  - 锁存 Q 高电平下限高于保持 MOS VGS(th) 上限；导通压降远低于 UVLO 门限下限；不锁时 MOS 关断漏电计入 UVLO/OVLO 门限（动作态与不动作态都核）；见 [比较器故障记忆与锁存](../../计算方法/入口保护与配电/比较器故障记忆与锁存.md)
  - 冷启动复位门限下端高于逻辑器件最低工作电压（掉电先复位、冷启动清锁有效）；见 [比较器故障记忆与锁存](../../计算方法/入口保护与配电/比较器故障记忆与锁存.md)
  - 清锁事务：先关断全部受控输出、确认许可、清锁脉冲宽度与读回；清锁后各路保持关断直到新命令
  - 故障注入项：主过流锁定、清锁、保持 MOS 开路时只靠控制器自身锁定
- **落实规则**：G02-004、G02-022、G02-023、G03-025、G04-010、G05-008、G05-009、G05-018、G05-060、G05-061、G05-063、G05-064、G05-065、G05-098
- **已知坑**：
  - 记忆触发器的预置判据必须对命令关断、MCU 复位、过流重试、热插入允许负载逐一核不成立，否则正常动作就置锁且复位后真锁假锁分不开（审查发现：Matrix 综合控制板电源与保护 R2，F-001）
  - 插入延时期间定时脚同样充电到上门限，只判电平会误锁；插入与故障的充电电流保证范围不重叠，才能用斜率区分（S1 p6）
  - 用二极管从逻辑高电平拉 UVLO 保持锁定时，不锁状态下高输入使二极管反向把 UVLO 分压钳住、OVLO 失效；改开漏 MOS，门限要同时核动作态与不动作态（设计评审：2026-11-03，R2 CALC-MAIN-UVOV 复核发现）
  - PRE 与 CLR 同时有效时 Q 与 Q̄ 同为高且不保持；故障事件置位必须由冷启动复位门控，冷启动优先（S2 p10）
  - 比较器输出低电平只在空载与一个较大灌电流两点、最高电源下给出，接施密特门时按外推核 VT−，留样机实测（S3 p7）
  - 电气特性表头条件是上拉电压等于电源电压；比较器由较高的常供电源供电、输出上拉到 3.3 V 逻辑电源时已不在表格条件内，表中输出摆幅不能直接用作该接口的保证（S3 p7）
  - 冷启动复位只取监督器输出，不接 MCU 复位线；看门狗或软件复位不得清锁（设计评审：2026-11-03，R2 MCU与固件接口.md 第 3 节）
  - 控制器再使能门限只有典型值，许可门限按典型值留余量，结论只能是条件成立（S1 p6）

  - （S3 p7 失调、输出摆幅）

### 2. 只用锁定版控制器自身的锁定

- **适用范围**：需求只要求“过流后关断、不自动重试”，允许断电重来或欠压跌落时解除锁定（S1 p15）。不需要比较器、触发器和保持管。
- **核心器件类**：08 热插拔_eFuse（锁定版）
- **必需外围**：需要远程清锁时，UVLO 脚接开漏或集电极开路器件，瞬时拉到门限以下（S1 p15、p16）
- **必算项**：开漏器件关断漏电计入 UVLO/OVLO 分压（同方案 1）；恢复方式与料号后缀一致（G05-059）；锁定的复位路径写明（G05-060）
- **落实规则**：G05-059、G05-060、G05-061、G05-062
- **已知坑**：
  - 输入欠压跌落本身就会清锁（S1 p15）；需求要求欠压恢复不清锁时不能只靠它
- **来源**：S1 p15、p16
