# 计算方法

类型：方法。层次：功能电路、器件。状态：64 条已写，均过来源核对。

回答：一类电路的元件值按什么顺序定、每一步用什么式子、输入取哪一端、算完要满足什么。

## 与设计准则的分工

设计准则写的是“必须成立什么”，多数是算完之后的核对条件，有的也带核对用的式子。本组件写的是**取值步骤**：从需求和器件手册出发，按什么顺序把元件值一个个定下来，使那些准则成立。

- 准则里已有的判据和工程取值，这里只写编号引用，不重抄。
- 一个步骤算出的量要满足哪条准则，在步骤里写出准则编号。`工具/rule_support.py` 据此生成 [准则支撑表](../索引/准则支撑表.md)。
- 降额系数和应力判法在设计准则的 G10，这里引用。

## 条目格式

一类电路（或一类器件的选型）一个文件，放在它的知识域子目录里：

```
# <名称>

类别：计算方法（取值步骤）。
适用范围：哪类电路、哪种控制方式或器件类型；不适用的写明。
对应典型电路：../../典型电路/<知识域>/<文件>.md（没有的写 无）

## 来源
- S1：<相对 原件/ 的路径>

## 已知条件
| 量 | 说明 | 谁给 | 来源 |      ← 谁给：需求、接口约定、器件手册、上一步

## 取值顺序
| 步 | 定什么 | 算式 | 输入取哪一端 | 算完要满足 | 来源 |
                                              ← “算完要满足”写准则编号或手册条件

## 相互牵制
哪个量改了，前面哪几步要重算。

## 算完之后的核对
逐条写要核的量和对应的准则编号；本条目没有覆盖、要另找条目算的也列出。

## 什么时候这套步骤不适用

## 算例（可选）
只用来源里自带的算例，逐个数注明页码；不用某块实际板子的数。
```

写法要求：

- 来源的写法和核对同 [条目规范](../条目规范.md) 的“来源的写法与核对”，条目要过 `python3 工具/check_sources.py`。页码用 PDF 文件页序，逐页抽取确认（`pdftotext -f N -l N`）；整本抽取后数换页符会数错。
- 每个输入写明取最小值还是最大值；取法的一般规则见 [最坏情况怎么取](通用方法/最坏情况怎么取.md)。
- 式子写全，注明成立的条件和忽略了什么。来源里的式子有错的，按正确的写并注明原件哪里错了。
- 不写某块板的取值，不出现技能名。

## 现有条目

全部条目和来源核对结果见 [条目总表](../索引/条目总表.md)（工具生成，随条目更新）。

| 知识域（子目录） | 放什么 |
|---|---|
| `通用方法/` | 最坏情况怎么取、最坏情况分析的范围、各类电路要核的量、分压与门限 |
| `电源变换/` | 降压、升压、反激、LLC、功率因数校正、线性稳压、补偿与环路、去耦、输入滤波器、充电 |
| `入口保护与配电/` | 熔断器、TVS、浪涌协调、防反接、热插拔、负载开关、保持电容、共模与差模滤波器、PoE 受电端 |
| `信号与模拟/` | 运放级、噪声预算、测温与电流检测的误差预算、ADC 驱动 |
| `总线与接口/` | 上拉、端接与位时序、同步接口时序、缓冲器模型、射频匹配、光耦输入级 |
| `数字核心与时钟复位/` | 晶体振荡电路、上电时序与复位 |
| `驱动与执行/` | 感性负载关断、智能高边开关、LED 限流、D 类功放 |
| `隔离与安规/` | 绝缘距离、接触电流与 Y 电容总量 |
| `热与寿命/` | 结温与热阻、电解电容寿命、贴片电阻功率、可靠性预计 |

前七个域与 [典型电路](../典型电路/README.md) 的子目录同名，同一个域的电路和算法两边对着查。故障模式分析、故障树等分析步骤不在本组件，在 [失效与故障分析](../失效与故障分析/README.md)。

## 与其他组件的关系

- 每个典型电路的“必算项”指到这里的条目。
- 器件的保证值在 [`器件参数/`](../器件参数/README.md)，这里只说要哪个参数、取哪一端。
