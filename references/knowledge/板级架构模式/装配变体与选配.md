# 装配变体与选配

类别：板级架构模式。
回答：同一块板有几种装配组合、有互斥的选配位（两个 0 Ω 电阻二选一、选配器件与旁路链路等）时，怎样把组合表达清楚；每种组合下怎样逐个检查输入悬空、两个输出对顶、电源短接。
适用条件：图上有不装配的位号、选焊电阻、跳线或拨码开关；或需求有多种产品变体；或为了测试另有一种装配状态。
不在本条目：不装配位号在原理图和 BOM 里用什么字段标（G09-018，主判 G02-037）；配置脚的出厂状态表（G09-017）；依赖选配的计算列表（G02-018）；边界扫描链的旁路接法（见 [边界扫描链](../典型电路/boundary-scan-chain.md) 方案 D）。

## 先要知道的条件

| 条件 | 说明 |
|---|---|
| 产品变体定义 | 需求里有哪几种产品、各要哪些功能。没有定义时记资料不足（G09-019），不按图推定。 |
| 默认组合 | 出厂装哪一种；生产测试用哪一种。 |
| 测试用的装配状态 | 只为测试才装或才改的件。例：某处理器评估板进边界扫描时要装一只上拉电阻，否则看门狗输出悬空引起复位（S5 p48）。 |
| 谁能改、什么时候改 | 生产时焊接决定的、现场插拔跳线决定的、上电后不能改的。 |

## 做法

### A 装配组合表

- 结构：一张矩阵，行是每个选配位号（含跳线帽和开关的位置），列是每种允许的组合（默认组合、各产品变体、测试状态），格子里写“装/不装”或跳线位置。每列再写这一组合的功能和被影响的网，以及检查结论（下一节）。表外的组合一律不允许。
- 依据：选配有几种常见用法：只要一种功能时直接接死；以一种功能为主、偶尔要另一种时用选焊电阻，小改板就能把配置脚接高或接低；要随时切换时引到连接器，用上下拉定默认、由外部控制器改写（S1 p5、p6）。前两种是装配组合，第三种不改装配，只在出厂状态表里写默认值（G09-017）。
- 要补的措施：组合表和不装配清单（G09-018）、BOM 的装配状态列一致；依赖选配的功能和计算按 G02-018 列出。

### B 互斥组

- 结构：不能同时装的几个位号写成一组，标明“组内只装一个”或“组内恰好装一个”。常见几种：
  1. **一脚两电阻，二选一接高或接低**（S1 p5 的选焊电阻）。两只都装时，是上下拉电阻串在电源与地之间；用 0 Ω 电阻时就是电源对地短路。两只都不装时，该脚悬空。所以这一组是“恰好装一个”。
  2. **选配器件与它的旁路链路**：选配的边界扫描器件不装时，用一个链路（通常 0 Ω 电阻）接通扫描链（S1 p8）。器件装上时链路不能再装，否则链路与器件的 TDO 对顶。也是“恰好装一个”。
  3. **两路供电二选一**：例，开发板用一个三针跳线在“调试器供电”和“外部供电”之间选（S3 p17、p18）。三针跳线在物理上只能插一个位置；用两个独立的 0 Ω 电阻或两个两针跳线实现时，物理上能同时装，要在组合表里写成互斥。
  4. **测量跳线与另一供电路径**：例，从扩展插座直接给目标器件供电时，测电流的跳线测不到电流，用户指南要求拆掉这只跳线，防止倒灌给调试电路（S3 p18）。
- 合适：凡是“两个都装会短路或对顶、两个都不装会悬空或断开”的位置，都要写成互斥组。
- 代价：多一张表；能用三针跳线、单刀双掷开关这类物理上互斥的件时，可以少依赖表。

### C 测试状态也是一种组合

- 结构：为测试临时装的件、插的跳线、关看门狗的链路（S1 p7），在组合表里单列一列“测试状态”，按下一节同样检查，并写明测试后恢复到哪一列。
- 依据：评估板进边界扫描时要装一只上拉电阻（S5 p48），合规脚要处在规定电平（S5 p11）；电池在在线测试时不应装上，装着时要有可拆的链路把它与电路隔开（S6 p4）。

## 每种组合的检查步骤

对组合表的每一列（含默认组合和测试状态）做一遍：

1. **得出这一组合的有效电路**：从网表里去掉这一列“不装”的件，按跳线位置连上或断开相应的网。
2. **输入悬空**：逐个查器件输入脚和使能、复位、片选、配置脚，在这一组合下有没有驱动源或上下拉。例：某转换器使能脚必须由外部设成高或低，片内下拉只在先为低时才保持低电平（S4 p8），选配掉使能上的电阻就是悬空；片选、使能脚应经上下拉电阻接电源，不直接接死（S6 p4），这样换组合时也不会失去确定电平。关键输入悬空的，按 G09-019 判不成立。
3. **两个输出对顶**：逐网查在这一组合下同时有两个以上推挽驱动源的网，包括互斥组同装、选配器件与旁路同装、测试设备经连接器驱动的网与板上驱动器同时有效。边界扫描测试时也一样：要加约束，禁止两个可扫描输出同时驱动同一网（S2 p78）。
4. **电源短接和倒灌**：查这一组合下有没有两个电源轨被接在一起（两路供电都装）、电源经 0 Ω 直接接地（上下拉位都装 0 Ω），以及一路断开后另一路经跳线、信号线或调试口给它倒灌（S3 p18；G04-009、G03-031）。
5. **切换过程**：组合要在通电时切换的（插拔跳线、拨开关），查切换瞬间的后果。例：把供电选择跳线从“旁路”换到“使用”时，目标器件失电并复位（S3 p19）。不允许带电切换的写进操作要求。
6. **功能结论**：这一组合下需求功能是否都成立，不成立的写明是有意的（该变体不要这个功能）还是缺陷。
7. 把每一列的结论写回组合表。没有结论的列不能关闭（G09-019 的关闭条件）。

## 怎么选

| 做法 | 条件 | 判据 | 来源 |
|---|---|---|---|
| 直接接死 | 只要一种功能 | 配置脚接到所需电平，不设选配 | S1 p5 |
| 选焊电阻（互斥组） | 以一种功能为主，偶尔要另一种 | 写成“恰好装一个”的组；两只都用零欧电阻时同装即电源对地短路（推论） | S1 p5 |
| 引到连接器，不改装配 | 要随时切换 | 上下拉定默认，外部改写；写入出厂状态表 | S1 p6 |
| 选配器件加旁路 | 器件可能不装 | 不装时链路接通；不太可能装的放到单独一条链 | S1 p8 |
| 物理互斥的选择件 | 两路供电或两个来源二选一 | 用三针跳线一类只能插一处的件 | S3 p17 |
| 测试状态单列 | 测试要另装件或插跳线 | 与默认组合同样检查，并写明测试后恢复 | S5 p48 |

## 不适用的情形

- 只有一种装配、没有不装配位号的板。
- 上电后由软件选择的功能复用（引脚复用、内部开关）不是装配组合，按 G04-102 和接口条目核。
