# 接地与回流

类别：板级架构模式。
回答：信号地、功率地、机壳地怎样划分、在哪里怎样连接（单点、多点、经电容或电阻）；模拟部分与数字部分的地是什么关系；对外端口的地放在哪里接机壳。
适用条件：板上有模拟前端或数据转换器与数字电路并存；或有大电流、感性负载的功率回路；或有金属机壳、屏蔽连接器、对外电缆；或是多块板组成的系统。
不在本条目：隔离一侧的地对机壳怎样连（见 [隔离边界](隔离边界.md)）；端口浪涌的泄放路径和机壳与信号地三种连接方式的具体选取判据（设计准则 G07-025～G07-027）。本条目只写原理图阶段能定的地网划分和连接关系，铺铜和走线属于布局，不在本框架。

## 先划分地

| 地 | 流过什么 | 来源 |
|---|---|---|
| 数字地 | 单片机逻辑、时钟、通信总线的回流，频率高，有地弹噪声 | S4 p322 |
| 模拟地 | 弱信号检测、传感器输入、前级放大、单片机模拟电源的回流，幅度小，容易受干扰 | S4 p322 |
| 功率地 | 大功率输出电路的回流，电流大，地线上压降和干扰大 | S4 p322 |
| 噪声地 | 电机、继电器、电磁阀等感性负载的回流，开关时有冲击电流；必须与其他地分开设置 | S4 p322 |
| 机壳地 | 与设备金属外壳相连的导体；与信号地通常在一处或几处相连 | S1 p155 |

划分的理由是共阻抗耦合：几个电路共用一段地回路时，一个电路的地电流在共用阻抗上的压降加到另一个电路上。地阻抗高、地电流大、电路噪声裕量小，三者有其一时就成问题（S1 p153）。先划分，再决定各部分怎样连到一起（S4 p322）。电源的分配拓扑一般跟着地的拓扑走：先定地，再按同样的方式分配电源（S1 p148）。

## 连接方式

### A 单点接地

- 结构：各电路的地分别连到同一点。串联（菊花链）的单点接地最差，各电路的地电流在公共段上叠加；并联的单点接地没有交叉耦合，但在大系统里布线笨重；实际多是两者组合，低电平电路共一条回线，高电平电路共另一条（S1 p148、p150）。
- 合适：低频、小功率。直流到约 20 kHz 最有效，一般不在 100 kHz 以上使用，有时可放宽到 1 MHz（S1 p148）。常用于模拟电路（S4 p322）。
- 代价：频率高时地线电感使阻抗变大，地线长度接近四分之一波长的奇数倍时阻抗很高并成为天线；地线应短于波长的二十分之一。高频下杂散电容会把单点接地变成多点接地（S1 p150）。

### B 多点接地（地平面）

- 结构：每个电路就近接到低阻抗的地平面，连接尽量短（S1 p152）。
- 合适：高频（约 100 kHz 以上）和数字电路（S1 p150、p152）。
- 补充：板上逻辑地是多点的，不等于给板子供电的直流电源也要多点接地；高频逻辑电流应留在板内，电源可以按单点接入（S1 p152）。

### C 混合接地

- 结构：低频时是单点、高频时是多点。典型做法是在一端经电容接地：低频时电容阻抗高，相当于单点；高频时电容阻抗低，相当于两端接地（S1 p154）。反过来也可以在接地线里串电感：工频下低阻抗满足安全接地，高频下阻抗高（S1 p154、p155）。
- 合适：信号频率跨越 100 kHz 上下很宽的范围时（S1 p154）。

## 模拟与数字部分

### 一块地平面、分区布置（多数情况的首选）

- 只用一块地平面，把板子分成模拟区和数字区，模拟信号只在模拟区走，数字信号只在数字区走；这样数字回流留在数字区信号线下方，不流进模拟区（S3 p2）。
- 依据：高频回流沿阻抗最小、也就是紧贴信号线的路径返回，所以数字地电流本来就不倾向流过模拟区（S2 p4）。
- 两条电磁兼容原则：电流应在本地、紧凑地返回源；系统只应有一个参考平面（S2 p4）。

### 分割成模拟地和数字地两块

- 信号跨越分割缝时，回流只能绕到两块地的连接处，形成大环路，辐射大、对干扰敏感；两块地只在电源处相连时，环路一直绕回电源（S3 p1）。
- 一定要分割时，两块地先在一处相连形成桥，所有跨区信号都从桥上走；高分辨率（≥20 位）的 Δ-Σ 数据转换器称重这类应用会这样做（S3 p1）。其他跨缝方式是光耦、变压器或真正的差分信号（S3 p1）。

### 数据转换器这类混合信号器件的接法

- 数据转换器是模拟器件。数字电流小的，模拟地脚和数字地脚在器件处连在一起，都接模拟地平面（S2 p2）。
- 数字电流大的，模拟地脚接模拟地、数字地脚接数字地，两地之间的噪声直接加在器件两个地脚之间，不能大到破坏内部的噪声裕量（S2 p3）。
- 两块地之间可以并一对反向的肖特基二极管，防止两地之间出现大的直流或低频尖峰而损坏器件；也可以用磁珠给直流通路、在几兆赫以上隔开，但它会引入直流地环路，不适合高分辨率系统（S2 p3）。两种接法都不确定时，用跳线或可选焊盘留出两种连法（S2 p3）。
- 一块板上有几个数据转换器时，模拟地和数字地在每个转换器下面实打实地连在一起；电源从数字区进入，直接供数字电路，再经滤波或稳压给模拟电路（S3 p3）。

## 机壳与对外端口的地

- 电路地有压降，这个压降会驱动共模电流流到对外电缆上而辐射。电路地若在远离电缆的一端接机壳，整个压降都加在电缆上；在 I/O 连接器处接机壳，驱动电缆的电压理想情况下为零（S1 p155）。所以电路地与机壳的低阻抗连接放在板子的 I/O 区（S1 p155）。
- 这个连接要在关心的频率上阻抗低，频率到几百兆赫时意味着电感小，通常要多处连接（S1 p156）。同时它也改善抗扰度：电缆上感应的高频噪声电流流到机壳，而不流过电路地（S1 p156）。
- 屏蔽连接器的屏蔽接机壳网（G07-050）；端口分流器件的回流优先回机壳（G07-026）。机壳与信号地用直连、电容并电阻，还是隔离域只经电容接机壳，按 G07-027 的判据选。
- 一次电源在一点接结构，这一连接要能承受最坏故障电流（S5 p67 第 5.8.1a 条）。

## 多块板

- 多块板时，每块板上模拟地和数字地都在转换器处相连，单点星形接地不再可能，会有地环路（S3 p3）。用背板作板间连接，给出连续的地平面；连接器有相当比例的针是地（S3 p3）。
- 背板地平面再接机壳有两种方式：多处接机壳（多点接地），多用于全数字系统，也可用于数字地电流小且分散的混合信号系统；或接到一个星形点（通常在电源处），多用于模拟地和数字地分开的高速混合信号系统（S3 p3、p4）。多点接机壳时，与机壳的接触要可靠，阳极氧化的铝表面是绝缘的（S3 p4）。

## 怎么选

| 做法 | 条件 | 判据 | 来源 |
|---|---|---|---|
| A 单点 | 低频、小功率、模拟 | 直流到约 20 kHz 最有效，一般不超过 100 kHz，最多放宽到 1 MHz | S1 p148 |
| B 多点 | 高频、数字 | 约 100 kHz 以上用多点 | S1 p153 |
| C 混合 | 信号频率跨越很宽 | 跨越 100 kHz 上下时用混合接地 | S1 p154 |
| C 的电感接法例 | 安全接地线上要隔开高频噪声 | 串 10～25 mH 扼流圈 | S1 p155 |
| 板层与地平面 | 高密度、高频 | 例：4 层板比 2 层板好 20 dB 以上，可有完整地平面 | S4 p322 |
| 分割地 | 高分辨率转换器、必须分割 | ≥20 位 Δ-Σ 转换器一类；所有跨区信号走桥 | S3 p1 |
| 两地之间的二极管 | 模拟地、数字地分开 | 两地之间电压限在 0.3 V 以内 | S2 p3 |
| 多板连接器 | 背板连接 | 连接器 30～40 % 的针接地 | S3 p3 |
