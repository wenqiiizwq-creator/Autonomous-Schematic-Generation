# SWD 与 JTAG 调试接口

类别：总线约定。
适用范围：板上处理器、可编程逻辑与调试工具之间的 JTAG（TCK、TMS、TDI、TDO，可带 TRST−、RTCK）和 SWD（SWDIO、SWCLK，可带 SWO）调试接口，以及调试口上的目标电压参考、复位和地。多器件扫描链和边界扫描只写接口层面要核的量。实现电路见典型电路 [swd-debug](../../典型电路/测试与调试/swd-debug.md)、[boundary-scan-chain](../../典型电路/测试与调试/boundary-scan-chain.md)。

## 电气约定

### 信号与采样关系

| 信号 | 方向（工具看） | 作用 | 性质 | 来源 |
|---|---|---|---|---|
| TCK | 输出 | 测试时钟 | 应用笔记 | S1 p6 |
| TMS | 输出 | 测试访问口状态机控制，在 TCK 上升沿采样 | 应用笔记 | S1 p6；S3 p31 |
| TDI | 输出 | 数据输入，在 TCK 上升沿采样 | 应用笔记 | S1 p6；S3 p31 |
| TDO | 输入 | 数据输出，在 TCK 下降沿改变 | 应用笔记 | S1 p7；S3 p31 |
| TRST− | 输出（推挽） | 低有效，异步复位测试访问口；可选 | 应用笔记 | S1 p6 |
| SRST− | 输入/输出（工具侧开漏） | 低有效，复位目标系统；可选 | 应用笔记 | S1 p7 |
| VTREF | 输入 | 目标电压参考，工具据此定输入门限和输出电平 | 应用笔记 | S1 p5 |
| SWDIO / SWCLK | 双向 / 输出 | 两线调试，分别与 TMS / TCK 共脚 | 应用笔记、器件手册 | S1 p26；S4 p20 |
| SWO | 输入 | 串行跟踪输出，占用原 TDO 脚 | 应用笔记 | S1 p26 |

说明：
- S1 p6 建议 TRST− 在目标侧接下拉，使未接工具时片上调试逻辑不工作，同时注明这不符合 JTAG 标准；S1 p13 又说可选信号如要固定电平，TRST− 应固定为高（无效）。两处并不矛盾：前者是加弱下拉，后者是“固定接死”时不能接成有效。按处理器手册的要求定。
- S1 p13 推荐不经缓冲或电平转换直接短接调试口与处理器；工具输出已带串联端接，把信号再分到别的连接器会破坏端接效果（S1 p14）。
- S1 p16：TRST− 与 SRST− 不能直接连在一起，否则工具无法在复位释放前停住处理器，看不到程序最初几条指令。
- S2 p12：C2000 要求 TMS、TCK 上有足够强的外部上下拉，防止噪声把芯片带进边界扫描模式；S2 p5 又说上下拉太强也会造成通信故障。阻值按器件手册（S2 p2、p16）。
- S5 p40：STM32 的 SWD 固定在 PA13（SWDIO）、PA14（SWCLK），复位后默认就是调试功能；固件若把这两个脚改作他用，要靠 NRST 在复位状态下连接（S5 p40、p42）。

## 设计时要核的条件

1. **调试口信号齐全**：按处理器和工具列出必需信号（JTAG 四线或 SWD 两线、地、目标电压参考、复位），按所选连接器的针脚定义接（S1 p4、p26～p27）。准则已覆盖（G09-010）。
2. **目标电压参考直接接处理器 I/O 电源**：VTREF 接调试脚所在 I/O 电源，不经串联电阻，能驱动电缆的 100 kΩ 下拉，并能给旧版电缆提供约 2 mA（S1 p5、p13，应用笔记）。I/O 电源不在工具的 VTREF 范围内的，换工具或另作电平处理（S1 p9）。
3. **上下拉与 TRST**：每个调试脚按处理器手册配上下拉，手册没规定的按准则取值；TRST 不硬接地。准则已覆盖（G09-011）。S1 推荐 10 kΩ（1 k～47 k，S1 p13）；准则工程取值为 1 k～10 k，两者范围不同，以手册为先。
4. **调试脚复用不阻断连接**：调试脚另接 LED、配置电阻或作 GPIO 时，工具仍能驱动，上电默认是调试功能（S5 p40）。准则已覆盖（G09-012）。
5. **能重新进入调试**：固件把调试脚改掉或进入低功耗后，靠复位线在复位状态下连接（S5 p40、p42）。准则已覆盖（G09-013）。
6. **TRST− 与 SRST− 分开**：测试访问口复位与系统复位不直接连在一起（S1 p16，应用笔记）。
7. **复位线的驱动方式与电容**：工具以开漏驱动复位（S1 p7），复位线上的上拉和电容要让工具能把电平拉到处理器的复位低电平门限以下（例：STM32F103C8 VIL(NRST) 0.8 V，S4 p66～p67，器件手册），且未接工具时不误复位（S1 p7）。复位线另有监控芯片推挽驱动的，与工具驱动冲突，要改成开漏或加隔离。
8. **多器件扫描链**：TDO 到 TDI 顺序串联，TCK、TMS、TRST 并联，不同电压的器件分组或加转换。准则已覆盖（G09-014）。器件数不超过工具所能可靠连接的数目（例：C2000 无 ICEPick 时 XDS100/110/200 只能可靠接 2 个，S2 p8，应用笔记）。
9. **不经缓冲、走线短**：调试口到处理器直接短接，不经缓冲或电平转换；推荐距离小于 5 in，同一信号不分到多个连接器（S1 p13～p14，应用笔记）。必须加缓冲的（如长距离或多处理器），按 G04-011 核往返时序。
10. **调试口的地**：工具的地接到哪个域、是否带危险或浮动电位。准则已覆盖（G09-015）。
11. **电平兼容**：调试脚所在 I/O 电源与工具输出电平、输入门限匹配（S1 p9）。准则已覆盖（G04-003、G04-004）。
12. **RTCK 回送可断开**：用 RTCK 补偿延时而把 TCK 直接回送 RTCK 时，留跳线或焊盘可断开（S1 p7、p13，应用笔记）。

## 两端各要交代什么

按 [逻辑信号](../参数模板/逻辑信号.md) 的模板，另加：

- **处理器（目标）所在块**：调试方式（JTAG、SWD、两者切换）；各调试脚的片内上下拉和手册要求的外部上下拉；调试脚所在 I/O 电源；复位脚的片内上拉、输入门限、推荐电容；调试脚复位后的默认功能及固件是否会改掉；扫描链中的位置和测试访问口个数。
- **调试工具与连接器**：连接器型号与针脚定义；VTREF 的范围和取电情况；输出驱动方式（推挽或开漏）和是否带串联端接；复位线的驱动方式和电缆内上拉；可靠连接的扫描链长度；工具地与目标地的关系（是否隔离）。
- **板上其余连到调试脚的器件**：复用为 GPIO 时的负载；复位线上的其他驱动源（监控芯片、按键）及其输出类型。

## 准则没有覆盖的条件

- 条件 2：VTREF 直接接 I/O 电源、能驱动电缆下拉并供电（S1 p5、p9、p13）。G09-010 只要求有目标电压参考。
- 条件 6：TRST− 与 SRST− 不直接相连（S1 p16）。
- 条件 7：复位线开漏驱动、电容与门限、与其他复位源的驱动冲突（S1 p7；S4 p66～p67）。
- 条件 8 的后半：扫描链长度不超过工具能力（S2 p8）。
- 条件 9：不经缓冲、距离短、不分到多个连接器（S1 p13～p14）。
- 条件 12：RTCK 回送可断开（S1 p7、p13）。
