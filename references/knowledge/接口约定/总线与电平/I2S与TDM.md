# I2S 与 TDM（板内数字音频串行接口）

类别：总线约定。
适用范围：板内两颗芯片之间传输脉冲编码调制（PCM）数字音频的串行接口：I2S、左对齐、右对齐、DSP 与 TDM（多时隙），以及麦克风用的脉冲密度调制（PDM）单线接口。不管：S/PDIF、AES3 这类带时钟嵌入的链路，以太网音频与 A2B 总线（见各自器件手册）。实现电路见 [audio-codec](../../典型电路/audio-codec.md)；建立、保持余量的算法见 G04-011 与 G02-022 的取值方法；控制通道（I2C 或 SPI）另见 [I2C](I2C.md)、[SPI](SPI.md)。

**只有 I2S 有一份公开的总线规范。** 左对齐、右对齐、DSP、TDM 和 PDM 没有统一标准，各厂家的帧格式、帧同步脉宽和时隙数不同；本条目对这几种格式引用代表器件的手册，设计时以两端器件手册为准。

## 电气约定

### 三根线与数据格式

| 信号 | 作用 | 取值 | 性质 | 来源 |
|---|---|---|---|---|
| 串行时钟 SCK（又叫位时钟 BCLK、BCK） | 每个时钟周期传一位数据 | 由控制器产生，连续运行 | 标准 | S1 p4 |
| 字选择 WS（又叫帧时钟 LRCK、WCLK、FSYNC） | 指出正在传的声道 | WS 为 0 是声道 1（左），WS 为 1 是声道 2（右）；WS 可在时钟的任一沿变化，不必对称；在目标端用时钟的前沿锁存 | 标准 | S1 p4–5 |
| 串行数据 SD | 两个声道时分复用 | 补码，先传最高位 | 标准 | S1 p4 |
| I2S 的位置关系 | WS 变化后的下一个时钟周期传该字的最高位 | 最高位位置固定，最低位位置随字长变；发送端字长比系统字长短时低位补 0；接收端收到的位多于自身字长时多余的低位丢弃，少于时内部补 0 | 标准 | S1 p4 |
| 数据的同步沿与锁存沿 | 发送端可用时钟下降沿或上升沿送出数据；接收端必须用时钟上升沿锁存 | | 标准 | S1 p4–5 |

### I2S 的时序量（以发送端、接收端的最小时钟周期为基准）

| 参数 | 符号 | 条件 | 值 | 单位 | 性质 | 来源 |
|---|---|---|---|---|---|---|
| 时钟高、低电平时间下限 | tHC、tLC | 发送端，T 为时钟周期 | 0.35T | | 标准 | S1 p5 |
| 数据与字选择的延迟上限 | tdtr | 发送端，相对时钟参考沿 | 0.8T | | 标准 | S1 p5 |
| 数据与字选择的保持时间下限 | thtr | 发送端 | 0 | ns | 标准 | S1 p5 |
| 接收端建立时间上限 | tsr | 接收端 | 0.2T | | 标准 | S1 p6 |
| 接收端保持时间 | thr | 接收端 | 0 | ns | 标准 | S1 p6 |
| 时钟上升时间上限 | tRC | 只对目标模式的发送端有意义 | 0.15T | | 标准 | S1 p5、p7 |
| 高低电平的界定 | VH、VL | 时序按此两门限量 | 2.0 / 0.8 | V | 标准 | S1 p5 |
| 示例：2.5 MHz 数据速率下的发送端 | T | 控制器发送端，±10 % | 360 / 400 / 440（最小 / 典型 / 最大） | ns | 标准 | S1 p6 表1 |

说明：

- 所有时序按时钟周期的比例写，这样数据速率提高后同样适用（S1 p5）。
- 目标端发送端的时钟上升很慢时，延迟 tdtr 可能不超过 tRC，保持时间变成零或负，所以发送端要保证时钟上升时间不超过上限时保持时间不小于零（S1 p7 注 4）。
- S1 p6 表 2 的接收端保持时间“最小值”列写的条件是“小于 0”，p5 图 3 把 tHC 写成“0.35”缺了 T；本条目按 p7 表 3 的比例写法取值。这两处是原件的排印不一致，不影响取值。

## 设计时要核的条件

1. **谁是控制器**：位时钟和字选择只能由一个器件产生；其余器件是目标，从控制器接收时钟（S1 p3）。几个发送端、接收端并存、没有天然控制器时，由系统控制器统一给时钟，发送端按外部时钟送数据（S1 p3）。
2. **格式一致**：两端的帧格式（I2S、左对齐、右对齐、DSP、TDM）、字长、位时钟与帧的比、字选择极性、位时钟的有效沿，在两端手册里逐项对上；I2S 规范里字选择为低是左声道（S1 p5），其他格式的字选择极性按器件手册，不能照搬（S2 p16–17、S3 p13）。
3. **建立、保持时序有余量**：发送端的时钟到数据延迟、走线延迟、接收端的建立和保持，按保证值算，不用典型值（G04-011、G02-003、G02-022）。位时钟越快，余量越要紧。
4. **位时钟速率对得上**：位时钟至少等于通道数乘字长乘采样率；TDM 的时隙数乘时隙宽度不超过一帧的位时钟数（S3 p13、p14）。
5. **时钟占空比**：位时钟高、低电平时间不短于 0.35 倍周期；某些器件的帧同步在立体声模式下要求 50 % 占空比（S1 p5；S3 p13）。
6. **时钟的来源和抖动**：编解码器的主时钟、位时钟和帧时钟必须同源，或帧、位时钟由编解码器自己从主时钟分出；两个互不同步的时钟域直接相接，会丢样或有爆音（见 [audio-codec](../../典型电路/audio-codec.md)）。
7. **电平兼容与耐压**：两端的输出高、低电平和输入门限，按各自供电的最坏组合核（G04-003、G04-004、G04-005）；跨电压时加电平转换器时按 [level-translation](../../典型电路/level-translation.md) 选，速率较高时看转换器的最高速率。
8. **时钟线的上电和断电状态**：时钟停止时芯片的行为按手册：有的会自动进入低功耗并在时钟恢复后自动重新锁定（S3 p11）；时钟脚上电、复位期间由谁驱动要明确（G04-010）。
9. **线长与串联端接**：板内几厘米到十几厘米的线，常见做法是在驱动端串联小电阻限制边沿、抑制反射；线长大于信号上升时间（ns）数值的英寸数时才需要考虑端接，这条是教材经验（参见 [SPI](SPI.md) 的线长与端接表）；本条目没有取得音频接口专门的线长限值；位时钟、帧时钟、数据三条线并行走线并长度接近，把约束交给 PCB（G04-014）。
10. **PDM 麦克风的时钟线**：时钟线上挂多只麦克风时总电容上升，边沿变慢；PDM 数据在时钟的哪个沿有效由麦克风的选择脚（左、右）决定，两只麦克风共线时必须一只左一只右（S3 p11）。

## 两端各要交代什么

| 交代的量 | 谁给 | 另一端怎么用 |
|---|---|---|
| 控制器还是目标；位时钟、帧时钟谁驱动 | 两端 | 确定时钟方向，避免两个输出对接 |
| 帧格式、字长、时隙宽度、时隙数、每个通道占第几个时隙 | 两端 | 配置对端格式，核位时钟速率 |
| 采样率、位时钟与采样率之比、允许的采样率范围 | 控制器 | 目标端核自己支持的位时钟范围 |
| 位时钟高、低电平时间，边沿速率，占空比 | 控制器输出端 | 目标端核输入要求 |
| 数据相对位时钟的建立、保持（或时钟到输出延迟） | 发送端 | 接收端核余量 |
| 输入门限、输出电平、输入耐压、电源 | 两端 | 核电平兼容（G04-003、G04-005） |
| 时钟停止与恢复时的行为；多片共线时未用时隙是否三态 | 目标端 | 控制器知道可否停时钟，多片共线时不冲突 |

## 准则没有覆盖的条件

- 准则里没有针对音频串行接口的条目；本条目引用的 G04-011、G02-022 是同步接口的一般性时序条目。
- 位时钟抖动对转换器信噪比的影响没有现成的限值：主时钟抖动按编解码器手册要求，原件常只给“应使用低抖动时钟”的说明。
- 数字音频线上高速边沿对模拟部分的串扰没有数值；做法见 [audio-codec](../../典型电路/audio-codec.md) 的布局要点。
