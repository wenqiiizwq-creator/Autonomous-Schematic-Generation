# 接口约定

类型：模式、事实。层次：块与块之间。状态：27 条已写（参数模板 5、总线与电平 16、环境与电磁等级 6），均过来源核对。

回答：两个功能块之间要交代哪些参数，才能各自设计而不必看对方；常用逻辑电平和总线在电气上的约定是什么。

## 目录

| 目录 | 内容 |
|---|---|
| `参数模板/` | 按接口种类，列出源端要保证、负载端要声明的量，以及两端合起来要成立的条件 |
| `总线与电平/` | 每种总线或电平族的电气约定、设计时要核的条件、两端各要交代什么 |
| `环境与电磁等级/` | 端口和整机所处环境的约定：供电网的稳态、瞬态、尖峰和应急范围，各类端口的抗扰度试验项目与电平，军用雷电感应瞬态，航天热真空的温度裕量，车载 12 V、24 V 电源瞬态，医疗电气的隔离与漏电流。写标准给的数和适用条件，以及设备侧据此要定的量 |

全部条目和来源核对结果见 [条目总表](../条目总表.md)（工具生成，随条目更新）。

## 来源的写法与核对

- 条目开头列来源清单：`- S1：<相对 ../HardwareWiki/raw/ 的路径>`。
- 表格最后一列叫“来源”，写 `S1 p43`，可带表号或条款号；正文里写 `（S1 p50）`。
- `python3 ../工具/check_sources.py <条目或目录>` 逐行核对：文件存在、页码存在、表格里的数能在所引页的文字里找到。新条目要过这项核对。

## 条目写什么

分两部分。

**接口参数模板**：按接口种类，一种一个文件，列出源端要保证什么、负载端要声明什么。例如：

| 接口种类 | 源端要保证 | 负载端要声明 |
|---|---|---|
| 电源轨 | 电压上下限、电流能力、故障时不超过的上限 | 可接受的电压范围、最大取用电流、上电时序要求 |
| 带热插拔或负载开关的电源轨 | 另加：限流下限、允许的启动负载 | 另加：输入电容、启动电流、短路限流上限 |
| 逻辑信号 | 输出高低电平、最高电压、驱动方式 | 输入门限、耐压、漏电流 |
| 模拟量 | 量程、源阻抗 | 满量程、输入阻抗、允许的注入电流 |
| 差分对 | 差分阻抗、共模范围 | 端接、共模范围 |

**电平与总线约定**：每种逻辑电平族、每种总线一个文件，写电气门限、上拉或端接要求、总线电容或长度限制，以及标准号与条款。

## 来源

逻辑电平取自 JEDEC 标准或器件手册；总线取自各自的规范（I2C、RS-485、CAN、USB、以太网），原件在 `../HardwareWiki/raw/Standard/`。

## 与其他组件的关系

- 具体器件的门限数值在 [`器件参数/`](../器件参数/README.md)；这里写的是这一类接口共同的约定。
- 接口上常见的错法在 [`失效与异常工况/`](../失效与异常工况/README.md)。

## 与设计准则的分工

准则 G04 里已有的总线核对条件（I2C、RS-485、CAN、以太网等），条目里只写一句话加准则编号；准则没有的条件才展开，并列在条目末尾的“准则没有覆盖的条件”。电气约定表（标准里的数）只在这里存。

## 待补

- 高速接口（HDMI、MIPI、DDR、PCIe）、音频接口、无线模块接口还没有。
- SD 完整规范的电气章节、RMII 规范、TP-PMD（百兆发送幅度、回损、开路电感）、IEEE 1149.1、NAMUR NE 43 原文没有，相关的量在条目的“缺的量”里。
- 知识库没有 JEDEC JESD8、TIA/EIA-485、ISO 11898、TIA-232、IEC 61131-2 的标准原文，相关条目的数是厂家手册和应用笔记转述，条目里都写明了。
