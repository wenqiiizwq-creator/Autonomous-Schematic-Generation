# 带限流开关的电源轨

类别：接口参数模板。

适用范围：源端在电源轨上串有会主动限流的开关——热插拔控制器加外部 MOSFET、eFuse、带限流的负载开关或配电开关——把这条轨供给一个或几个负载块。开关可以在限流后经计时关断、锁死或自动重试。本模板在 [电源轨](电源轨.md) 之上增加限流、启动和保护配合的量；电源轨模板里的量和条件照样适用，这里不重复。

下面各量的取值步骤见 [热插拔与限流开关](../../计算方法/热插拔与限流开关.md)（源端开关）和 [限流供电负载侧核算](../../计算方法/限流供电负载侧核算.md)（负载一侧）；实现这类轨的电路见典型电路 [hotswap-latch-powerlimit](../../典型电路/hotswap-latch-powerlimit.md)、[ideal-diode-hotswap](../../典型电路/ideal-diode-hotswap.md)、[efuse-aux-branch](../../典型电路/efuse-aux-branch.md)、[efuse-bfet-short-latch](../../典型电路/efuse-bfet-short-latch.md)、[ovp-cutoff-efuse](../../典型电路/ovp-cutoff-efuse.md)、[discrete-load-switch](../../典型电路/discrete-load-switch.md)、[high-side-quad](../../典型电路/high-side-quad.md)；航天母线上的限流器等级见 [航天限流供电接口](../总线与电平/航天限流供电接口.md)。

本模板只列量和条件，不给某条轨的取值。表中“说明”里出现的数是来源里的举例或某类器件的典型值，用来说明这个量通常怎样写，不是本模板的要求。

S1、S2 写的是航天器母线上的锁存限流器（LCL）；其中由开关物理（限流、计时、安全工作区、负载电容充电）推出的要求，对热插拔控制器、eFuse 和负载开关同样成立，下文按这一口径引用。S6 把过流保护的类型、额定电流、限流值和持续时间列为电源接口必须交代的数据（S6 p57）。

## 源端要保证的量

| 量 | 说明 | 为什么要 | 来源 |
|---|---|---|---|
| 限流值的下限与上限 | 在全温度、全电压和器件容差下，开关开始限流的电流的最小值和最大值，例如 1 A 级配电开关限在 1.1–1.4 A；或给出设定值加精度，例如 ±8 %。 | 下限决定负载能取多大电流而不被限住；上限决定故障时下游走线、连接器和上游源要承受多大电流。只给典型值，两头都判不了。 | S1 p16 表3-1、p24；S4 p5 |
| 限流值随开关压降的变化 | 开关压降大时限流值是否下降：功率限制（限流值为设定电流与 P_LIM/V_DS 中的较小者）、热折返（例如功耗超过 10 W 时下降 0–15 %）。 | 启动和短路时开关压降最大，此时实际限流值最低，负载电容的充电电流和启动负载都要按这个最低值算。 | S3 p3；S4 p5–6 |
| 过载限流值与短路限流值 | 开关处于低阻导通（线性区）时的过载限流值，和处于饱和区（输出被拉低、压降大）时的短路限流值，二者可以不同。 | 正常工作时过载按前者动作，启动和短路时按后者；负载工作电流若落在两者之间，热插入时输出可能升不到额定值。 | S5 p4、p8 |
| 快速关断阈值与响应时间 | 硬短路时快速关断的电流阈值和关断时间，例如阈值为限流设定值的 1.6 倍、在 200 ns 内切断。 | 限流环路带宽有限，硬短路的峰值电流靠它截断；上游源和通路要承受这段峰值。 | S4 p5 |
| 短路时的电流过冲 | 突然短路时开关输入、输出电流的过冲峰值、到达峰值的时间、回到限流值的时间和过冲电荷，例如不超过 50 A、5 µs、300 µs、1 mC。 | 上游源和同一母线上的其他负载要承受这次过冲；它也要求负载和线缆电感在规定范围内。 | S1 p37 5.4.1.1 |
| 故障计时 | 限流（或功率限制）持续多久后关断：最小值和最大值，例如 1 A 级为 10–20 ms；或电路断路器式的固定超时，例如 4 ms。 | 最小值决定负载电容必须在多长时间内充满；最大值决定开关在故障时承受的应力时间和上游承受限流的时间。 | S1 p16 表3-1、p25；S3 p4–6；S4 p5 |
| 过流响应方式 | 过流时是持续限流直到过热关断，还是计时到后断开（断路器式），或二者兼有。 | 持续限流允许短时过载而不断电；断路器式在超时后立即断开。负载能否容忍短时过载、需不需要立即断开，由此决定。 | S4 p5 |
| 故障后的恢复方式 | 锁死（需要重新使能或重新上电）还是自动重试；自动重试的重试间隔和触发条件，例如过热关断后结温下降 12 °C、再等 128 ms；限流器自动重试的最小间隔，例如 20 s。 | 负载和系统要知道故障后轨会不会自己回来、多久回来；反复重试期间开关和负载输入件要承受重复应力。 | S4 p5、p8；S1 p12、p43 |
| 两次开启之间的最小间隔 | 外部开启命令之间允许的最小时间，例如 1 s。 | 连续开启会叠加开关的热应力。 | S1 p38 5.4.1.4 |
| 反复过载下的行为 | 过载反复出现（例如与负载欠压保护形成打嗝）时，开关能否保证在结温达到额定值前关断；计时器上升与下降的时间常数之比。 | 计时器在每次过载间隙被清零时，开关可能一直不关断而过热失效。 | S1 p29；S2 p40–42 |
| 启动方式与启动电流 | 输出上升时开关处于哪种控制：限流、功率限制，还是由输出斜率控制电容（dV/dt）限定充电电流；对应的启动电流、输出斜率和电流变化率上限，例如 1 A/µs。 | 负载电容的充电电流和开关在启动时的功耗都由启动方式决定。 | S3 p4、p6；S4 p4；S1 p38 5.4.2.1 |
| 允许的最大负载电容 | 在规定的启动方式下，开关能在故障计时内充满、且不超出安全工作区的负载电容上限；给出它所依据的电压上限和启动负载条件。 | 负载电容超过它，启动时计时到点关断，或开关在启动中损坏。 | S1 p16 表3-1；S2 p31；S3 p11–12 |
| 允许的启动负载 | 输出上升期间负载可以同时取用的电流或电阻性负载，例如启动时接 10 Ω；或要求负载在电源好之前保持关断。 | 启动负载占用一部分限流值，还使开关功耗波形不再是方波，启动时间和开关应力都变大。 | S3 p9、p11、p18；S4 p11 表1 |
| 允许的最长启动时间 | 从开启到输出达到额定值，开关允许的最长时间；由故障计时和计时器容差决定。 | 负载电容充电和启动负载要在这段时间内完成。 | S1 p38 5.4.2.3；S3 p4、p14 |
| 能承受的故障情形 | 带短路启动（开启时输出已短路）、热短路（工作中输出短路）、热插拔后立即重插，开关是否都能在额定值内承受。 | 这些情形下开关承受的应力最大；源端不保证时，负载侧或系统要另加措施。 | S3 p4–5、p11；S1 p27 5.2.7.5 |
| 导通压降与量测点 | 额定电流下开关通路（含采样电阻）的压降，以及量测从哪里到哪里，例如从调节点到输出连接器、不超过额定电压的 1 %。 | 进入轨的压降分配；只写导通电阻不写电流和量测点，压降会被低估。 | S1 p41 5.4.5 |
| 开关的稳态损耗与温升 | 最大负载电流下开关的导通损耗和由此决定的外壳温度；导通电阻随结温的变化要计入。 | 进入功率和损耗预算；稳态温度高时开关的安全工作区要降额，启动和短路裕量随之变小。 | S3 p8、p12–13；S4 p2 |
| 关断时的续流与电流变化率 | 关断或限流后断开时，负载和线缆电感中的电流经什么路径续流；关断电流变化率上限，例如 1 A/µs。 | 电感电流被突然切断会在开关两端产生过压。 | S1 p27 5.2.7.7、p38 5.4.2.2 |
| 限流状态下允许的负载电感和输出阻抗 | 开关在限流状态下能稳定工作的负载电感上限（含线缆和输入滤波，例如 300 µH）；限流状态下的输出阻抗随频率的变化。 | 限流环路的稳定性取决于负载；负载端要据此核对源–负载稳定性。 | S1 p33–34、p44；S2 p36–39 |
| 欠压锁定与使能阈值 | 开关的输入欠压关断阈值、开启阈值、回差和响应时间，例如回差大于 0.5 V，短于 500 µs 的欠压不动作。 | 决定母线跌落多少时轨被切掉、恢复到多少时重新开启。 | S1 p39–40；S4 p4 |
| 过压保护方式 | 输入过压时是切断输出还是把输出箝位在某个电压，以及阈值，例如 12 V 输入在 16.5 V 时切断，或输出箝位在 15 V 左右。 | 切断时负载断电，箝位时负载继续工作但输入电压升高到箝位值；负载的耐压和行为要与之配合。 | S4 p7 |
| 反向电流阻断 | 开关有无反向电流阻断；有的写阻断的检测条件和关断时间，例如 1 µs。 | 单个 MOSFET 的体二极管会让输出侧的储能电容倒灌回输入；负载有大保持电容或多源供电时要知道。 | S4 p6–7；S1 p30 |
| 输出放电 | 开关关断时输出是否主动放电。 | 不放电时掉电过程由负载决定；放电会把轨拉到地。见电源轨模板的掉电时序条件。 | S4 p9 |
| 状态与电流监测输出 | 电源好、故障标志、电流监测输出的含义、门限和精度；电源好是否只在开关完全导通且输出达标时给出。 | 负载用电源好控制自己的启动；状态信号的含义不清，负载可能在输出未达标时就开始取电。 | S4 p10；S1 p28、p43 |
| 单一故障下开关可能的状态 | 开关失去限流但仍能通断、开关常通、开关耗散失效（压降约 4–5 V）时，输出上会出现什么。 | 负载要能承受这些状态；功率预算要覆盖开关常通而断不开的情况。 | S1 p12、p31、p36；S2 p52–58 |

## 负载端要声明的量

| 量 | 说明 | 为什么要 | 来源 |
|---|---|---|---|
| 输入电容（按容差上限） | 挂在这条轨上的全部电容：输入滤波、去耦、下游转换器的输入电容，按容差上限和最坏温度写。 | 与源端允许的最大负载电容比较；也决定启动时开关耗散的能量。 | S1 p44 5.5.2.2；S3 p12 |
| 输入电感（含线缆） | 输入滤波电感加上开关到负载的线缆电感。 | 与源端允许的负载电感比较，关系到限流环路的稳定性和过冲电荷。 | S1 p44 5.5.2.1、p37 |
| 启动期间的取用电流 | 轨电压从零上升到额定值的过程中，本块在各个电压下取多少电流；本块在什么条件下开始取电（输入电压达到某值、收到电源好信号、软启动开始）。 | 启动负载与充电电流一起占用限流值；在饱和区限流值较低时，负载电流若大于它，输出会停在中间电压。 | S3 p9、p11；S5 p8；S2 p33 |
| 输入滤波充电时间 | 以源端限流下限给本块充电时，充满输入滤波所需的时间。 | 必须短于开关的最小故障计时并留有余量。 | S1 p35 5.3.2.3、p38 5.4.2.3；S2 p32–34 |
| 后级转换器启动时的电流 | 本块内转换器启动时，为其输出电容和后级负载充电而额外取用的电流和持续时间。 | 这部分浪涌不应靠上游开关限流来控制；上游开关一旦限流就成了电流源，开关转换器在高阻源上可能工作不正常。 | S2 p33；S1 p35 5.3.2 |
| 本块自带的输入限流 | 本块内部有限流或下级限流开关的，写各路限流值的上限、故障计时和恢复方式。 | 与上级限流比较，决定故障时谁先动作。 | S1 p46 5.5.5；S2 p46–49 |
| 本块的输入欠压保护 | 关断阈值、恢复阈值、回差和延时。 | 上级限流使输入电压下降时，欠压保护会切断负载、过载消失、电压回升、再次开启，形成打嗝；要一并分析。 | S1 p36 5.3.5；S2 p43–45 |
| 正常工作期间的电流包络 | 稳态最大电流，加上负载阶跃、母线瞬态、纹波经输入滤波谐振引起的附加电流和自身传导发射。 | 这些叠加后的电流都必须低于源端限流下限，否则会误限流甚至计时关断；限流值较小时影响更显著。 | S1 p35 5.3.1；S2 p34 |
| 失去限流时的冲击电流 | 开关失去限流、相当于把额定电压直接接到本块时的峰值冲击电流。 | 开关、负载输入滤波元件和母线都要承受它；输入电感饱和时更大。 | S1 p45 5.5.4；S2 p52–53 |
| 开关耗散失效时的行为 | 输入电压因开关耗散失效而降低时，本块是照常工作、自主进入安全状态，还是能挺过且不产生异常发射。 | 这是开关单一故障时负载端必须有确定的行为。 | S1 p36 5.3.3；S2 p59 |
| 输入阻抗包络 | 输入阻抗的幅值和相位随频率的变化，例如 100 Hz–1 MHz。 | 与开关限流状态下的输出阻抗比较，核对源–负载稳定性。 | S1 p45 5.5.2.3 |

## 两端合起来要成立的条件

符号：I_lim 为开关的限流值，min、max 为其在全条件下的下限、上限；t_trip 为故障计时；t_start 为从开启到输出达标的时间；C_load、L_load 为负载输入电容、电感（含线缆）；V_max 为开关输入电压上限。

| 编号 | 判据 | 说明 | 来源 |
|---|---|---|---|
| K1 | I_lim,min > I_self,max + ΣI_load(正常工作电流包络) | 正常工作中的负载电流，包括母线瞬态、纹波和传导发射引起的部分，始终小于额定电流，而额定电流低于限流下限。出处是定性要求。 | S1 p16、p35 |
| K2 | 限流设定值至少比最大负载电流高 10 %，并以设定容差下的最小值复核 K1 | 出处用这个裕量覆盖控制器限流容差。 | S3 p12 |
| K3 | t_start,max ≤ 80 % × t_trip,min，t_start,max 按 I_lim,min、C_load,max 和最坏工况算 | ECSS 对负载输入滤波充电时间的规定。 | S1 p38 |
| K4 | t_trip ≥ 1.5 × t_start,max，t_start,max 按典型限流值和功率限值算 | TI 用这个系数覆盖功率限值、计时电流和计时电容的偏差。 | S3 p14 |
| K5 | C_load,max × V_max ≤ 70 % × I_lim,min × t_trip,min | 以限流下限恒流充电，充到最高电压所需的时间不超过最小计时的七成；出处另留 10 % 给拖拽效应。七成是标准的等级表定最大负载电容用的系数；负载一侧核实际充电时间时，准则 G03-052 的判据是不超过最短跳闸时间的八成，拖拽效应另行修正，见 [限流供电负载侧核算](../../计算方法/限流供电负载侧核算.md)。两个系数用途不同，不要混用。 | S2 p31 |
| K6 | 用 dV/dt 控制启动时，I_inr = C_load × dV/dt；功率限值 P_LIM ≥ 2 × V_IN,MAX × I_INR,MAX，使启动期间计时不运行 | 负载在启动期间关断时成立。 | S3 p18、p19 |
| K7 | 输出上升全过程中，I_inr + I_startload(V_out) 小于当时的实际限流值（开关处于饱和区时取短路限流值） | 不成立时输出停在中间电压，直到计时到点关断。出处的例子中工作电流 2 A 大于短路限流值 0.91 A，热插入后输出升不到 5 V。 | S5 p8 |
| K8 | 负载内的转换器启动时，负载电流不超过额定电流；开关的限流只用来限制输入滤波的充电电流 | 出处是定性要求。 | S1 p35 |
| K9 | 启动、热短路、带短路启动三种情形下，开关的功耗脉冲（非方波按等能量折算为方波）在最高外壳温度降额后的安全工作区内，且留 1.5 倍余量 | 热短路时开关承受 P_LIM 持续 t_trip，通常最严酷。 | S3 p4、p10、p14 |
| K10 | 负载在启动期间关断时，开关在一次充电中耗散的能量等于 ½ × C_load × V²，与充电快慢无关；有启动负载时另加启动负载在开关上产生的能量 | 拉长充电时间可以降低功率，但能量不变；用于 K9 的折算。 | S3 p12、p18 |
| K11 | 下级限流：I_lim,sec,i,max + 其余各下级支路电流之和 < I_lim,prim,min | 满足时上级不会进入限流，二者计时无须配合；出处建议总按这一条设计。 | S2 p49 |
| K12 | K11 不成立时：t_trip,sec < t_trip,prim，两者相差约 50 %；且下级负载的输入滤波在下级计时内充满 | 否则下级限流时上级先计时到点，整路断电。 | S2 p49 |

- K5 的式子是按 S2 p31 所说的依据（限流下限、最小计时、最高母线电压、七成系数）写出的；用它复算 S1 p16 表3-1 的最大负载电容，结果与表中数一致。
- K3 与 K4 是两种写法：K3 按限流下限和最坏工况直接算最长启动时间，K4 按典型值算再乘系数；用哪一种，取决于源端给的是保证值还是典型值。

## 什么时候这份模板不够用

- 几个限流开关并联供一条轨：总限流值通常小于各路之和，均流、计时和开启命令要另外约定；开关断开时还要承受与输入相同的输出电压（S1 p30；S2 p49–51）。
- 开关用作电源切换或冗余“或”（两路源经开关接到同一条轨）：要另外规定两路之间的反向电流、切换时间和二极管模式的行为（S4 p6、p10）。
- 开关放在回流线上，或用一个限流开关带一组受控的开关负载：负载侧开关在上级限流时会进入线性区，热设计要按这一故障另算，本模板未覆盖（S2 p47）。
- 负载是加热器等纯电阻负载、几乎没有输入电容：限流计时和允许电容按另一套取值（ECSS 的加热器限流器），本模板的启动条件不适用（S1 p18）。
- 开关在上电时自动开启、在故障后自动重试，且所供负载是必须持续供电的关键负载：重试的允许、禁止和防误操作要在系统层另外规定（S1 p26、p34；S2 p61–62）。
- 源端带输出过压箝位而负载要在箝位期间继续工作：箝位持续时间受开关过热关断限制，需看具体器件（S4 p7）。
