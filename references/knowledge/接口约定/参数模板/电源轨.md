# 电源轨

类别：接口参数模板。

适用范围：一个功能块（源端）向另一个或几个功能块（负载端）供一条直流电源轨，两边各自设计，只靠本模板列出的量对接。源端可以是稳压器、DC/DC、上游母线或板外输入；负载端可以是一个块，也可以是挂在同一条轨上的几个块。源端带热插拔控制器、eFuse 或负载开关、会主动限流的，另加 [带限流开关的电源轨](带限流开关的电源轨.md) 的量。

本模板只列量和条件，不给某条轨的取值；数值由需求、标准或器件手册给出。表中“说明”里出现的数是来源里的举例，用来说明这个量通常怎样写，不是本模板的要求。

## 来源

- S2：Standard/ECSS-E-HB-20-20A 电源电气设计与接口要求指南 - 2016.pdf
- S3：Standard/ECSS-E-ST-10-24C Rev.1 接口管理 - 2024.pdf
- S4：Standard/ETSI EN 300 132-2 V2.8.1 ICT设备输入电源接口 第2部分 -48V直流 - 2024.pdf
- S5：Standard/MIL-STD-1275F Characteristics of 28 Volt DC Input Power to Utilization Equipment in Military Vehicles - 2022.pdf
- S6：Applicationnote/TI - 2004-05电源设计研讨会合集（含多轨上电时序） - SLUP224.pdf
- S7：Applicationnote/TI - eFuse基础 - SLVA862A.pdf

页码一律是 PDF 文件的页序（第 1 页是封面或首页），不是印在页脚上的页码；两者在 S5 不一致。

接口约定的口径取自 S3：一个接口分两端，各端由负责的一方给出本端数据，接口负责人核对两端数据彼此一致、相互兼容（S3 p10、p26）；电源接口要交代的数据项见 S3 p56–57 E.3.4；每个对外电气接口都要规定并核实故障发射和故障耐受，用电压和电流表示（S3 p31 5.8.1h）。下面两张表就是这两端的数据。

## 源端要保证的量

| 量 | 说明 | 为什么要 | 来源 |
|---|---|---|---|
| 稳态电压上下限，及它所在的点 | 正常工作时轨电压的最小值和最大值，并写明是在调节点还是在负载输入端量的。同一条母线在调节点和负载端的范围可以不同，例如 28 V 调节型母线在调节点为 ±1 %，在负载端为 −5 % / +1 %。 | 调节点到负载之间有路径压降；不写量测点，负载端会拿调节点的范围去比，低端裕量被高估。 | S1 p23 表5-1；S4 p11、p13；S3 p56 |
| 纹波 | 纹波幅值和所覆盖的频段，例如 ±500 mVpp、30 Hz–50 MHz；或峰峰值与频段，例如 4 Vpp、30 Hz–5 kHz。 | 负载的电压裕量要扣掉纹波；只给幅值不给频段，负载无法判断哪些成分会穿过它的输入滤波。 | S1 p23 表5-1；S5 p11 |
| 负载阶跃引起的电压瞬态 | 瞬态幅值，连同对应的阶跃大小和电流变化率，例如 50 % 负载阶跃、1 A/µs 时 ±1.4 V；电源自身调节引起的缓慢变化写变化率。 | 稳态范围不含瞬态；负载要用“稳态加瞬态”的包络判断自己会不会掉出工作范围。 | S1 p23 表5-1；S4 p17 表5 |
| 异常稳态电压范围 | 不在正常范围、但会出现且源端不保证性能的稳态电压，例如从 0 V 到某个上限。 | 负载在这个范围内要不损坏、回到正常后能自己恢复；不写，负载只按正常范围设计耐压和恢复逻辑。 | S1 p22–23；S4 p13 表2 |
| 故障时不超过的电压上限（故障电压发射） | 源端自身故障或误操作时，接口上可能出现的最高电压。 | 负载的耐压（绝对最大值）要高于它；正常上限不能代替它。 | S1 p11 3.2.7、p23 表5-1；S3 p31 |
| 异常瞬态 | 短路及保护动作、开关操作、雷击等引起的跌落和过冲：幅值、持续时间、波形或能量。 | 这些瞬态会超出稳态异常范围；负载要据此选箝位和储能，并决定期间要不要保持工作。 | S1 p23 表5-1；S4 p14–16；S5 p12–13 |
| 持续电流能力 | 源端在整个稳态电压范围内能长期供出的最大电流。 | 负载电流之和要不超过它；它也是下游走线、连接器和保护选型的依据。 | S3 p56–57；S1 p35 |
| 源块自耗与可供外部的电流 | 源块自己的电路也从这条轨取电时，分别写出本块自耗的最大值，和交给接口、可供外部负载用的电流。 | 能力要覆盖轨上的全部取用；只写总能力，负载端会把本块自耗也当成自己可用的电流。 | S3 p56；S1 p31；S2 p48–49 |
| 源端保护的类型与动作值 | 熔断器、断路器或其他过流保护：额定电流、动作电流和动作时间；源端会主动限流的，按带限流开关的模板写。 | 负载的稳态电流、低压时的电流和浪涌都不能使它动作；动作后负载会断电。 | S4 p17 4.5、4.6；S3 p57 |
| 源端输出阻抗 | 源端输出阻抗的幅值和相位随频率的变化，例如 100 Hz–1 MHz。 | 与负载输入阻抗比较才能判断源–负载系统是否稳定；负载的输入滤波会与它谐振。 | S3 p56；S1 p33；S2 p39–40 |
| 上电时输出电压的上升 | 上升时间或斜率，是否单调，从使能到电压达标的延迟；有电源好信号的，写它在什么电压、什么时刻给出。 | 负载的浪涌电流和上电时序都取决于它；源端母线本身的上升斜率也会影响下游开关的状态。 | S3 p56；S1 p21 4.2b；S6 p27 |
| 关断状态下的输出 | 源端关断或母线刚上电、本路尚未开启时，输出上可能出现的电压和漏电流，例如关断时输出低于 1 V、漏电流不大于 100 µA，母线上电时输出脉冲不超过 5 V、1 ms。 | 负载要在这样的电压下保持关断，不进入不确定状态。 | S1 p38–39；S2 p35 |
| 掉电与关断时的放电方式 | 关断后输出是浮空、由负载自己放电，还是由源端主动放电；主动放电的放电速度。 | 输出浮空时掉电过程完全由负载决定，负载可能停在未定义状态；主动放电又可能把另一条轨还在工作的负载引脚拉到地。 | S7 p9 3.10；S6 p29 |
| 欠压关断阈值与回差 | 源端设有输入或输出欠压关断的，写关断阈值、恢复阈值和响应时间。 | 负载要知道轨在多低时会被源端切掉，并与自己的欠压保护协调。 | S3 p56；S1 p39–40 |
| 过压保护 | 源端设有过压保护的，写阈值和动作方式（切断或箝位）。 | 决定故障电压发射的实际上限，以及过压时负载是断电还是继续工作。 | S3 p56；S7 p7 |
| 承受反向电流的能力 | 源端在开通和关断状态下能吸收的负载回注电流，峰值与持续时间，例如峰值等于额定电流、10 分钟内线性衰减；不能吸收的写“不能”。 | 电机、大保持电容等负载会把电流送回轨上；源端不能吸收时要另加阻断。 | S1 p30、p37；S2 p51 |

## 负载端要声明的量

| 量 | 说明 | 为什么要 | 来源 |
|---|---|---|---|
| 正常工作电压范围 | 在本块输入端、性能不降级的输入电压最小值和最大值，并写明是否已含纹波。 | 与源端在负载端的电压包络比较；超出部分要么改源端，要么改负载。 | S4 p11；S5 p11；S1 p22 |
| 不损坏的电压范围（故障电压耐受） | 本块能承受而不损坏的最低和最高输入电压，即输入端器件的绝对最大值决定的范围。 | 与源端的故障电压发射、异常稳态和异常瞬态比较。 | S1 p11 3.2.8、p22；S3 p31；S4 p13 表2 |
| 能耐受的纹波和瞬态 | 本块在不降级前提下能承受的纹波（幅值、频段）、尖峰和浪涌（幅值、持续时间或能量）。 | 源端的纹波和瞬态要落在它之内；它也决定负载输入滤波和箝位的设计。 | S5 p11–13；S4 p15–16 |
| 越限后的恢复方式 | 电压回到正常范围后本块是否自动恢复、需不需要人工干预、恢复要多久。 | 异常电压和瞬态之后，负载不应停在故障状态，也不应使源端保护动作。 | S4 p13、p16 |
| 输入欠压保护 | 本块设有输入欠压保护的，写关断阈值、恢复阈值（回差）和响应延时。 | 回差防止阈值附近反复通断；延时防止负载阶跃等瞬态引起误关断；阈值还要与源端的最低电压协调。 | S2 p43；S1 p36 5.3.5 |
| 稳态最大取用电流 | 本块在各工作模式下的最大稳态电流，并写明对应的输入电压；同时给各模式的平均功耗和峰值功耗。 | 源端电流能力和保护要按它选；只给额定电压下的值会漏掉低压时的电流。 | S4 p17–18；S3 p31 5.8.1l |
| 电流随输入电压的特性 | 输入电流与输入电压的关系，至少给出最低输入电压下的电流；恒功率负载在低压时电流变大。 | 源端保护在最低电压下也不能动作，例如 ETSI 要求 40.5 V 时的电流不大于额定电压下最大电流的 1.5 倍，并要求给出 I(U) 曲线。 | S4 p17–18 表6 |
| 峰值电流与电流变化率 | 负载阶跃、脉冲负载的峰值电流、持续时间和电流变化率。 | 源端的瞬态响应和保护都要容得下；电流变化率还决定瞬态电压的大小。 | S3 p57；S1 p23、p35 |
| 上电浪涌电流 | 接通时的浪涌电流峰值、持续时间和波形；分开输入滤波充电和后级转换器启动两部分。 | 浪涌会使源端保护动作，或拉低同一条轨上其他负载的电压。 | S3 p57；S4 p18–19；S2 p32–33；S7 p4 |
| 输入电容 | 本块挂在这条轨上的全部电容，含输入滤波、去耦和下游转换器的输入电容，按容差上限写。 | 决定上电浪涌和源端启动时的负担，也参与源–负载谐振。 | S1 p34、p44；S2 p31 |
| 输入电感 | 本块输入滤波电感加上本块到源端的线缆电感。 | 影响源端的稳定性和关断时的感性能量；有的源端规定了允许的最大值，例如 300 µH。 | S1 p34、p44 |
| 输入阻抗与输入滤波阻尼 | 输入阻抗的幅值和相位随频率的变化，例如 100 Hz–1 MHz；输入滤波的阻尼系数。 | 与源端输出阻抗比较判断稳定性；欠阻尼的输入滤波在谐振频率附近会放大纹波，开关转换器的负阻抗在低压满载时最差。 | S1 p45；S2 p64–65 |
| 上电时序要求 | 本块各电源轨之间的先后顺序、延迟、比例或同时上升的要求，以及任何时刻都不能超过的轨间电压差。 | 多电源器件在一条轨有电、另一条没电时可能闩锁、ESD 结构受应力或总线冲突。 | S6 p23–28 |
| 掉电时序要求 | 掉电顺序；是否要求掉电过程可控；某条轨工作时另一条轨能否被强拉到地。 | 掉电顺序错误同样会引起总线冲突或损坏；一条轨有电时把另一条强拉到地，可能损坏引脚间的 ESD 二极管。 | S6 p27、p29；S7 p9 |
| 关断状态下保持关断的条件 | 本块在输入为多高的电压、多长的脉冲时仍保持关断或保持在确定状态。 | 与源端关断状态下的输出电压比较，防止被误开启或进入不确定状态。 | S2 p35；S1 p38–39 |
| 回注电流 | 本块会不会把电流送回这条轨：峰值、持续时间或能量；例如断开输入时大保持电容的放电、电机制动。 | 与源端承受反向电流的能力比较；超出时要阻断。 | S1 p44；S2 p51；S7 p6 |
| 本块向轨上发射的纹波与尖峰 | 本块工作时在这条轨上产生的纹波电压（幅值、频段）和尖峰（幅值、能量）。 | 同一条轨上的其他负载要承受它；源端的纹波指标通常不含负载自己产生的部分。 | S5 p11–12；S1 p35 |
| 反接时的电流 | 接口可能接反时（板外输入、可插拔），本块在反极性下的输入电流，例如不大于正常工作电流。 | 反接时源端和通路要承受这个电流，负载自己不能损坏。 | S5 p10 4.1 |

## 两端合起来要成立的条件

“源端在负载端”的量，指源端的值换算到负载输入端（扣除路径压降）以后的值。条件里的符号：V 为电压，I 为电流，下标 src 为源端，load 为负载端，op 为正常工作范围。

| 编号 | 判据 | 说明 | 来源 |
|---|---|---|---|
| P1 | 源端电压范围与负载电压范围在同一个点上比较：源端给的是调节点的值时，V_src,min(负载端) = V_src,min(调节点) − ΔV_path,max | ECSS 的调节型母线把两个点的范围分开给出。 | S1 p23 表5-1 |
| P2 | 同 P1，路径压降要计入 | ETSI 的电压范围在接口点规定，接口点不在设备端子时，二者之间还有压降。 | S4 p13 注3 |
| P3 | V_src,min(负载端，含纹波和瞬态下冲) ≥ V_load,op,min | 负载工作范围的下限按含纹波写。 | S5 p11 |
| P4 | V_src,max(负载端，含纹波和瞬态上冲) ≤ V_load,op,max | 负载工作范围的上限按含纹波写。 | S5 p11 |
| P5 | V_src,fault,max ≤ V_load,fault,tol；源端的异常稳态范围和异常瞬态落在负载不损坏的范围内 | 故障电压发射不超过故障电压耐受；“不损坏”指器件额定值不被超过。 | S1 p11、p22 |
| P6 | 电压从异常范围回到正常范围后，负载自动恢复，且异常电压不使源端或通路上的保护动作 | 出处是定性要求。 | S4 p13 |
| P7 | I_src,avail ≥ ΣI_load,max；源块自身也取电时，I_src,total ≥ I_self,max + ΣI_load,max | 各负载取各自最坏工作模式；出处要求功率预算覆盖实际最大负载。 | S1 p31 |
| P8 | P7 中的 I_load,max 取负载最低输入电压下的值 | 恒功率负载低压时电流变大；出处要求给出电流随电压的特性。 | S4 p17、p18 |
| P9 | 负载在阶跃、母线瞬态、纹波和自身传导发射叠加时的电流，仍不超过源端在该持续时间内的电流能力 | 出处是对限流源的要求，同样适用于有电流上限的普通源；纹波经输入滤波谐振会附加电流。 | S1 p35 |
| P10 | 负载的稳态电流（取最低电压下的值）和上电浪涌都不使源端保护动作 | ETSI 取保护器件额定电流为额定电压下最大稳态电流 Im 的 1.5 倍；并规定浪涌电流与 Im 之比的上限曲线；浪涌的能量也要计入。 | S4 p17、p18 |
| P11 | 一个负载的上电浪涌不使同一条轨上其他负载的电压跌出 V_load,op | 出处是定性要求：浪涌拉低背板电压会影响其他负载。 | S7 p4 |
| P12 | 在源、负载阻抗幅值相等的频率上，两者相位差在 ±150° 之内；在相位差为 −180° 的频率上，源阻抗比负载阻抗高至少 5 dB | 出处针对限流源与负载，给出了源–负载稳定判据的一种数值形式。原件字面写的是“相位差大于 150°”“负载阻抗增益减限流器阻抗增益大于 5 dB”，方向写反，这里按正确理解写，与 [带限流开关的电源轨](带限流开关的电源轨.md) 的 K21 一致，依据见 [源与负载阻抗稳定性](../../计算方法/电源变换/源与负载阻抗稳定性.md)。 | S1 p45 |
| P13 | 负载输入滤波按最坏情况（输入电压范围、功耗、源阻抗、元件容差、负载阻抗）计算阻尼，阻尼系数不低于推荐值 | 指南推荐飞行条件下不低于 0.4、地面条件下不低于 0.3。 | S2 p64 |
| P14 | 负载声明的每对相关轨，在上电、掉电全过程中满足先后顺序和延迟，且任何时刻轨间电压差不超过负载声明的上限 | 出处给出了器件手册中这类限值的写法，例如两轨之差在任何时刻不超过若干伏。 | S6 p26、p28 |
| P15 | 负载声明某轨工作时另一轨不得被强拉到地的，源端在这一期间不得对该轨主动放电 | 出处是定性要求。 | S6 p29；S7 p9 |
| P16 | V_src,off,max < 负载保持关断的输入电压上限（按相同的脉冲宽度比） | ECSS 对配电开关给出了关断状态和母线上电时输出电压的上限。 | S1 p38、p39 |
| P17 | I_load,reinject,max ≤ 源端承受反向电流的能力；源端不能承受的，在负载或通路上阻断 | ECSS 建议负载不向母线回注；允许回注时，回注电流不超过额定电流，10 分钟内线性衰减。 | S1 p37、p44 |
| P18 | 负载欠压关断阈值低于源端在负载端的最低电压（含瞬态下冲），并设有回差和延时 | 出处是定性要求。 | S2 p43 |

## 什么时候这份模板不够用

- 源端会主动限流、带计时关断或自动重试（热插拔控制器、eFuse、负载开关、限流配电开关）：另加 [带限流开关的电源轨](带限流开关的电源轨.md)。这时负载的输入电容、启动负载和启动时间都受限流和计时约束（S1 p35、p38）。
- 几路源并联或互为冗余供同一条轨：均流、各路之间的反向电流、一路关断时另一路要承受的输出电压，都不在本模板里（S2 p49–51；S7 p6）。
- 轨要在源端短时中断时由储能维持（保持时间）：要另外规定保持时间和储能电容，以及中断期间对上游的回注（S4 p15；S7 p6）。
- 接口跨出板外，经线缆接到车辆、通信局站、航天器母线等：这时源端特性由对应的电源接口标准规定，要逐条套用该标准的电压、瞬态、浪涌和测试条件，本模板只给出要交代的量（S4 p10–19；S5 p10–13；S1 p22–23）。
- 负载回路不是单纯的“正端供电、负端回流到地”：例如开关放在回流线上，或接口要求隔离、浮地；接地和隔离要另外约定（S2 p47；S4 p11；S3 p57）。

## 对应准则（补）

- G01-016：对外接口的故障发射，对应源端“故障时不超过的电压上限”一行。
