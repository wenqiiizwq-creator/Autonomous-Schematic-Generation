# 模拟量

类别：接口参数模板。

适用范围：两个功能块之间传一个单端或伪差分的模拟量，两边各自设计，只靠本模板列出的量对接。常见的有：传感器或调理电路输出到 ADC、电压基准送到 ADC 或 DAC 的基准输入、电流检测放大器的输出、4–20 mA 电流环。源端是给出这个量的块，接收端是读它的块（多为 ADC 或比较器）。全差分的模拟信号和高速差分信号不在本模板，后者见 [差分对](差分对.md)；数字电平见 [逻辑信号](逻辑信号.md)。实现电路见典型电路 [adc-front-end](../../典型电路/信号与模拟/adc-front-end.md)、[opamp-stage](../../典型电路/信号与模拟/opamp-stage.md)；采样网络和噪声的取值步骤见 [SAR ADC驱动与采样](../../计算方法/信号与模拟/SAR%20ADC驱动与采样.md)、[噪声预算](../../计算方法/信号与模拟/噪声预算.md)；4–20 mA 电流环的约定见 [4-20mA电流环](../总线与电平/4-20mA电流环.md)。

本模板只列量和条件，不给某个接口的取值；数值由需求、标准或器件手册给出。表中“说明”里出现的数是来源里的举例，用来说明这个量通常怎样写，不是本模板的要求。

## 源端要保证的量

| 量 | 说明 | 为什么要 | 来源 |
|---|---|---|---|
| 信号种类与功能 | 电压还是电流；是测量值、基准还是状态；单端、伪差分还是差分；直流耦合还是交流耦合。 | 接收端按这几项选输入方式和量程。 | S1 p57 |
| 量程与传递函数 | 输出范围的最小值和最大值，以及它和物理量的对应关系（斜率、零点、单位）；超出被测范围时输出会到哪里，例如 4–20 mA 变送器把断线报警也编在电流范围里，举例的电流范围是 2.5 mA 到 27.5 mA。 | 接收端的满量程和换算都依据它；超范围和报警电平也要落在接收端能分辨的范围内。 | S1 p57；S9 p26 |
| 参考点 | 输出是对哪一个地或哪一个点量的；伪差分接法时把这个参考点单独引给接收端。 | 两块地之间有电位差时，接收端量到的是“信号加地电位差”；单独引回参考点可以把这部分消掉。 | S6 p20；S2 p20 4.1.2a |
| 输出阻抗（随频率） | 直流时的输出电阻，和在接收端关心的频率上的阻抗幅值；运放手册有的给闭环值、有的给开环值，要写明是哪一种。 | 输出阻抗和接收端的输入电容、滤波电容一起决定建立时间；对容性负载它还会产生额外相移。 | S4 p184；S2 p20 4.1.2a |
| 驱动容性负载的能力 | 能稳定工作的负载电容范围，以及对电容等效串联电阻的要求，例如某基准写明稳定的输出电容是 0.1 µF 到 22 µF；运放写允许直接接的最大电容，或要加的隔离电阻。 | 接收端输入滤波和去耦电容都挂在源端输出上；超出范围会峰化或振荡。 | S8 p7；S5 p45；S4 p112、p184 |
| 驱动能力 | 能供出和吸收的电流，负载变化引起的输出变化，短路电流，例如某基准分别给出供出和吸收电流时的负载调整率和短路电流。 | 接收端的动态负载（采样电容充电、基准输入电流）和故障时灌进来的电流都由它承担。 | S1 p57；S8 p7 |
| 带宽与建立时间 | 小信号带宽；满量程阶跃后建立到规定精度所需的时间，并写明是哪一档精度。手册常给到 0.1 % 或 0.01 %，与接收端要求的精度可能差很多。 | 接收端在采样时间内要的是建立到 1/2 LSB 以内；精度档不同，建立时间可以差很多。 | S4 p226；S6 p21 |
| 噪声 | 写明频带的噪声：低频段给峰峰值，宽带给有效值或噪声密度，例如某基准给出 0.1 Hz–10 Hz 的峰峰值和 10 Hz–10 kHz 的有效值。 | 接收端要把它积分到自己的带宽内，与自身噪声合成后再算信噪比。 | S1 p57；S8 p6 |
| 误差与漂移 | 初始误差、温度漂移（写明温度范围和计算方法）、长期稳定性（写明时长），以及失调与偏置电流随温度、时间和电源的变化。 | 接收端的误差预算要逐项累加；漂移只在一个温度区间内给出时，其他区间不能套用。 | S8 p7；S5 p45 |
| 上电、断电和故障时的最高最低电压 | 正常工作、上电和断电过程、本块故障时，这条线上可能出现的最高和最低电压，以及能流出或灌入的最大电流；运放的电源轨高于接收端基准时，输出可以越出接收端的输入范围。 | 接收端的输入耐压、钳位和限流电阻要按它设计；正常量程不能代替它。 | S1 p57；S2 p21 4.1.2f；S6 p20 |
| 关断状态下的输出 | 本块未上电或关断时，输出是高阻、被拉到某一电平还是不确定。 | 接收端在这种状态下读到什么、会不会因此误判，都取决于它。 | S1 p57；S2 p20 4.1.2e |
| 电流输出：环路电压要求与自耗 | 4–20 mA 这类电流输出，写出变送器正常工作所需的最低端电压和最高耐受电压，以及环路供电时本块自己消耗的电流；例如某变送器芯片的供电范围是 4.0 V 到 36 V，总自耗小于 4 mA 时可直接由环路供电。 | 接收端的采样电阻和线阻会吃掉环路电压；变送器自耗必须低于它要输出的最小电流，否则输不出低端。 | S9 p1、p27 |

## 接收端要声明的量

| 量 | 说明 | 为什么要 | 来源 |
|---|---|---|---|
| 满量程与基准 | 满量程对应的输入电压或电流，和它取自哪一个基准；基准输入允许的电压范围，例如某 SAR ADC 的输入范围是 0 到 VREF，基准范围 2.4 V 到 5.1 V。 | 源端的量程和误差要与它比；基准的误差和噪声直接进到结果里。 | S6 p3、p4；S7 p6 |
| 绝对输入范围与共模范围 | 每个输入引脚对地允许的工作电压范围，以及共模电压范围；内部放大器开或关时范围不同的要分别写，例如某 ΔΣ ADC 不用内部放大器时是 AVSS − 0.1 V 到 AVDD + 0.1 V。 | 伪差分接法时，参考点的地电位差也要落在这个范围内。 | S6 p3；S7 p6、p25 |
| 输入等效电路与采样电容 | 采样期间的输入等效电路：引脚电容、开关电阻和采样电容，例如某 SAR ADC 典型为 400 Ω 加 40 pF；转换期间的输入只剩引脚电容。开关电容输入在每次采样开始时会从源端抽一股电荷（电荷注入或回踢）。 | 源端要在采样时间里把采样电容充到规定精度；回踢使源端输出瞬时跌落，源端和外部滤波电容要能补上。 | S6 p20、p17；S3 p2 |
| 采样时间与采样率 | 每次采样实际可用来给采样电容充电的时间，它随采样率变化；多路复用输入还要写换通道的时刻。 | 建立条件按这个时间判；多路复用时每次换通道都相当于输入一个阶跃。 | S6 p3；S3 p2 |
| 输入电流 | 采样期间平均输入电流和漏电流的最大值，写明温度；ΔΣ ADC 分别写每个输入的电流和两输入之差。 | 源阻抗乘以它就是一项固定误差；源阻抗高时还会随温度变。 | S6 p3；S7 p25 |
| 允许的源阻抗和推荐的外部滤波 | 器件手册推荐的输入电阻电容和驱动器，以及在什么带宽和采样率下推荐；源阻抗高的场合是否要加缓冲器。 | 源端的输出阻抗加上外部电阻，必须在接收端要求的范围内。 | S6 p21；S7 p25 |
| 输入耐压与允许的注入电流 | 输入引脚的绝对最大电压，以及超出时允许流入的电流和持续时间；有内部钳位的写钳位门限和钳位能吸收的电流，例如某 SAR ADC 写明 VREF + 0.4 V 或 ±130 mA（10 ms），内部钳位最多吸收 50 mA 且不能长期承受。 | 与源端的故障电压比；超出时靠串联电阻限流，限流后的电流要在这里给出的范围内。 | S6 p4、p8、p20；S7 p5、p20 |
| 钳位电流流向 | 输入超出范围时电流经保护二极管流到哪一个引脚（电源、基准或地），以及那个引脚因此多出的电流，例如某 SAR ADC 写明钳位动作时基准引脚多出约 100 µA。 | 电流灌进基准或电源时会抬高它，影响共用这个基准的其他通道。 | S6 p4、p20 |
| 基准输入的负载 | 基准输入的电流随采样率的变化，例如某 SAR ADC 在 2 MSPS 时为 0.75 mA；基准输入是否也是开关电容。 | 基准源端要按这个动态负载选驱动能力和去耦电容。 | S6 p4；S7 p6 |
| 抗混叠要求 | 采样频率；ΔΣ ADC 写调制器频率，因为数字滤波的响应在调制器频率的整数倍附近重复，那里的成分不衰减；要求外部模拟滤波在哪些频率上衰减多少。 | 源端的噪声和干扰落在这些频率上会折回有用频带，数字滤波去不掉。 | S7 p48；S4 p222、p227 |
| 本端噪声与精度 | 接收端自身的噪声（有效值，或折合到输入的值）、积分非线性和增益误差，例如某 SAR ADC 典型噪声 37 µV 有效值。 | 判断源端噪声会使信噪比损失多少，以及误差预算还剩多少给源端。 | S6 p3、p21 |
| 本块断电时的输入特性 | 本块断电后输入引脚是否仍能承受源端的正常信号或故障信号，此时会不会经保护二极管给本块电源反灌。 | 源端上电而本块未上电时不能损坏，也不能把本块电源抬起来。 | S2 p20 4.1.2d |

## 两端合起来要成立的条件

条件里的符号：V 为电压，I 为电流，R 为电阻，C 为电容，下标 src 为源端，in 为接收端；N 为 ADC 位数；t_acq 为采样时间。

| 编号 | 判据 | 说明 | 来源 |
|---|---|---|---|
| A1 | V_src,min(含误差、噪声和超范围) ≥ V_in,op,min；V_src,max ≤ V_in,op,max | 量程要在接收端的输入范围之内，超范围和报警电平也要能分辨；伪差分接法时两个引脚分别对地也要在绝对输入范围内。 | S6 p3；S7 p6 |
| A2 | 采样电容建立到 1/2 LSB：A(t_acq) ≥ 1 − 1/2^(N+1) | A(t) 是采样电容电压与输入阶跃之比。 | S3 p3、p4 |
| A3 | t_acq 不小于把外部滤波和采样开关看成二阶低通算出的建立到 1/2 LSB 所需时间；算式与各参数的取端见 [SAR ADC驱动与采样](../../计算方法/信号与模拟/SAR%20ADC驱动与采样.md) 第 2、4 步，这里不重抄 | 把外部滤波和采样开关看成二阶低通：R1 为源端输出阻抗加外部串联电阻，C1 为外部滤波电容加引脚电容，R2 为采样开关电阻，C2 为采样电容。推导假定驱动器是理想电压源，输入阶跃发生在采样开始之后，是最坏情况。 | S3 p2、p3、p5、p8、p9 |
| A4 | 驱动器在采样时间内建立到 1/2 LSB 以内，即相对误差 ≤ 1/2^(N+1) | 手册给的 0.1 % 或 0.01 % 建立时间不能直接代替；12 位对应约 0.0122 %，16 位对应约 7.63 ppm（S6 p21 写的 16 位 15.25 ppm 是 1/2^16，即建立到 1 LSB，比本条要求的 1/2 LSB 宽一倍）。 | S4 p226；S6 p21 |
| A5 | (R_src + R_ext) × I_in,max ≤ 误差预算中分给这一项的电压 | 输入电流取工作温度范围内的最大值；源阻抗高时加缓冲器，缓冲器自身的失调、噪声和增益误差再计入。 | S6 p3；S7 p25 |
| A6 | 源端噪声积分到接收端带宽后造成的信噪比损失不超过预算：SNR_loss = 20 log( e_in / √( e_in² + (π/2) × f_−3dB × (N_g × e_N)² ) ) | e_in 为接收端自身噪声有效值，f_−3dB 为接收端输入带宽或外部滤波截止频率，N_g 为驱动器噪声增益，e_N 为驱动器输入噪声密度。 | S6 p21 |
| A7 | 源端在故障和上下电时的最高最低电压在接收端输入耐压之内；超出时 (V_src,fault − V_clamp) / R_series ≤ I_in,inj,max，且持续时间不超过手册给的时间 | V_clamp 为接收端钳位或保护二极管导通时的引脚电压；注入电流同时不能超过钳位的吸收能力。 | S6 p4、p8、p20；S7 p5、p20 |
| A8 | 故障时经保护二极管流进接收端基准或电源的电流，不使该基准或电源越出它的工作范围 | 共用一个基准的几路 ADC 中一路过压，会通过基准影响其他各路。 | S6 p4、p20 |
| A9 | 挂在源端输出上的全部电容（外部滤波电容、引脚电容、去耦）在源端声明的稳定负载范围内：C_L,min ≤ C_load ≤ C_L,max | 运放直接驱动大电容会峰化或振荡；基准类器件往往还有最小电容和等效串联电阻范围的要求。 | S8 p7；S5 p45；S4 p184 |
| A10 | 在接收端会折回有用频带的频率上（大于采样频率一半的成分；ΔΣ ADC 为调制器频率整数倍附近），源端噪声和干扰经外部滤波衰减后低于允许值 | 允许值由接收端精度和需求定。 | S7 p48；S4 p222、p227 |
| A11 | 源端参考点与接收端地之间的电位差，加上信号本身，仍在接收端的共模范围和绝对输入范围内 | 地电位差超出时，改用伪差分或差分输入把源端参考点单独引回。 | S6 p20；S2 p20 4.1.2a |
| A12 | 一端上电、另一端断电时，上电一端的正常信号或故障信号不损坏断电一端，也不经输入保护二极管给断电一端供电 | 出处是定性要求。 | S2 p20 4.1.2d、4.1.2e |
| A13 | 电流环：V_loop,min − I_loop,max × (R_sense + R_wire) ≥ V_tx,min；I_tx,self,max < I_loop,min | I_loop,max 取含报警电平的最大电流；R_sense 为接收端采样电阻，R_wire 为来回线阻。第一式由欧姆定律推出，不是引自电流环标准原文。 | S9 p1、p26、p27 |

## 什么时候这份模板不够用

- 信号是全差分的（差分驱动 ADC、仪表放大器输入）：还要给差分与共模分开的范围、共模抑制和两路之间的匹配；本模板只覆盖单端和伪差分（S1 p57）。
- 信号跨越隔离边界（隔离放大器、隔离 ADC）：要另给隔离两侧的增益误差、带宽和隔离耐压。
- 电流环上叠加数字通信（例如 HART）：要另按该通信规范给环路噪声上限和负载电阻范围，例如 S9 举例的环路噪声要求是按 500 Ω 负载给的（S9 p26）。
- 连线长、出板，或在强干扰环境里：要另给线缆类型、屏蔽和接地方式、线间阻抗和最大长度（S1 p58）。
- 接收端是比较器或带门限的判别电路：门限、回差和响应时间要另给，判据不同于本模板的采样建立。

## 待补

- 4–20 mA 电流环的标准值（正常范围之外的饱和电流和报警电流门限、负载电阻范围、最低环路电压）：知识库没有 IEC 60381 或 NAMUR NE 43 原件，现只能从变送器手册和应用笔记转述，转述的数已写在 [4-20mA电流环](../总线与电平/4-20mA电流环.md)；A13 第一式是推导。
- 桥式传感器与比值测量（激励电压与基准同源时误差相消）的接口量：S7 有比值测量的器件用法，但还没有一般性的来源说明哪些量可以因此不交代。
- 源端输出噪声与接收端带宽合成的一般算法：已按运放噪声分析应用笔记（SLVA043B）写成 [噪声预算](../../计算方法/信号与模拟/噪声预算.md)；本模板 A6 仍是 S6 针对某一 ADC 的式子，一般情形按噪声预算算。
- 运放驱动容性负载的数值判据（隔离电阻怎样取、相位裕量下限）：S4、S5 只给定性说明，要另找有数值的来源。
