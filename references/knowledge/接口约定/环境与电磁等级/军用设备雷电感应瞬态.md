# 军用设备雷电感应瞬态与相关传导敏感度（GJB 151C）

类别：环境与电磁等级（端口抗扰度约定）。
适用范围：按 GJB 151C-2024 做电磁兼容要求的军用设备和分系统，对外互连电缆和输入主电源线上的雷电感应瞬态（CS117），以及同属电缆、电源线瞬态的 CS106（电源线尖峰）、CS115（电缆束脉冲激励）、CS116（阻尼正弦瞬态）。按安装平台选项目由准则 G07-051 管；民用工业场所的浪涌按 [工业环境抗扰度等级](工业环境抗扰度等级.md)，两者不能互换（G07-052）。舰船交流电网自身的尖峰见 [舰船交流电源](舰船交流电源.md)。

另见：[车载电源瞬态](车载电源瞬态.md)（民用车载与军车 28 V 的区别）。

## 设计时要核的条件

1. **先定平台与项目**：按安装平台从表 5 取 CS106、CS115、CS116、CS117 的适用性（G07-051）。CS117 再判本设备是否安全性关键、是否与安全性关键设备相连、电缆是否敷设在舰船甲板上；判不清的列为订购方确认项（S1 p68）。
2. **定内部还是外部、线束是否低阻、是否装在复合材料区**：这三项决定表 17 取哪一行哪一列（S1 p69）。这些是安装信息，由需求给出，原理图阶段不推定。
3. **端口耐受按两种量核**：电压波形（2、3、4）的 VL 或 VT 是端口要承受的开路电压，钳位器件的击穿与钳位电压、隔离器件的耐压按它核；电流波形（1、5A、6）的 IT 是注入线束的电流，钳位器件的峰值电流与能量按它核，单根导线取 c 栏值（S1 p69 注 c）。多重回击是 14 次在 1.5 s 内相继到来，钳位器件的能量与温升按重复脉冲核，不能只按单次（S1 p70 图 65）。
4. **CS106 与 CS117 分别核**：CS106 只施加在高电位电源线上，不含地线和回线（S1 p47）；CS117 的电源线试验按完整电源电缆和每根高电位线（S1 p68）。两项的钳位器件可共用，但电压、脉宽、源阻抗不同，要分别核。
5. **不用 IEC 浪涌代替**：IEC 61000-4-5 的 kV 等级和 1.2/50 µs 波形不能代替表 17 的电平和波形（G07-052）。
6. **判据**：CS117 判据是不出现任何故障、性能降低或偏离，严于工业标准的判据 B；所以试验期间通信、采样、控制输出都要不受影响，不能靠复位恢复（S1 p68）。
7. **试验列为下游**：原理图阶段写全矩阵行，试验通过与否在样机阶段判（G08-053）。

## 两端各要交代什么

- **需求侧**：安装平台；是否安全性关键设备、是否与之相连；内部设备还是外部设备；电缆是否敷设在甲板上；是否装在复合材料蒙皮或结构区域；线束是否短、低阻；订购方对 S、L 项目的规定；设备规范给出的允差。
- **设计侧**：每个电缆端口适用的项目和电平行；每根线的钳位或耐受方式及其按电压、电流两种量的核算；多线束按注 c 的取值；判据在电路上的具体含义。

## 准则没有覆盖的条件

- 条件 2：内部与外部设备、复合材料区、短低阻线束三项决定取值，G07-052 只写“按表 17”，没有列这三个输入。
- 条件 3：电压波形与电流波形分别核、多重回击按重复脉冲核能量、多线束按注 c 取小者。
- 条件 4：CS106 的电平（舰船 400 V、5 µs，飞机 200 V、10 µs）和只加高电位线的规定。
- CS115、CS116 的电平与施加对象。
