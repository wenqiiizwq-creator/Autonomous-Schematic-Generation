# Espressif ESP32-C3

类别：器件参数。
器件：Wi-Fi（11b/g/n）与蓝牙低功耗单芯片，单核 RISC-V 处理器，QFN32 封装，射频口 LNA_IN 直接出到板上做匹配；除基础型号外都带封装内闪存。本文收原件整个 ESP32-C3 系列。
手册：ESP32-C3 Series Datasheet v2.4。

## 引脚与处置

引脚共 33 个，其中 33 脚是底部地（S1 p14、p16）。

| 引脚 | 功能 | 能接受的电压 | 不用时怎么接 | 来源 |
|---|---|---|---|---|
| LNA_IN（1） | 射频输入输出 | 射频信号 | 接匹配网络与天线 | S1 p25 |
| VDD3P3（2、3） | 模拟电源 | 见推荐工作条件 |  | S1 p26 |
| VDD3P3_RTC（11） | RTC 与部分数字电源 | 见推荐工作条件 |  | S1 p26 |
| VDD3P3_CPU（17） | 数字电源 | 见推荐工作条件 |  | S1 p26 |
| VDD_SPI（18） | 闪存电源，可输入也可输出 |  |  | S1 p26 |
| VDDA（31、32） | 模拟电源 | 见推荐工作条件 |  | S1 p26 |
| CHIP_EN（7） | 高电平使能芯片，低电平关闭 | 见 VIH_nRST、VIL_nRST | 手册说明不要悬空 | S1 p25 |
| XTAL_N（29）、XTAL_P（30） | 外接晶体或振荡器，差分时钟 |  |  | S1 p25 |
| GPIO2（6）、GPIO8（14）、GPIO9（15） | 启动配置脚 | 见电气特性的数字口电平 | 见下面启动脚一段 | S1 p16 |

启动脚默认值：GPIO9 内部弱上拉，GPIO2、GPIO8 默认悬空（S1 p30）。启动方式：GPIO2 = 1、GPIO8 任意、GPIO9 = 1 为 SPI 启动；GPIO2 = 1、GPIO8 = 1、GPIO9 = 0 为联合下载启动，可经串口或 USB 下载；手册说明 GPIO2 其实不决定这两种启动方式，但建议上拉以防毛刺（S1 p31）。启动脚采样需要的保持时间 tH 最小 3 ms（S1 p30）；电源稳定后到 CHIP_EN 拉高之间的 tSTBL 最小 50 µs，CHIP_EN 保持低于 VIL_nRST 的 tRST 最小 50 µs（S1 p28）。

默认驱动强度：GPIO2、GPIO3、MTMS、MTDI 为 10 mA，GPIO18、GPIO19 为 40 mA，其余引脚为 20 mA（S1 p17）。

| ESP32-C3FN4（停产） | QFN32（5×5） |  | 4 MB 闪存，22 个 GPIO | -40 ~ 85 °C |  | S1 p12 |
