# Espressif ESP32-S3-MINI-1

类别：器件参数。
器件：Wi-Fi（11b/g/n）与蓝牙低功耗模块，内置 ESP32-S3 芯片（双核处理器）、SPI 闪存和部分型号带的伪静态存储器；MINI-1 带板载 PCB 天线，MINI-1U 带外接天线连接器。本文收原件中的 MINI-1 系列。
手册：ESP32-S3-MINI-1 & MINI-1U Datasheet v1.7。

## 引脚与处置

| 引脚 | 功能 | 能接受的电压 | 不用时怎么接 | 来源 |
|---|---|---|---|---|
| 3V3（3） | 电源 | 见推荐工作条件 |  | S1 p11 |
| EN（45） | 高电平使能芯片，低电平关闭 | 见 VIH_nRST、VIL_nRST | 手册说明不要悬空 | S1 p12 |
| IO0（4） | 启动配置脚，GPIO0 | 见电气特性的数字口电平 | 见下面启动脚一段 | S1 p11 |
| IO46（44）、IO45（41） | 启动配置脚，GPIO46、GPIO45 | 见电气特性的数字口电平 | 见下面启动脚一段 | S1 p12 |
| IO3（7） | 启动配置脚，GPIO3，决定 JTAG 信号来源 | 见电气特性的数字口电平 | 见下面启动脚一段 | S1 p11 |
| IO26（26） | 型号后缀为 -N4R2 时连内置存储器，不可另作它用 | 见电气特性的数字口电平 |  | S1 p11、p12 |

启动脚默认值（S1 p13）：GPIO0 内部弱上拉，GPIO45、GPIO46 内部弱下拉，GPIO3 悬空且没有内部上下拉。GPIO3 的手册要求：它的值必须由外部电路确定，不能处于高阻状态（S1 p15）。启动方式：GPIO0 = 1 为 SPI 启动（GPIO46 任意）；GPIO0 = 0 且 GPIO46 = 0 为联合下载启动，可经串口或 USB 下载（S1 p14）。GPIO45 在熔丝未强制时决定闪存电压：为 0 是 3.3 V，为 1 是 1.8 V（S1 p15）；模块内闪存的接法见手册外围电路与模块原理图章，本文未收。启动脚采样需要的保持时间 tH 最小 3 ms，电源稳定后到 EN 拉高之间的 tSTBL 最小 50 µs，EN 保持低于 VIL_nRST 的 tRST 最小 50 µs（S1 p14、p16）。

天线净空：MINI-1 的板载天线有净空区，MINI-1U 没有（S1 p10 的引脚布局图）。

## 必需外围

手册的外围电路图给出：电源脚去耦电容 22 µF 与 0.1 µF，EN 脚加 RC 延时，通常取 R = 10 kΩ、C = 1 µF，具体值按模块上电时序和芯片上电复位时序调整；32.768 kHz 晶体与负载电容为不装配（S1 p41）。底部散热焊盘可焊可不焊（S1 p41）。
