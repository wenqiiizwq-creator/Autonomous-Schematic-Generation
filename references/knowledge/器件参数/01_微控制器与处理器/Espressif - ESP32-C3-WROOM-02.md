## 引脚与处置

引脚共 19 个；GND 为 9 脚和 19 脚（S1 p10、p11）。

| 引脚 | 功能 | 能接受的电压 | 不用时怎么接 | 来源 |
|---|---|---|---|---|
| 3V3（1） | 电源 | 见推荐工作条件 |  | S1 p11 |
| EN（2） | 高电平使能芯片，低电平关闭 | 见 VIH_nRST、VIL_nRST | 手册说明不要悬空 | S1 p11 |
| IO8（7）、IO9（8）、IO2（16） | 启动配置脚，GPIO8、GPIO9、GPIO2 | 见电气特性的数字口电平 | 见下面启动方式一段 | S1 p11 |
| RXD（11）、TXD（12） | GPIO20、GPIO21，串口 0 | 见电气特性的数字口电平 |  | S1 p11 |
| IO18（13）、IO19（14） | USB 的 D-、D+ | 见电气特性的数字口电平 |  | S1 p11 |

启动脚默认值：IO9 内部弱上拉，IO8、IO2 默认悬空（S1 p12）；手册建议 IO2 上拉以防毛刺（S1 p13）。启动方式：GPIO2 = 1、GPIO8 任意、GPIO9 = 1 为 SPI 启动；GPIO2 = 1、GPIO8 = 1、GPIO9 = 0 为联合下载启动，可经串口或 USB 下载（S1 p13）。启动脚采样需要的保持时间 tH 最小 3 ms，电源稳定后到 CHIP_EN 拉高之间的 tSTBL 最小 50 µs，CHIP_EN 保持低于 VIL_nRST 的 tRST 最小 50 µs（S1 p13、p15）。

天线净空：WROOM-02 的板载天线有净空区，WROOM-02U 没有（S1 p10）。

## 必需外围

手册的外围电路图给出：3V3 脚的去耦电容 10 µF 与 0.1 µF，EN 的 RC 数值标为待定（TBD），EN 与 IO9 各接按键，IO8 上拉电阻，JTAG 与串口接口（S1 p34）。EN 不能悬空（S1 p11）。
