# TI TPS2372

类别：器件参数。
器件：PoE 受电端接口芯片，支持 IEEE 802.3bt Type 3、Type 4（兼容 Type 1、2），内置 100 V 热插拔开关，自动维持功率特征（MPS）与 Autoclass；TPS2372-3 面向 60 W、TPS2372-4 面向 90 W。
手册：SLUSCM4B，2018-11。

## 来源

- S1：Datasheet/08_电源管理/以太网供电 (PoE)/TI - TPS2372.pdf

页码均为 PDF 文件页序。本芯片只含受电接口与热插拔，没有 DC-DC 控制器，后级变换器另选。

用这些数时要注意：

- 检测电流、分级电流是控制器本身的值，PSE 在 PI 口看到的签名还要加上整流桥的压降和漏电（S1 p20）。
- MPS 要求在 PSE 端的电缆末端满足，电缆长度、体电容和整流桥类型会使芯片端所需脉冲更长，所以有三档占空比可选（S1 p23）。
- 热关断温度的迟滞 20 °C 手册标为仅供参考，不是保证值（S1 p8）。
- 手册写 Class 3 的最大功率为 12.95 W，IEEE 802.3 的 PD 输入平均功率上限写 13 W，两者差在取整（S1 p14；IEEE 802.3-2022 表 145–29）。

## 必需外围

- 检测电阻 RDEN：24.9 kΩ ±1 %，接 DEN 与 VDD 之间；手册说它只承受约 5 mW，可用小功率电阻（S1 p15、p20）。
- 分级电阻：Class 1 到 8 的 RCLSA、RCLSB 取值见下表（S1 p14）。
- 输入旁路电容 C1：VDD 与 VSS 之间 0.1 µF、100 V、±10 % 陶瓷（S1 p29）。
- 保护管 D1：整流后的 VDD 与 VSS 之间必须加瞬态抑制二极管，一般室内用 SMAJ58A 或同等器件；adapter 接在 VDD 与 RTN 之间时电缆电感与内部电容振铃会产生电压瞬变，要靠足够的电容或 TVS 限制在绝对最大值内（S1 p28）。
- REF 脚 49.9 kΩ ±1 % 到 VSS（S1 p3、p5）。
- 自动 MPS：负载电流可能低于约 20 mA 又要维持 PSE 供电时，AMPS_CTL 接电阻到 VSS，手册例取 1.3 kΩ（S1 p16、p30）。
- 输入整流桥：手册建议 3 A 到 5 A、100 V 的分立或桥式二极管；大功率高效率设计常用有源 FET 桥（S1 p28）。
