# 输出储能与滤波

功能：吸收开关纹波、提供负载瞬态电流并满足 PD 的电压/纹波要求。

适用范围：开关电源输出端。

电路类型：POWER_CONVERTER

## 做法

### 电解/聚合物 + MLCC 并联

- **适用范围**：5–21 V 可调输出、几安培
- **核心器件类**：20 铝电解电容、聚合物电容、MLCC
- **必需外围**：假负载/泄放电阻、π 型滤波电感（可选）
- **必算项**：
  - 纹波电流（RMS）与电解电容纹波额定、寿命
  - MLCC 在直流偏压、温度、容差、老化后的有效容量（采购下限）
  - 负载瞬态压降与 PD 规范要求
  - 放电时间（PD 电压切换与安全放电）
- **落实规则**：G03-010、G03-026、G03-039
- **已知坑**：
  - 关键旁路/输出 MLCC 只按标称容量算，直流偏压后不够（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-MLCC）
  - 两侧节点放电没有算（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-BLD）
