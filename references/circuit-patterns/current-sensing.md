# 电流检测与校准

功能：把输出或开关电流变成控制器可用的电压，并保证精度。

适用范围：PD 的 CC 控制、OCP、线缆补偿。

电路类型：ANALOG

## 做法

### 低边分流电阻进控制器 CS 引脚

- **适用范围**：PD 控制器内置电流放大器
- **核心器件类**：22 电流检测电阻（分流）
- **必需外围**：RC 滤波、Kelvin 连接（交 PCB）
- **必算项**：
  - 分流电阻功耗与温升、温度系数带来的误差
  - 控制器 CS 失调/增益误差 → 总误差预算，是否需要校准
  - 校准算法（单点/两点）与残差分配
- **落实规则**：G02-017、G02-027、G04-052
- **已知坑**：
  - 校准设计只写"需校准"没有算法与残差预算（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-CAL）
