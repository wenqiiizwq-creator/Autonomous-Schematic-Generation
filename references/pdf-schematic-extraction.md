# PDF 原理图分析与提取

从 PDF 形式的原理图（参考设计、开发板、评估板、应用笔记、手册的典型应用）提取电路线索。提取结果只作线索，
仍按 SKILL.md 任务 2.1 核对数据手册；人读的页面按任务 3.2 用 recipes 画，按任务 4.1 做自动检查。

## 阅读与提取顺序

1. **弄清目的**：整板重建、借用某个子电路、看厂家的器件选择，还是用已知可用的参考设计核对自己的数值。
2. **通读并编目**：先读标题页和页索引，按功能区读页，有 BOM 页就读 BOM。每页记下页标题与功能、关键 IC 及料号、
   电源轨和电压、连接器和接口，以及设计者标在图上的注释。一次读 2–4 页；复杂页一次只看一个区域；
   读不清的值记下来，再与 BOM 或数据手册交叉核对。
3. **按目的提取**：BOM（位号、值、封装、料号）、子电路拓扑与网络名、器件值及其理由、设计决定。
4. **核对**：按本页“对照数据手册核对”一节逐项核对，PDF 即使来自厂家也可能有错，应用条件也可能不同。

## 器件提取

| 字段 | 在 PDF 中的位置 | 说明 |
|-------|--------------|-------|
| 位号 | 印在符号旁（R1、C5、U3） | 编号习惯可能与你的工程不同 |
| 值 | 印在符号上或附近 | "100n"、"10K"、"4.7u"：注意记法 |
| 料号 / MPN | 在 BOM 表中，或印在符号上 | 原理图本身不一定看得到 |
| 封装 | 有时在 BOM，有时要从上下文判断 | "0402"、"0603"、"SOT-23-5" |
| 耐压 | 有时有标注，常常只在 BOM 中 | 对电容至关重要："16V"、"25V" |
| 容差 | 原理图上很少有，通常在 BOM 中 | "1%"、"5%"、"10%" |
| 注释 | 器件旁的设计者标注 | "DNP"、"Optional"、"Select for 3.3V" |

| PDF 记法 | 含义 |
|-------------|---------|
| `100n`、`0.1u`、`100nF` | 100 纳法（录入时统一写成 `100nF`） |
| `4R7`、`4.7R` | 4.7 欧（R 表示小数点） |
| `10K`、`10k` | 10 千欧 |
| `2M2` | 2.2 兆欧 |
| `4u7`、`4.7u` | 4.7 微法 |
| `22p` | 22 皮法 |
| `NF`、`NP`、`NC` | 不装 / 不贴 / 不连接 |
| `DNP`、`DNS` | 不装配 / 不贴装 |

PDF 常省略的信息：

- **没写 MPN**：按值 + 封装找合适的器件；只写 "100nF" 的通用件在补全 BOM 时选定具体料号。
- **没写封装**：有 BOM 就查 BOM，否则从上下文推断，并写明是推断。
- **电容没写耐压**：额定耐压 ≥ 所在电源轨最高电压（直流加交流峰值）÷ [降额规范](shared/derating-rules.md)该电容类型电压规则的本级取值（片状陶瓷 CAP-MLCC-CHIP-V、铝电解 CAP-AL-V-LOW/HIGH、钽 CAP-TA-V 等；等级未定按设计准则库工程取值 `unset_level`），取不低于它的标准档

## 网络与连接提取

PDF 用导线、网络标签（同名即同一网络，跨页也一样）、电源符号、端口/出页连接符和总线记法（D[0:7]）表示连接。
多页原理图要逐页记下出页连接符和标签并跨页匹配；电源轨通常全局。复杂的提取先建一份网络图，再写设计网表：

```
Net Name: USB_DP
  Page 2: U1 pin 33 (MCU USB_DP)
  Page 2: R5 pin 1 (22R series resistor)
  Page 3: J1 pin A6/B6 (USB-C connector D+)
  Page 3: U4 pin 3 (ESD protection)
```

地符号可能有几种（机壳地、数字地、模拟地、信号地）：弄清原设计里哪些相连、哪些分开，每个不同的地网络在设计网表里单独命名。

## 子电路提取

最常借用的是电源（LDO、Buck、Boost、充电器）、接口（USB、以太网、CAN、RS-485）、传感器前端、无线模块外围和保护电路。
每个提取的子电路核对：

- [ ] 所有器件已识别并有值，所有连接（含电源和地）已追踪，网络名已记录
- [ ] 原设计者的注释已记下，与其他子电路共用的器件（如共用的大电容）已识别
- [ ] 板子专用的器件（不需要的测试点、调试排针）已识别并排除
- [ ] 电源轨和电流要求已写明，已对照 IC 数据手册核对

几乎不能原样照抄。常见的改造：

| 改造 | 何时需要 | 怎么做 |
|-----------|-------------|-----|
| **输入电压不同** | 你的电源与参考设计不同 | 重新计算输入电容、耐压、反馈分压 |
| **输出电流不同** | 负载更轻或更重 | 核对稳压器额定，调整电感/电容规格 |
| **温度范围不同** | 工作环境与参考设计不同 | 按全温角点核对器件额定 |
| **封装不同** | 想用别的封装 | 找同一 MPN 的其他封装，或等效器件 |
| **去掉不用的功能** | 参考设计有你不需要的功能 | 查数据手册确认哪些器件是可选的 |
| **增加功能** | 想要 power-good 或软启动 | 按数据手册加器件 |
| **器件供货不同** | 原器件难买 | 找关键参数匹配的等效器件，按任务 2.3 核对 |

说不清某个器件为什么在那里、应该取什么值时，先查清楚再加；照抄不明所以的器件会留下调试不了的神秘器件。

## PDF 器件到 KiCad 符号的对应

| PDF 符号 | KiCad 库 | 说明 |
|-----------|--------------|-------|
| 电阻（矩形或锯齿） | `Device:R` | 加 MPN、值、封装 |
| 电容（两条线） | `Device:C` 或 `Device:C_Polarized` | 电解/钽电容用有极性的 |
| 电感（线圈） | `Device:L` | 看是否需要屏蔽型 |
| 二极管（三角形） | `Device:D`、`Device:D_Schottky` 或 `Device:D_Zener` | 类型与功能匹配 |
| LED | `Device:LED` | 记下颜色以确定正确的 VF |
| N 沟道 MOS | `Device:Q_NMOS_GDS` | 核对引脚顺序一致 |
| P 沟道 MOS | `Device:Q_PMOS_GDS` | 核对引脚顺序一致 |
| NPN/PNP | `Device:Q_NPN_BCE` / `Device:Q_PNP_BCE` | 核对引脚顺序 |
| 一般 IC | 按 MPN 搜 KiCad 库 | 库里没有就查厂家库，或按数据手册引脚说明建自定义符号 |
| 连接器 | `Connector_Generic:Conn_01xNN` 或专用符号 | 匹配引脚数和类型 |
| 晶振 | `Device:Crystal` | 两脚或四脚（带地） |
| TVS 二极管 | `Device:D_TVS` 或 `Device:D_TVS_bidir` | 单向/双向（注意 `Device:D_TVS` 只表示双向，单向器件见 symbol-and-peripheral-contracts.md） |
| 磁珠 | `Device:FerriteBead` | 值为 100MHz 下的欧姆数 |

来自 Altium、OrCAD 或 Eagle 的 PDF 显示的引脚号或引脚名可能与 KiCad 符号不一致：引脚编号以数据手册为准。

## 对照数据手册核对

PDF 原理图会错：没有应用勘误、转绘错误、版本不一致（PDF 是 rev A，手册已到 rev C）、板子专用的临时修补、工作条件不同。核对步骤：

1. 拿到每颗 IC 的当前数据手册，不依赖 PDF 附带的信息。
2. 逐脚比较 PDF 的连接与手册引脚表。
3. 与手册的 "Typical Application" 电路比较。
4. 器件值按手册推荐核对（任务 2.1–2.2）。
5. 查取代该参考设计的勘误或应用笔记。
6. 核对 PDF 中的封装与当前可买到的是否一致。

危险信号：

- 看起来不寻常的器件值（例如本应 100nF 的地方是 47nF）
- 数据手册说应悬空的引脚被连上了（或反过来）
- IC 电源引脚缺去耦电容
- 网络标签与 IC 数据手册的引脚名对不上
- "TBD"、"check"、"verify" 之类的标注：设计可能尚未定型
- 很老的版本日期：电路可能早于重要的勘误
