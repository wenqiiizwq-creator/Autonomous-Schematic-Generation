# NTC 温度检测

功能：把板温/口温变成控制器 ADC 可读的电压用于降额和保护。

适用范围：PD 控制器或 MCU 的温度降额。

电路类型：ANALOG

## 实现方案

### NTC 分压进 ADC

- **适用范围**：控制器提供上拉或外部分压
- **核心器件类**：22 NTC 热敏电阻、22 电阻、20 电容
- **必需外围**：分压电阻、滤波电容
- **必算项**：
  - 全温范围的分压读数与 ADC 量程、阈值映射
  - B 值容差与电阻容差带来的温度误差
  - 自热
  - 从 NTC 分压到数字温度列全链误差表：B 值、电阻比、初始/温漂/老化、偏置及漏电压降、ADC 增益/失调/量化误差、基准初始误差与温漂；合成全温温度误差及阈值偏差对照检测精度/降额要求，可校准项另列条件与残差
- **落实规则**：G04-052、G04-054
- **已知坑**：
  - NTC 全温读数没有算就定阈值（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-NTC）
  - 降额映射是固件配置，要在选型/配置表里落实（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-APP）
