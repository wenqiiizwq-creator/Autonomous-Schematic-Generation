# 辅助绕组过压锁定

功能：用辅助绕组电压间接检测输出过压并锁定控制器。

适用范围：有 FAULT/OVP 引脚的反激控制器。

电路类型：POWER_PROTECTION

## 实现方案

### 齐纳 + 电阻进 FAULT 引脚

- **适用范围**：要求反馈失效时硬件过压关断
- **核心器件类**：23 齐纳二极管、22 电阻
- **必需外围**：限流电阻、滤波电容
- **必算项**：
  - 正常窗口：最高正常辅助电压下不误动作（齐纳最小击穿 + FAULT 阈值）
  - 故障窗口：反馈开路时输出升到多少才动作，是否低于输出电容/负载耐压
  - 齐纳温漂与 FAULT 阈值容差两侧
  - 列 FAULT 锁存的复位路径及位号（如断电泄放），计算 VCC 衰减到复位门限所需时间并对照要求的断电时间；在原理图表达该路径，核故障持续时不会形成不受控重试
  - 把齐纳、分压/限流电阻及 FAULT 门限的初始容差（含装配漂移）、温度、寿命末老化、辅助绕组接口及负载变化列参数变化表，合成动作上下界对照正常窗和保护窗；略去项给量化理由
- **落实规则**：G02-005、G05-060
- **已知坑**：
  - D403 的正常窗口与故障窗口只算了一侧（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-AUX-OVP）
  - 保护/检测阈值都要两侧算：不误动作 + 保护有效（SKILL.md 任务 2.2）
