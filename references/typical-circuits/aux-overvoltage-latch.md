# 辅助绕组过压锁定

功能：用辅助绕组电压间接检测输出过压并锁定控制器。

适用范围：有 FAULT/OVP 引脚的反激控制器。

电路类型：POWER_PROTECTION

## 实现方案

### 齐纳 + 电阻进 FAULT 引脚

- **适用范围**：要求反馈失效时硬件过压关断
- **核心器件类**：23 齐纳二极管、22 电阻
- **必需外围**：限流电阻、滤波电容
- **必算项**：
  - 正常窗口：最高正常辅助电压下不误动作（齐纳最小击穿 + FAULT 阈值）
  - 故障窗口：反馈开路时输出升到多少才动作，是否低于输出电容/负载耐压
  - 齐纳温漂与 FAULT 阈值容差两侧
- **落实规则**：无（正常/故障窗口对应 G05-036/037，但两条的适用文本限于热插拔/eFuse/负载开关，待规范放宽后引用）
- **已知坑**：
  - D403 的正常窗口与故障窗口只算了一侧（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-AUX-OVP）
  - 保护/检测阈值都要两侧算：不误动作 + 保护有效（SKILL.md 任务 2.2）
