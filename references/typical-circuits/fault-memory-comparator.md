# 比较器 + 触发器的故障记忆与清锁

功能：用比较器从锁定型热插拔控制器的定时脚识别真正的过流故障（电平与斜率同时成立），经冷启动门控置位 D 触发器；锁存跨普通 MCU 复位保持，只在清锁许可成立时由 MCU 清锁请求的上升沿清除，或由真实冷启动清除；锁定输出经缓冲门与开漏 MOS 把控制器 UVLO 拉低，保持主路关断。

适用范围：带定时电容脚的锁定型热插拔控制器（插入延时与故障定时都给同一电容充电）；要求普通 MCU 复位、看门狗复位不清锁，主过流锁定不关常供域；比较器与逻辑由主保护之前的常供电源供电。各路 eFuse 的短路记忆用同一套触发器、清锁资格与冷启动门控，事件由 eFuse 指示组合产生（见 efuse-bfet-short-latch）。

电路类型：POWER_PROTECTION、STARTUP

## 实现方案

### 比较器判定时脚电平与斜率 + D 触发器记忆（D 端清锁资格）+ 开漏 MOS 保持 UVLO

- **适用范围**：只判定时脚电平会在插入延时误动作，要加斜率判据区分插入充电与故障充电；比 SR 锁存器多出 D 端清锁资格，许可恢复时不会消费一直为高的旧清锁请求；保持用开漏 MOS 而不用二极管，不锁时不改变 UVLO/OVLO 分压
- **核心器件类**：05 比较器（开集电极输出，多通道）、18 触发器_锁存器_寄存器（带 PRE/CLR 的 D 触发器）、18 标准逻辑门（NOR、NAND，施密特输入）、09 MOSFET（小信号 N 沟道，低关断漏电）、23 肖特基势垒二极管 (SBD)（差分器负向钳位）、22 电阻、陶瓷电容（差分器用 C0G）
- **必需外围**：
  - 识别：比较器由常供电源经 RC 去耦供电；电平比较器：定时脚对基准分压上点；斜率比较器：定时脚经电容-电阻差分器（肖特基负向钳位）对基准分压中点；许可比较器：定时脚低于再使能门限之下的分压点时输出释放；比较器输出各自上拉；未用比较器输入固定
  - 记忆：事件 = NOR(电平_N, 斜率_N)；PRE_N = NAND(事件, 冷启动复位_N)；CLR_N = 冷启动复位_N；D = NOR(Q̄, 许可)；CLK = MCU 清锁请求（下拉电阻）
  - 保持与读回：Q 经缓冲门驱动开漏 MOS 把控制器 UVLO 拉到地；锁定状态送 MCU 读回并留测试点；MCU 命令线上拉到关断态、清锁请求线下拉
- **必算项**：
  - 电平门限：基准电源容差、分压电阻容差与比较器全温失调合成；下端高于正常启动结束时定时脚电压上限，上端低于控制器定时上门限下限（控制器关断前已置位）
  - 斜率门限：插入定时电流上限对应斜率的差分输出低于斜率门限下端；故障定时电流下限对应斜率、在到达电平门限时的差分输出高于斜率门限上端
  - 许可门限上端低于控制器再使能门限（手册只给典型值的标典型）
  - 比较器开集电极输出在实际灌电流下的低电平上界低于施密特门 VT− 下限（手册只给两点电流时外推，标估算）
  - 锁存 Q 高电平下限高于保持 MOS VGS(th) 上限；导通压降远低于 UVLO 门限下限；不锁时 MOS 关断漏电计入 UVLO/OVLO 门限（动作态与不动作态都核）
  - 冷启动复位门限下端高于逻辑器件最低工作电压（掉电先复位、冷启动清锁有效）
  - 清锁事务：先关断全部受控输出、确认许可、清锁脉冲宽度与读回；清锁后各路保持关断直到新命令
  - 故障注入项：主过流锁定、清锁、保持 MOS 开路时只靠控制器自身锁定
- **落实规则**：G02-004、G02-022、G02-023、G04-010、G05-008、G05-009、G05-018、G05-060、G05-061、G05-063、G05-064、G05-065
- **已知坑**：
  - 插入延时期间定时脚同样充电到上门限，只判电平会误锁；插入与故障的充电电流保证范围不重叠，才能用斜率区分（datasheet:Datasheet/08_电源管理/热插拔_eFuse/TI - LM5069.pdf#p6）
  - 用二极管从逻辑高电平拉 UVLO 保持锁定时，不锁状态下高输入使二极管反向把 UVLO 分压钳住、OVLO 失效；改开漏 MOS，门限要同时核动作态与不动作态（user:2026-11-03，R2 CALC-MAIN-UVOV 复核发现）
  - PRE 与 CLR 同时有效时 Q 与 Q̄ 同为高且不保持；故障事件置位必须由冷启动复位门控，冷启动优先（datasheet:Datasheet/18_逻辑与电平转换/触发器_锁存器_寄存器/TI - SN74HCS74.pdf#p10）
  - 比较器输出低电平只在空载与一个较大灌电流两点、最高电源下给出，接施密特门时按外推核 VT−，留样机实测（datasheet:Datasheet/05_放大器与比较器/比较器/TI - TLV1704.pdf#p7）
  - 冷启动复位只取监督器输出，不接 MCU 复位线；看门狗或软件复位不得清锁（user:2026-11-03，R2 MCU与固件接口.md 第 3 节）
  - 控制器再使能门限只有典型值，许可门限按典型值留余量，结论只能是条件成立（datasheet:Datasheet/08_电源管理/热插拔_eFuse/TI - LM5069.pdf#p6）
