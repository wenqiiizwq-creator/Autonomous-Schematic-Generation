# 多域复位监督与单向开漏组合

功能：每个电源域一颗固定门限复位监督器（SENSE 接逻辑电源、MR 接该域降压器的 PG、固定延时档），输出经施密特缓冲和开漏驱动分别送 MCU、交换芯片、PHY 的复位；MCU 自身复位（看门狗、软件、NRST 内部拉低）不反向影响网络域和故障锁存，监测逻辑电源的那一路另作冷启动复位直接送故障记忆。

适用范围：3.3 V 逻辑电源加多路低压降压器的网络/控制板；要求 MCU 复位与网络复位分域、普通 MCU 复位不清故障锁；不做输出精密窗口检测。

电路类型：STARTUP

## 实现方案

### 每域一颗监督器（MR 接 PG）+ 施密特缓冲 + 开漏驱动

- **适用范围**：MCU 的 NRST 是双向脚、内部复位时自身拉低，各域复位与冷启动复位要互不反灌；比加双与门的三芯片做法少一颗器件（见来源方案设计 §35）；比精密窗口监控器方案少器件，但只监测逻辑电源门限与降压器 PG，不检测低压轨的窗口
- **核心器件类**：08 电压监控_复位(Supervisor)（开漏 RESET、MR 输入、CT 固定延时档）、18 缓冲器_收发器（施密特输入缓冲；开漏输出缓冲，均支持 Ioff）、22 电阻、陶瓷电容
- **必需外围**：每颗监督器 VDD 去耦；CT 经手册范围内的电阻接 VDD（固定长延时档）；RESET 开漏上拉；MR 接对应降压器 PG（PG 上拉到监督器 VDD 同一电源）；冷启动复位（监测逻辑电源、MR 接逻辑电源 PG 的那颗）直接送故障锁存的 CLR 与 PRE 门控，同时经缓冲送 MCU；开漏驱动输出各自上拉，MCU NRST 加对地电容；缓冲器与驱动器去耦，未用输入接地、未用输出悬空
- **必算项**：
  - 逻辑电源输出下限减纹波高于复位门限上端（门限全温精度）
  - 复位门限下端高于故障锁存逻辑的最低工作电压（掉电先复位、冷启动清锁有效）
  - 默认态表：监督器上电复位电压以上 RESET 即有效为低，开漏驱动由同一逻辑电源上拉，上电与复位期间各域复位输出为确定低电平
- **落实规则**：G04-010
- **已知坑**：
  - CT 接 VDD 取固定长延时档要经手册规定范围的电阻，不能直连；悬空为短延时档，要压低 CT 脚寄生电容（datasheet:Datasheet/08_电源管理/电压监控_复位(Supervisor)/TI - TPS3808.pdf#p11）
  - MR 内部上拉到 VDD，高电平门限按 VDD 比例；降压器 PG 的上拉电源要与监督器 VDD 相同，RESET 上拉电阻有下限（datasheet:Datasheet/08_电源管理/电压监控_复位(Supervisor)/TI - TPS3808.pdf#p4）
  - MCU 复位脚双向，直接和其他域复位或冷启动复位相连，看门狗复位会传到网络域并清掉故障锁；各域输出经施密特缓冲与开漏驱动单向隔离（user:2026-11-02，方案设计 §22 SIMPLE-1）
  - 冷启动复位只接监督器输出，普通 MCU 复位线不接入故障锁存的 CLR 与 PRE 门控（user:2026-11-03，R2 MCU与固件接口.md 第 3 节）
  - 固定延时档只有表列范围，复位延时相对电源斜率、时钟有效的起算条件 R2 未闭合，不当作已核定的产品时序（user:2026-11-02，方案设计 §22）
  - 缓冲器未用输入必须接 VCC 或 GND，不能悬空（datasheet:Datasheet/18_逻辑与电平转换/缓冲器_收发器/TI - SN74LVC3G17.pdf#p4）
