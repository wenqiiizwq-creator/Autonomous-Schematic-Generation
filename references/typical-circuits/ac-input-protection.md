# 市电输入：整流、浪涌与 EMI

功能：把市电变成可用的整流母线，并挡住浪涌、过流和传导 EMI。

适用范围：85–264 Vac 单相输入，几十瓦到几百瓦；不含三相和 PFC 本体。

电路类型：POWER_PROTECTION、AC_MAINS

## 实现方案

### 保险丝 + NTC + MOV + 共模扼流圈 + 桥式整流

- **适用范围**：通用输入适配器/充电器 30–300 W
- **核心器件类**：28 保险丝、22 NTC 热敏电阻、28 压敏电阻、21 共模扼流圈、20 安规电容(X_Y)、23 桥式整流器（见 part-roles.md）
- **必需外围**：X 电容泄放电阻或泄放 IC；Y 电容跨隔离；整流后母线电容（PFC 时为小薄膜电容）
- **必算项**：
  - 保险丝额定与分断：冲击电流（NTC 冷态）、预期短路电流、与 MOV 的配合
  - MOV 压敏电压 ≥ 最高输入峰值×裕量，能量与保险丝配合
  - NTC 冷态浪涌限流与稳态功耗/温升
  - X 电容泄放时间常数（安规要求）
  - 安规爬电/间隙与 5000 m 海拔修正
  - 保险丝的 AC/DC 额定类型与回路一致；额定电压覆盖最高回路电压（含瞬态钳位后的电压），对照 FUSE-V 降额限值
  - 按保险丝局部最高温度及手册曲线折减额定电流，再按 FUSE-I/FUSE-TEMP 核持续电流；手册规定叠加的标准降额与温度折减同时计入
  - 保险丝动作点最低端（容差、温度）高于最大正常电流；启动浪涌和负载跃变的幅值、持续时间对照时间—电流特性，确认不误熔断
  - 从市电源到负载列保护链协调表：动作量、动作点最小/最大值、动作时间或时间—电流曲线、恢复方式、被保护对象及耐受；采用保证值，典型曲线标明并定界
  - 假定 MOV 短路或灾难性击穿，按故障电流算上游保险丝清除时间与清除前能量，对照相邻器件损坏及起火耐受；不能清除时写明后果和处置
  - 按实际浪涌电流、波形及最高温度算 MOV 钳位电压（VBR + ISURGE·RDYN），不超过桥堆和后级最低绝对最大值；波形不匹配时标估算并保留证据缺口
  - 把共模扼流圈的实际差模等效电感、X 电容及源阻抗纳入滤波模型；在输入、功耗、源阻抗及元件容差最坏组合下算谐振峰与后级变换器最小输入阻抗，确认全频段 |Zin|/|Zfilter,out| ≥ g03_filter_z_ratio；不足或算不清时按 G03-012 核阻尼，不以共模电感标称值代替差模模型
- **落实规则**：G03-011、G05-019、G05-020、G05-021、G05-031、G05-032、G05-035、G05-045、G05-046、G05-047、G05-048
- **已知坑**：
  - 保险丝分断与输入浪涌没有一起算，只给了额定电流（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-AC）
  - 交流引入端的电气规格（永久焊接、电压/电流额定、应力释放）没有写进设计（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-AC-CONTACT）
  - 两侧节点放电（X 电容、母线）没有算放电时间与功耗（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-BLD）
