# 隔离反馈与隔离信号

功能：把二次侧的调节误差和故障/许可信号送过隔离带。

适用范围：隔离电源的 CV/CC 反馈、故障锁定、PFC 许可。

电路类型：POWER_CONVERTER、ISOLATION

## 实现方案

### PD 控制器直驱光耦（无外置误差放大器）

- **适用范围**：PD/快充控制器内置反馈补偿并直接驱动光耦二极管
- **核心器件类**：24 光耦（线性晶体管输出，CTR 分档）、22 电阻
- **必需外围**：光耦偏置电阻、控制器 OPTO 引脚外围、一次侧 FB 上拉
- **必算项**：
  - CTR 最小值×温度×老化折减下的环路增益与饱和余量
  - 光耦二极管电流范围与控制器驱动能力
  - 环路带宽与相位裕量（控制器内置补偿的可配置范围）
  - 增益裕量（按内置补偿的配置值与 CTR 两端，取最坏组合）对照 g03_loop_gm_min
  - 光耦或其驱动单点开路时输出的上升速度，对照一次侧过压保护的检测延时与输出电容额定
  - 反馈光耦、驱动及其供电的单点失效按 g05_critical_item_criterion 列关键项，对应独立过压通道等控制措施
- **落实规则**：G02-005、G03-008、G03-009、G05-006、G05-009
- **已知坑**：
  - 三路光耦的 CTR 折减与故障驱动余量没有按温度/寿命算（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-OPTO）
  - CTR 分档是决定性参数，换料号要重算环路（选型记录光耦角色）
  - 反馈光耦是唯一送能控制，单点开路时一次侧按限流满功率送能，FAULT 脚过压检测 22.5 ms 的延时远长于输出电容 4.5 ms 越过额定的时间，需要独立的二次侧快速过压通道（review:SR-20261023-R5-验收-claude-6d74689/F-A）
- **来源**：
  - raw/Designexample/USB-PD/NCP1343PD100WGEVB（U4 光耦、RT 参考电路）
  - raw/Datasheet/08_电源管理/USB PD 控制器/Richtek - RT7209.pdf

### 光耦 + 并联基准（TL431 类）

- **适用范围**：无内置反馈的变换器，固定输出
- **核心器件类**：24 光耦、08 电压基准（并联型）、22 电阻、20 电容
- **必需外围**：分压网络、补偿 RC、基准最小阴极电流电阻
- **必算项**：
  - 分压与基准精度 → 输出精度
  - 最小阴极电流
  - 环路补偿
  - 环路 Bode 在输入、负载、电容/ESR（低温、寿命末）最坏组合下算；CTR 取初始两端并计温度与老化，相位裕量 ≥ g03_loop_pm_min
  - 静态输出误差（分压/基准）加负载跃变动态偏差（ΔI·ESR + ESL·di/dt 估算）合计对照负载电压窗
- **落实规则**：G03-008、G03-026
- **已知坑**：
  - 并联基准最小阴极电流在轻载/低光耦电流时不满足
- **来源**：
  - raw/Designexample/USB-PD/DER-937（对比参考）

### 故障/许可信号光耦

- **适用范围**：二次侧故障锁定一次侧、一次侧许可 PFC
- **核心器件类**：24 光耦、22 电阻
- **必需外围**：驱动限流电阻、接收侧上拉/下拉；驱动脚手册没有规定灌电流/VOL 时，加小信号 MOS（或 NPN）缓冲，
  栅极下拉保证上电默认关断；或改用手册规定的电流源档位直接点亮 LED
- **必算项**：
  - 驱动电流在最低驱动电压（低 V5、缓冲管最大导通压降或电流源档位下限）下仍大于锁定所需电流/CTR，CTR 取最小档并折减
  - LED 电流按需求定，不要远大于接收侧所需（多给的电流只增加功耗和老化）
  - 误动作裕量
  - 故障/许可驱动在上电、掉电、复位期间的默认状态表：按上下拉与漏电最坏端算电平，对照安全状态阈值
  - 驱动电流、VOL、CTR、接收门限取准确料号手册的保证限值（记表/页与测试条件），不用典型值算裕量
- **落实规则**：G02-003、G02-005、G04-010
- **已知坑**：
  - 低 V5/GPIO 实际电流下的驱动条件没核（review:SR-20261019-R3-改版前独立审查-41f4ad3/W-OPTO、W-V5）
  - PD 控制器 GPIO 开漏灌电流直驱光耦：RT7209 手册的 GPIO 只给开路电压和偏置电流档，没有灌电流、VOL 或导通电阻，
    计算里的 VOL≤0.4V 是编出来的；参考电路 GPIO 悬空，唯一的光耦接在 OPTO 上
    （review:SR-20261023-R5-从头审查-claude-5802e8c/F-GPIO-SINK，SR-20261023-R5-全新独立复审-1fe4df6/W-OPTO）
- **来源**：
  - raw/Designexample/USB-PD/NCP1343PD100WGEVB（U2/U3）
