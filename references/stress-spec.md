# 器件应力规范

> 读者：审查员（ASG 设计与 SR 审查共用此文件，两仓逐字相同）。

本规范定器件应力怎么判、查到什么程度。降额值取自 [降额规范](derating-rules.md)（`derating-rules.json`），
本文件取代降额规范原来的 R6（2026-10-27，用户：将共用规范 R6 和 ASG 统一到现在的“应力”规范下来，制定单独的应力规范）。
两个仓库里本文件逐字相同，改动要两边同时改。

## 降额等级

等级是需求的一部分，写明来源：SR 写 `intent.derating{level, source}`，ASG 写设计记录的 `derating{level, source}`；
`source` 是 `req:<需求编号>`，或 `clarification:<已答复的需求澄清编号>`。需求没写等级时按需求澄清当场问用户，
附建议等级（降额规范“降额等级从哪来”）。等级定下之前，点名降额规则的比较不能判。

## 判定

| 最坏应力 | 结论 |
|---|---|
| 超过额定值（最坏工作温度下的保证额定，降额规范 R4） | 不成立：记失败项，按实际后果定级 |
| 在额定值内，超过本等级的降额值 | 合格但有风险（应力）：余量写风险 `{types: [STRESS], corner, improvement}`，进风险清单，不挡定稿；改进写换额定更高的件或降低应力 |
| 不超过本等级的降额值 | 合格 |

降额值以内不写应力风险。1013 5.1、GJB 4.4 允许经评估偏离降额值：偏离就是上表第二行，不另挂待办，也不另要用户签认。

## 查到什么程度：按余量审核

只审写出来的应力余量，不要求每颗器件、每个参数都有一条降额比较（2026-10-27，用户：每颗器件都有降额规则过于严苛，
统一到余量审核规则上来）。

- 比较器件应力与额定的余量，降额规范对这类器件、这个参数有规则的，在余量上点名规则（SR：`basis.derating_rule`；
  ASG：计算检查的 `derating_rule`）。
- 门禁按等级核：规则存在、适用于该器件类型；判据是 `ratio`、`pulse_ratio` 的，按“应力 = 额定 − 余量、
  降额值 = 额定 × 本级取值”重算，核风险标签与上表一致。其余判据（`margin_c`、`max_c`、`tj_percent` 等）
  由写余量的一方按降额规范的判据表算，门禁只核规则与器件类型。
- 余量比较的是保证额定值、没点名规则，而降额规范对这类器件、这个量（电流、电压、功率）只有一条 `ratio` 规则适用时
  （同类有几条的按器件身份区分，如 USB 母座、器具耦合器，都不像的取“其他”那条），按本级重算；应力超过降额值的
  列为应力风险（SR：门禁自动列入风险清单；ASG：设计检查同样核），2026-10-28 起。
- 其余没点名规则、而降额规范有这类器件规则的应力余量，只出提示（SR：`DERATING_RULE_AVAILABLE`），不拒收。
