## 2. 决定的三种来源

| 来源 | 写法 | 何时用 | 审计核对 |
|---|---|---|---|
| 用户当场答复 | `user:<日期>`，并写 `locator`（对话里哪一处） | 有人可问时 | 日期格式；`locator` 非空；决定里任何文字不得是运行者自拟的标记（见第 5 节 `decision_self_assigned`） |
| 方案文档已确认 | `scheme:<证据编号>`，并写 `locator` 与 `quote`（原文） | 需求或方案文档已写明用户确认的选型（SKILL 1.4 已有“一并列出即可，不另问”） | 证据编号在 `design-closure.json.evidence`；文件不是 ASG 自己写的（不在 `设计资料/`、`record/` 下）；`quote` 在该文件里原样出现，且含选定型号 |
| 任务书代答（新） | `delegate:<代答人>:<日期>` | 外部流程派发、无人当场答复，任务书写明了代答授权 | `record/task.json` 有 `delegation`，代答人与日期一致，`scope` 含这一处；按 `rule` 核对答复内容（第 3 节） |

没有第四种。运行者自己拿主意不是来源：说明要求“按推荐自选”而任务书没有 `delegation` 时，按 PoE 的做法停下来问，或交 `NEEDS_INPUT`。

## 3. 数据格式

### 3.1 `task.json` 新增 `delegation`（可选，由流程生成，ASG 不修改）

```json
"delegation": {
  "by": "eval-wholeboard",
  "date": "2026-11-07",
  "scope": ["clarification", "selection"],
  "rule": "adopt_recommendation",
  "text": "本次评测没有用户可问。需求澄清采纳 ASG 的建议条文；选型确认采纳 ASG 的推荐方案。"
}
```

- `by`：代答人，字母、数字、`-`、`_`、中文，不含 `:` 和空格；`date`：`YYYY-MM-DD`。
- `scope`：`clarification`（1.1 及中途的需求澄清）、`selection`（1.4 选型确认，以及 ② 中改变已确认选型后的重新确认）。
  ② 中改变已确认方案的结果本来就写回这两处（SKILL 2.x 第 4 条“答复写回 `selection.json` 与需求清单”），不另设第三种范围。
- `rule`：目前只有 `adopt_recommendation`——代答只能采纳 ASG 的建议，不能替用户做别的选择。
- `text`：授权原文，报告照录。
- 用了 `delegate:` 来源时，ASG 把派发的 `task.json` 原样复制为交付目录的 `record/task.json`，打包时登记哈希；
  流程或评测方拿它和派发时的 `task_digest` 比对。

现有的 `clarification_answers`（逐项预填的答复）保留，`by` 写真实答复人；ASG 引用它时同样要复制 `record/task.json`。

### 3.2 选型确认：每个核心角色都有 `decision`

```json
"decision": {"source": "user:2026-11-07", "locator": "对话记录 2026-11-07 选型确认清单"}
"decision": {"source": "scheme:E-REQ", "locator": "决定表 D-04", "quote": "主输入热插拔控制器用 LTC4282（用户 2026-10-20 确认）"}
"decision": {"source": "delegate:eval-wholeboard:2026-11-07"}
```

有 `options` 的角色照旧加 `option`（方案名），选定型号必须在该方案的 `parts` 里。一次汇总确认的清单，各角色写同一个来源即可。

### 3.3 澄清答复：`by` 与 `source`

| 答复来自 | `by` | `source` |
|---|---|---|
| 用户当场答复 | 真实答复人或角色（“用户”“产品负责人”） | `{"source": "对话记录", "locator": …}`（现行写法不变） |
| 任务书逐项预填 | 与 `clarification_answers` 该项的 `by` 相同 | `{"source": "任务书", "locator": "<任务 id> clarification_answers <澄清编号>"}` |
| 任务书代答 | `delegate:<代答人>:<日期>` | `{"source": "任务书", "locator": "<任务 id> delegation"}` |
